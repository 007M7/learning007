# Learning 007 学科来源知识库

本目录是课程正文的上游资料层。它不直接存放教学话术，而是分领域维护权威书籍、核心论文、官方来源、开放获取状态和本地缓存证据。

## 六个领域

- `machine-learning`：机器学习
- `deep-learning`：深度学习
- `nlp`：自然语言处理
- `ai-product`：AI 产品经理
- `low-altitude`：物理 AI · 低空智能
- `robotics`：物理 AI · 机器人

每个领域包含：

- `books.json`：人工精选的教材、专著与权威手册；
- `papers.json`：按子主题从 OpenAlex 抓取并筛选的核心论文；
- `summary.json`：数量、主题覆盖、开放获取和更新时间统计。

`cache/books/` 保存从作者、出版社、大学、政府或标准组织官方下载的开放版本。缓存不提交 Git；书目记录保存下载 URL、文件哈希、文件大小和核验时间，任何机器都能重新构建。

## 权威性准入

书籍至少满足一项：领域公认教材；顶尖大学长期课程用书；权威学者专著；一线出版社出版；政府、国际组织或专业机构正式手册。商业版权书只记录官方入口，不从非授权站点下载。

论文按子主题分层选取：经典高被引工作、奠基性方法、可靠基准/综述，以及 2023 年以来能修正当前能力边界的近期论文。引用数只是筛选信号，不等于结论正确；记录中保留抓取时点和开放获取状态。

## 维护命令

```bash
npm run kb:refresh
npm run kb:download-books
npm run kb:validate
npm run kb:report
```

`kb:refresh` 会重新抓取论文并合并稳定 ID；`kb:download-books` 只下载声明为官方开放全文的书籍；`kb:validate` 检查每领域不少于 10 本书、100 篇论文以及必要元数据；`kb:report` 生成根目录下的 `REPORT.md`。

## 版权与使用边界

资料库不绕过登录、付费墙或数字版权保护。`open_fulltext` 才允许自动下载；`official_online` 只记录官方在线阅读入口；`commercial` 只保存书目信息和出版社页面。课程引用仍应按合理使用原则进行概述，不复制大段受版权保护原文。
