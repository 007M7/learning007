# AI 应用与 Agent 知识库

这份目录服务于 **AI 应用正式学习、AI 进阶和 Agent 前沿** 三个板块，不包含单独维护的 AI 产品经理资料。学习导航采用 19 个正式节点、18 个进阶节点和 10 个前沿章节；来源库进一步按前沿章节内部知识拆分，实际覆盖 67 个稳定节点 ID。

它并不把 AI 应用理解为一组模型 API。书目同时覆盖概率与深度学习、自然语言处理、信息检索、决策与强化学习，也覆盖操作系统、网络、数据库、分布式系统、可靠性与安全工程。后面这些软件层知识决定 Agent 能否被约束、重放、观测、恢复和安全地接入真实系统。
