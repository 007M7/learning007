# 物理 AI 知识库

物理 AI 知识库保存低空智能和机器人的教材、论文、标准、监管材料与实验依据。两个小专题共享感知、估计、规划、控制、学习、仿真和安全，但航空适航与机器人本体知识分别归档。

## 低空智能

- [低空智能证据账本](/fields/low-altitude/evidence)
- [低空智能正式学习](/fields/low-altitude/)

独立来源范围包括飞行器、空域、Remote ID、UTM、适航、运行批准、通信链路和机队运行。
