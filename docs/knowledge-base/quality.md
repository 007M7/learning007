# 质量与生产交付教材、权威手册与核心论文

质量与生产交付并不是“写测试”和“学运维工具”两段互不相干的工作。需求怎样被验收，决定测试需要提供什么证据；构建和制品身份决定发布内容是否可信；可观测性、SLO 与演练又决定系统失败后能否及时发现、止损和恢复。

这份目录以现有 16 个质量核心节点和 18 个交付进阶节点为边界，把稳定方法、工程手册、标准与研究论文放进同一张来源地图。本轮只完成目录建设，尚未撰写教材阅读综述。

```text
需求与风险 → 测试证据 → 可复现构建 → 受控发布 → 观测与恢复 → 生产验收
                               ↓              ↓
                     Kubernetes 与 GitOps → 容量与故障实验 → 容灾与平台治理
```

## 收录边界

- 教材与权威手册必须由作者、大学、标准组织、公共机构或官方项目维护，并能直接阅读正文。
- 论文必须具有开放全文，且直接支撑 34 个节点中的一个或多个判断；标题相关但研究对象漂移的材料不收录。
- 经典材料承担稳定机制，近年论文补充云原生、供应链、可观测性和平台工程的新证据。
- 目录记录只证明来源身份、相关性和入口可用；正式写作仍需逐项记录阅读范围与外推边界。
- 按已确认 SOP，本轮停在目录审阅门。目录通过后才选择第一本教材撰写完整样稿。
