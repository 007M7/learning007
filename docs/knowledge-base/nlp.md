# NLP 教材与核心论文

自然语言处理既研究语言如何被表示和计算，也研究语言系统如何在真实任务中被训练、评价和约束。这份知识库沿 40 个正式学习节点组织材料：从语料、分词与语义表示，推进到 Transformer、预训练与生成，再连接结构化语言分析、多语言、检索问答和事实性评测。

```text
语料与文本单位 → 统计与向量语义 → 神经网络与 Transformer
       ↓                    ↓                    ↓
结构化语言分析       生成 / 翻译 / 语音      检索、事实性与责任
```
