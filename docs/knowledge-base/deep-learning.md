# 深度学习教材与核心论文

深度学习不是一串模型名称。它从表示与梯度开始，经过训练稳定性、视觉与序列结构，进入预训练、后训练、生成建模、多模态、高效推理与安全评测。这份知识库按 40 个正式学习节点反推资料覆盖，保留 18 部能够承担系统教学任务的开放教材，以及 150 篇有直接全文入口的核心论文。

```text
表示与梯度 → 优化与泛化 → 视觉 / 序列结构 → 规模化预训练
     ↓              ↓                  ↓
生成建模      后训练与对齐      多模态 / 高效推理 / 评测安全
```
