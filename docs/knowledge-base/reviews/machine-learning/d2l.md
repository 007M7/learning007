# 动手学深度学习综述

理解一条公式，与让模型在真实代码中稳定训练之间隔着许多细节。张量形状怎样流动，损失如何按批量计算，梯度何时清零，训练与验证模式有什么差别，显存为什么突然耗尽。这些问题只有在运行、观察和修改代码时才会显形。

《Dive into Deep Learning》把教材写成可执行实验。读者先用基础张量实现模型和训练循环，再用深度学习框架的高级接口重写同一方法。两次实现服务于不同目标。第一次暴露机制，第二次建立工程效率。

## 全书用一套重复实验建立能力

```text
定义问题和数据
       ↓
写出数学模型与损失
       ↓
从零实现关键组件
       ↓
用框架接口重写
       ↓
训练、可视化与诊断
       ↓
改变一个因素并解释结果
```

从零实现让读者看到参数、前向计算、损失、梯度和更新之间的连接。框架实现则把这些步骤封装为层、优化器和训练器。两份代码都能运行只是起点。读者还要能够说清框架替自己完成了什么，并在结果异常时拆回基础步骤检查。

## 第一部分先把可执行基础补齐

### 张量是深度学习程序的基本数据结构

标量、向量、矩阵和高维张量统一表示数据与参数。读者需要熟练掌握形状、索引、广播、拼接、归约和内存视图。许多模型错误不会立即报错，广播可能让形状不合理的运算仍然执行，最后得到语义错误结果。

最实用的习惯是在每个新模块记录输入、输出和参数形状。例如图像批量常写成

$$
(batch,channel,height,width)
$$

序列批量可能采用

$$
(batch,time,feature)
$$

框架与模型之间的维度顺序不同，转置位置会直接影响后续计算。

### 自动微分追踪计算图

给定标量损失 $L$，自动微分根据计算图计算每个参数的 $\partial L/\partial\theta$。前向运算建立依赖，反向调用触发梯度传播。

训练循环中常见顺序如下。

1. 读取一个小批量。
2. 计算模型输出与损失。
3. 清除上一轮参数梯度。
4. 执行反向传播。
5. 使用优化器更新参数。

忘记清除梯度会让多批次梯度累积。需要保留图作多次反向时，要理解中间缓存与显存代价。对调试和指标计算使用停止梯度，避免无关计算进入图。

### 概率与统计服务于损失和评价

均值、方差、条件概率和期望贯穿全书。模型训练通常最小化样本损失平均，评价还要考虑抽样波动和数据划分。分类的 softmax 把得分转成概率，交叉熵对应正确类别的负对数似然。

数值实现应使用框架提供的稳定交叉熵，它通常在内部结合 log softmax。先计算 softmax 再取对数，容易出现溢出和下溢。

## 线性模型建立第一个完整训练闭环

### 线性回归从合成数据开始

书中先生成已知参数的合成数据，再实现小批量读取、模型、平方损失和随机梯度下降。因为真实参数已知，读者能判断训练是否恢复了数据生成规律。

从零实现会手工创建权重和偏置、计算矩阵乘法、调用反向传播并更新。框架实现使用线性层、内置损失和优化器。对比两者可以确认层参数、损失归约和更新步长怎样对应公式。

$$
y=Xw+b+\epsilon
$$

这个小例子建立了以后所有监督学习共享的骨架。后续模型主要更换网络结构、损失或数据管道，训练循环的责任基本稳定。

### Softmax 回归建立多分类基线

模型为每个类别输出一个得分，再通过 softmax 得到概率。训练使用交叉熵，预测选择最大概率类别。Fashion MNIST 等数据让读者接触真实批量加载和图像展平。

准确率要在样本维度正确聚合，损失要明确求和还是求平均。训练模式和评价模式需要分开，虽然线性模型差异不大，后续 dropout 和批量归一化会依赖这一切换。

## 多层感知机展示表示能力与过拟合

在线性层之间加入非线性激活，模型能够表达弯曲决策边界。ReLU 计算简单，是书中建立直觉的主要激活。隐藏层宽度、层数和激活共同决定函数族。

### 欠拟合与过拟合要从两条曲线判断

训练误差与验证误差都高，模型可能容量不足、特征不足或优化失败。训练误差很低而验证误差明显高，说明模型在训练样本上适应过强。只看最后一个验证分数无法区分过程。

书中通过多项式回归、权重衰减和 dropout 让读者观察容量与正则的影响。实验应固定数据划分，分别改变一个因素，并保留学习曲线。

### 数值稳定和初始化决定信号能否传播

sigmoid 在大正负输入下饱和，梯度接近零。深层网络还会出现梯度爆炸。初始化需要让各层激活和梯度尺度保持合理。Xavier 与 He 初始化根据层宽调整方差。

这些内容适合做小实验。记录每层激活均值、方差和梯度范数，比记住初始化公式更能建立调试直觉。

## 组件化章节把模型变成可维护程序

模块封装参数和前向计算，顺序容器组合层，参数管理负责初始化、访问、共享与保存。自定义层允许将任意可微计算包装成可复用组件。

延迟初始化在首次看到输入后决定参数形状，使用方便，也会让错误推迟出现。复杂网络应在正式训练前用一批虚拟输入执行前向，打印每层输出并统计参数量。

模型保存需要区分参数状态、优化器状态和完整对象。为了复现实验，应同时保存代码版本、配置、随机种子和数据处理方式。只保存权重文件无法恢复训练环境和评价口径。

## 卷积章节沿架构演进学习视觉偏置

### 从二维相关运算理解局部共享

卷积核在空间位置滑动，相同参数检测不同位置的局部模式。填充控制输出尺寸，步幅控制移动间隔，通道组织多类特征。输出尺寸可以由输入、核、填充和步幅计算，写模型前应手算一次。

池化汇总邻域，降低空间分辨率。最大池化保留强响应，平均池化保留平均信息。它们提供一定位置容忍，也可能损失细节。

### 经典网络展示设计问题怎样被解决

LeNet 建立卷积、池化和全连接的早期组合。AlexNet 展示更深网络、ReLU、dropout、数据增强和 GPU 训练的作用。VGG 用重复的小卷积块获得规整结构。NiN 用逐点卷积在通道间混合并减少全连接依赖。

GoogLeNet 用多分支同时处理不同尺度，残差网络通过恒等捷径让更深模型易于优化。DenseNet 让各层直接接收之前特征，强化特征复用。学习这些架构时，不必背层数，更应记录每一代解决了计算、梯度、尺度还是参数效率问题。

### 批量归一化连接优化与模型状态

批量归一化在训练时使用批量统计并更新移动平均，评价时使用保存的统计量。小批量过小时估计噪声增大，忘记切换评价模式会让预测依赖当前批次。

它改变激活尺度，通常允许更大学习率并降低初始化敏感性。其正则效果与批量噪声有关，不能简单理解为固定的数据标准化。

## 循环网络从文本预测建立序列直觉

### 语言模型预测下一个词元

给定历史词元 $x_1,\ldots,x_t$，语言模型估计

$$
P(x_{t+1}\mid x_1,\ldots,x_t)
$$

序列按时间切成小批量时，可以随机抽取子序列，也可以保持相邻批次的连续状态。两种采样方式决定隐藏状态何时重置和分离计算图。

困惑度是平均负对数似然的指数形式，越低表示模型为真实序列分配的概率越高。它便于比较同一词表和预处理下的模型，不能跨不同分词方案直接比较。

### RNN、GRU 与 LSTM处理记忆

基本 RNN 用上一隐藏状态和当前输入更新状态。长序列反向传播容易梯度消失或爆炸。梯度裁剪限制整体范数，门控结构控制信息保留和遗忘。

GRU 使用更新门和重置门，LSTM 使用输入、遗忘和输出门以及独立记忆单元。双向网络利用两侧上下文，深层循环网络叠加多层表示。选择结构时要考虑延迟、上下文是否完整和训练并行性。

## 注意力与 Transformer 重写信息访问路径

注意力根据查询与键的相似度，对值进行加权汇总。缩放点积注意力为

$$
Attention(Q,K,V)=softmax\left(\frac{QK^T}{\sqrt d}\right)V
$$

多头注意力在多个子空间计算关系，再拼接结果。它允许不同头关注位置、语义或句法关系。头的可视化具有启发性，不能自动视为完整解释。

Transformer 编码器由多头自注意力、前馈网络、残差连接和归一化组成。解码器加入掩码自注意力，避免生成位置看到未来词元，并通过交叉注意力读取编码结果。位置编码补充序列顺序。

相较 RNN，自注意力缩短远距离信息路径并提高训练并行性，标准注意力对序列长度具有平方级内存与计算。今天的大语言模型在规模和训练方法上已经扩展许多，基本 Transformer 数据流仍可由这一章建立。

## 优化章节用实验比较更新规则

书中从梯度下降、随机梯度和小批量开始，进入动量、AdaGrad、RMSProp、Adadelta 和 Adam，再讨论学习率计划。学习重点是理解噪声、曲率和参数尺度怎样影响更新，进而为具体问题选择优化器。

一次可靠优化实验应固定模型、数据顺序、初始化和训练预算，记录训练损失、验证指标、梯度范数与每步耗时。只比较最后精度，会把收敛速度、稳定性和计算成本混在一起。

学习率通常是最敏感参数。过小训练缓慢，过大损失震荡或发散。预热适合训练初期逐步增加步长，衰减让后期在较小邻域收敛。批量大小变化会改变梯度噪声和有效学习率，不能独立调整后直接比较。

## 计算性能章节把代码带到硬件

### 向量化减少解释器与调度开销

用矩阵和批量运算代替 Python 循环，能让底层库利用并行硬件。向量化也可能创建巨大中间张量，速度和内存需要共同测量。

### 异步执行让计时容易失真

GPU 操作可能异步提交。仅测量 Python 调用时间会低估实际计算，需要显式同步。数据加载、主机到设备传输和内核执行可以重叠，性能瓶颈不一定在模型。

### 多 GPU 训练需要通信

数据并行把不同小批量分配到设备，各设备计算梯度后同步聚合。扩展效率受计算通信比、带宽、批量大小和负载平衡影响。设备数翻倍不会保证训练时间减半。

混合精度减少显存并提高吞吐，低精度可能造成下溢，需要损失缩放和稳定算子。性能优化必须同时检查数值和最终指标。

## 应用章节把组件放回真实任务

计算机视觉部分覆盖图像增强、微调、目标检测、锚框、区域卷积、语义分割和神经风格迁移。每项任务都改变输出结构与评价指标。分类输出一个标签，检测需要类别和位置，分割需要像素级结果。

自然语言处理部分从词嵌入进入子词、预训练表示、情感分类、自然语言推断和序列到序列任务。预训练模型将通用语料中的表示迁移到下游任务，微调策略需要考虑数据规模、学习率和遗忘。

在线版还延伸到推荐系统和强化学习等主题。推荐系统要处理隐式反馈、负采样、排序指标和曝光偏差。强化学习中的数据由策略产生，评价不能沿用普通监督学习的静态假设。

## 每节应该怎样做实验

可以为每个学习节点建立四格记录。

| 记录项 | 要写的内容 |
| --- | --- |
| 机制 | 这一层或算法执行了什么计算 |
| 假设 | 它利用了空间、时间、稀疏或共享结构中的哪一种 |
| 证据 | 损失曲线、验证指标、速度和资源使用怎样变化 |
| 失败 | 什么输入、初始化或超参数会让它失效 |

例如学习 dropout，不要只抄定义。先训练无 dropout 基线，再固定其余条件改变比例，比较训练与验证差距，并在评价模式检查输出是否确定。最后解释改善来自什么，过强时又为何欠拟合。

## 从教程代码走向独立实现

### 第一轮复现

运行原始 Notebook，确认环境、数据和预期结果。记录版本和运行时间，不修改多个变量。

### 第二轮删除关键封装

隐藏原实现，独立写出数据读取、模型、损失和训练循环。用小数据过拟合测试检查实现。对自定义操作做形状断言和梯度检查。

### 第三轮做受控修改

更换激活、宽度、优化器或正则强度，每次只改变一个主要因素。保留随机种子重复，报告均值和波动。

### 第四轮迁移数据

把方法应用到一个新的小型数据集。重新定义输入、标签、指标和切分，不能只替换文件路径。数据迁移最能检验是否真正理解了假设。

### 第五轮写实验结论

结论应包含观察、解释和边界。训练更快是观察，较大学习率与归一化改善条件数是解释，只在当前批量和初始化下验证是边界。

## 常见失败方式

| 现象 | 常见原因 | 检查动作 |
| --- | --- | --- |
| 损失不下降 | 标签、损失、学习率或梯度链错误 | 小批量过拟合、打印梯度与输出范围 |
| 训练好而验证差 | 数据少、容量大、增强不足或切分偏差 | 学习曲线、重复切分、正则实验 |
| 指标异常高 | 数据泄漏、重复样本或评价实现错误 | 审计实体、时间与预处理边界 |
| GPU 利用率低 | 数据加载慢、批量小、同步频繁 | 分段计时、增加预取、检查传输 |
| 显存不断增长 | 保留计算图、缓存输出或未停止梯度 | 监控张量引用与反向范围 |
| 复现结果差异大 | 版本、随机性和数据处理不同 | 固定环境、种子和完整配置 |

## 本书最值得保留的判断

- 可执行实验把公式、张量、梯度和评价连成完整学习闭环。
- 从零实现用于理解机制，框架实现用于稳定复用，两者缺一会留下盲区。
- 每种网络结构都在利用特定数据规律，架构选择需要说明归纳偏置。
- 训练曲线能够区分优化问题与泛化问题，单个最终分数做不到。
- 深度学习性能同时受模型、数据管道、数值精度和硬件执行影响。
- 复现只是第一步，受控修改和新数据迁移更能验证掌握。
- 教材代码会随框架更新，数学目标、形状关系和实验原则更稳定。

## 推荐学习路线

零基础读者先完成张量、自动微分、线性回归、softmax 和多层感知机，确保能独立写训练循环。随后学习卷积、经典视觉网络和批量归一化。再进入 RNN、注意力与 Transformer，最后选择视觉、语言或推荐应用。

已有理论基础的读者可以快速完成前五章，把重点放在从零实现、组件封装、优化和性能。工程读者应额外记录数据加载、设备放置、保存恢复与计时方法。每个阶段都保留一个可独立运行的小项目。

## 版本边界

在线教材持续更新，PDF、网页和不同语言版本的章节可能不同。多框架代码覆盖也会变化。学习时应记录访问日期、框架与依赖版本，避免把接口差异误认为算法差异。

书中示例为教学压缩了数据治理、部署监控、安全和团队协作。能够训练模型后，还需补软件测试、数据版本、实验追踪、服务性能与上线评价。教程中的高分不能直接代表生产可用。
