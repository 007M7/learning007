# 几何深度学习阅读综述

同一张图像平移几个像素，分类结果通常不该改变；分子旋转以后，化学性质也不该凭空改变；知识图谱更换节点编号，关系预测仍应保持一致。模型如果靠数据重新学习这些常识，会浪费样本，也可能在训练集之外做出荒唐判断。几何深度学习研究怎样把这类对称性直接写进模型。

本书用对称群、不变性、等变性、局部性与尺度分离建立统一蓝图，再把蓝图落到网格、图、齐性空间和几何图。它能解释 CNN 与 GNN 为什么相似，也能指出二者依赖的域结构哪里不同。

## 先从任务允许哪些变化问起

这一节先处理几何域上的同一对象可以有多种坐标或编号表示，任务结果应遵守确定的变换规律。概念落到模型里，需要同时说明输入怎样表示、输出受什么约束，以及结果怎样被检查。

作者把域、信号和群作用分开，使数据变化与目标变化都有明确位置。书中的推导服务于这个关系，公式负责保留条件，例子负责展示条件变化后的结果。

知识图谱节点重编号后，检索和推理不应改变；界面截图平移后，控件识别也应稳定。工程上至少要留下输入样本、运行轨迹和结果证据，才能知道改动是否真的有效。

只看数据维度会把不同结构混在一起，向量、序列、网格和图拥有不同的合法变换。读者若能说清这条边界，就已经抓住本节对系统判断最有用的部分。

## 不变性与等变性承担不同任务

不变性与等变性承担不同任务决定后续方法能否站稳。不变输出在输入变换后保持相同，等变输出按照可预测规则一起变化。读者应先把这里的假设写清，再进入公式或代码。

分类常需要不变性，分割和坐标预测更需要等变性，书中用群表示统一两者。阅读时可以沿着数据、表示、目标和计算过程重画一遍，概念会比孤立记定义更牢。

Agent 感知模块要先判断输出是一个标签、位置还是结构，再选择对应约束。它给出的首先是一种判断方法，具体实现仍要受延迟、成本、权限和数据可得性约束。

把所有变化都压成不变会丢失位置，要求错误的等变关系也会限制模型表达能力。出现异常时，应回到本节的对象与假设排查，继续更换模型通常不能消除定义上的错误。

进入实际项目时，可以先做一个最小对照。保留旧方法作为基线，只引入本节讨论的变化，并记录它对正确性、稳定性和运行代价的影响。Agent 感知模块要先判断输出是一个标签、位置还是结构，再选择对应约束。

## 局部性让模型在大空间中复用规则

作者在这里关注现实交互通常先受邻近对象影响，局部算子可以在不同位置共享。这一步把一个宽泛问题缩成能够训练、推断或验证的对象。

几何先验把局部处理、参数共享、层级结构和任务对称性组合起来。前后章节的连接也在这里形成，上一章提供表示，本章说明怎样利用，下一章再处理它留下的限制。

图检索可以先聚合相邻实体，再逐层扩大关系范围，避免一次查看整张图。把它放进 AI 应用评审时，还应写出负责组件、可观察指标和失败后的接管方式。

层数增加会带来过度平滑和远程信息损失，局部性需要和长程连接共同设计。这种错误常在离线样本里不明显，进入新分布或长任务以后才集中暴露。

## 群与表示把直觉变成可检验条件

理解这一部分，可以从一个具体判断开始。群描述可组合且可逆的变换，表示说明这些变换怎样作用在特征空间。条件改变以后，原有算法的结论也会跟着改变。

书中用群卷积解释经典卷积，也讨论旋转、反射与更一般齐性空间。这种安排让方法的适用条件显形，也让不同模型能够在同一问题上比较。

当团队声称模型具备旋转等变或置换等变时，可以检查算子是否真的满足关系。这项迁移要求保留原书的假设，不能因为换成大语言模型就省略环境状态与评价标准。

数据增强只能提供有限样本，不能自动给出严格等变保证。因此，本节知识最终应整理成一条可以复查的设计约束，而不只是一个术语。

读者还应检查概念的测量方式。训练指标、离线任务和真实运行各能看见一部分现象，三者的口径若不一致，数据增强只能提供有限样本，不能自动给出严格等变保证。这时要先修正证据链。

## 图上的第一难题是没有天然顺序

图上的第一难题是没有天然顺序决定后续方法能否站稳。一个节点的邻居集合可以任意排列，聚合函数必须对排列保持稳定。读者应先把这里的假设写清，再进入公式或代码。

消息传递网络反复执行邻居消息、聚合和节点更新，读出函数再形成图级表示。阅读时可以沿着数据、表示、目标和计算过程重画一遍，概念会比孤立记定义更牢。

作者在这里关注谱方法借助图拉普拉斯的特征结构定义滤波，空间方法直接在邻域交换消息。这一步把一个宽泛问题缩成能够训练、推断或验证的对象。

## 几何图同时拥有关系与坐标

理解这一部分，可以从一个具体判断开始。分子、点云和机器人场景既有邻接关系，也有欧氏空间中的方向和距离。条件改变以后，原有算法的结论也会跟着改变。

模型需要对旋转、平移等变，并让标量、向量等不同类型特征遵守各自变换。这种安排让方法的适用条件显形，也让不同模型能够在同一问题上比较。

物理 Agent 的感知和控制若忽略坐标变换，换视角后可能输出不一致动作。这项迁移要求保留原书的假设，不能因为换成大语言模型就省略环境状态与评价标准。

把坐标直接拼进普通 GNN 会破坏所需对称性，特征类型必须明确。因此，本节知识最终应整理成一条可以复查的设计约束，而不只是一个术语。

## 放进 AI 应用与 Agent 学习路线

这本书在路线中连接“任务的对称性”与“几何图与新模型”。前者帮助读者定义系统正在处理的对象，后者把知识带到真正的结果和边界。读者可以选一个正在做的系统，把中间章节逐项映射到模型、数据、工具、运行时和评价证据。映射到却没有负责人和指标的地方，通常就是设计缺口。

阅读笔记可以专门留两栏。左栏跟踪“群作用”等原书概念的对象与假设，右栏写本地系统里的对应组件。读到“局部算子”以后，再补一条这项知识改变了哪个选择。这样做能阻止术语堆积，也会让后续论文有稳定位置。

## 本书没有替你完成的工作

《Geometric Deep Learning》提供了从“先从任务允许哪些变化问起”开始的问题框架，但它不知道你的数据分布、用户任务、权限制度和事故成本。团队仍需用本地样本与对照实验验证“几何先验是一份模型选择清单”在项目里是否成立，并从运行轨迹和外部结果中检查失败方式。

当前综述依据的版本为原型专著 2021，正式书稿持续更新。阅读作者维护的书稿、课程讲义与章节说明时，读者应在笔记中保存访问日期和章节标题。开放正文若调整“局部算子”相关内容，可以直接比较定义与判断是否改变，不必凭页面更新时间重写全部结论。

## 推荐阅读方法

第一次沿“任务的对称性”到“局部算子”阅读，只处理定义、关键图和章末总结。第二次带着一个真实系统进入“几何图与新模型”，检查输入表示、计算限制与验证方式。准备实现“不变性与等变性承担不同任务”时，再回到推导、代码和习题。三次阅读各有任务，一次读透往往会被局部细节拖住。

读完以后，围绕本书完成三项自测。

1. 用普通语言说明“先从任务允许哪些变化问起”处理什么。
2. 指出“不变性与等变性承担不同任务”成立的条件。
3. 给“几何先验是一份模型选择清单”写出一个失败反例。

随后把其中一项变成系统检查。答案具体到对象和证据，这本书才开始进入判断。
