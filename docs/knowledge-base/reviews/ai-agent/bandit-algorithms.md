# 多臂老虎机算法阅读综述

推荐一个候选以后，系统只看见被选项的反馈，没有看见其他候选当时会得到什么结果。继续选择熟悉方案能保持收益，尝试新方案才可能发现更好选择。Bandit Algorithms 用遗憾把这笔机会成本写清，并给出不同环境下的可证明策略。

教材从随机老虎机进入信息论下界、贝叶斯方法、对抗老虎机、线性与上下文老虎机、组合问题、排序、无限臂和部分监控。理论界限与算法设计紧密相连。

## 老虎机只观察被选动作的奖励

这一节先处理缺失的反事实反馈构成学习困难。概念落到模型里，需要同时说明输入怎样表示、输出受什么约束，以及结果怎样被检查。

策略根据历史逐轮选臂。书中的推导服务于这个关系，公式负责保留条件，例子负责展示条件变化后的结果。

在线 Agent 实验要保存当时可选集合和选择概率。工程上至少要留下输入样本、运行轨迹和结果证据，才能知道改动是否真的有效。

只记录被选结果无法直接比较未选方案。读者若能说清这条边界，就已经抓住本节对系统判断最有用的部分。

把本节变成练习，可以固定一份输入，逐项改变缺失的反事实反馈构成学习困难中的一个条件，随后比较结果、资源消耗和错误类型。策略根据历史逐轮选臂，所以观察项也应沿着同一关系设置。

产品实验可估算探索成本。它给出的首先是一种判断方法，具体实现仍要受延迟、成本、权限和数据可得性约束。

## Thompson Sampling 按后验抽样

## 放进 AI 应用与 Agent 学习路线

这本书在路线中连接“随机老虎机”与“结构化反馈与边界”。前者帮助读者定义系统正在处理的对象，后者把知识带到真正的结果和边界。读者可以选一个正在做的系统，把中间章节逐项映射到模型、数据、工具、运行时和评价证据。映射到却没有负责人和指标的地方，通常就是设计缺口。

阅读笔记可以专门留两栏。左栏跟踪“累积遗憾”等原书概念的对象与假设，右栏写本地系统里的对应组件。读到“贝叶斯与对抗环境”以后，再补一条这项知识改变了哪个选择。这样做能阻止术语堆积，也会让后续论文有稳定位置。

## 本书没有替你完成的工作

《Bandit Algorithms》提供了从“老虎机只观察被选动作的奖励”开始的问题框架，但它不知道你的数据分布、用户任务、权限制度和事故成本。团队仍需用本地样本与对照实验验证“部分监控划出反馈不足的极限”在项目里是否成立，并从运行轨迹和外部结果中检查失败方式。

当前综述依据的版本为2020。阅读作者公开的完整 PDF时，读者应在笔记中保存访问日期和章节标题。开放正文若调整“贝叶斯与对抗环境”相关内容，可以直接比较定义与判断是否改变，不必凭页面更新时间重写全部结论。

## 推荐阅读方法

第一次沿“随机老虎机”到“贝叶斯与对抗环境”阅读，只处理定义、关键图和章末总结。第二次带着一个真实系统进入“结构化反馈与边界”，检查输入表示、计算限制与验证方式。准备实现“遗憾衡量错过最佳策略的累计损失”时，再回到推导、代码和习题。三次阅读各有任务，一次读透往往会被局部细节拖住。
