# 规划算法阅读综述

规划经常被缩成让模型列出步骤。LaValle 研究的规划更严格。系统要知道状态空间、可用动作、障碍、目标和动力学，算法才可能判断一条路径能否真正执行。书中从有限图搜索一直走到受微分约束的机器人运动。

全书四部分覆盖离散规划、运动规划、决策不确定性和微分约束。配置空间、采样规划、反馈策略、博弈与控制理论共同说明计划怎样受环境结构限制。

## 规划问题先定义状态与动作

这一节先处理状态概括未来决策所需信息，动作规定合法转移。概念落到模型里，需要同时说明输入怎样表示、输出受什么约束，以及结果怎样被检查。

离散搜索用图统一多类问题。书中的推导服务于这个关系，公式负责保留条件，例子负责展示条件变化后的结果。

工具 Agent 要把前置条件与副作用写入动作契约。工程上至少要留下输入样本、运行轨迹和结果证据，才能知道改动是否真的有效。

只列动词步骤会遗漏执行条件。读者若能说清这条边界，就已经抓住本节对系统判断最有用的部分。

把本节变成练习，可以固定一份输入，逐项改变状态概括未来决策所需信息，动作规定合法转移中的一个条件，随后比较结果、资源消耗和错误类型。离散搜索用图统一多类问题，所以观察项也应沿着同一关系设置。

## 搜索算法依赖候选展开顺序

搜索算法依赖候选展开顺序决定后续方法能否站稳。广度、深度、代价和启发式搜索使用不同队列规则。读者应先把这里的假设写清，再进入公式或代码。

完备性与最优性在明确条件下成立。阅读时可以沿着数据、表示、目标和计算过程重画一遍，概念会比孤立记定义更牢。

任务规划器应记录搜索预算和启发函数。它给出的首先是一种判断方法，具体实现仍要受延迟、成本、权限和数据可得性约束。

模型给出的优先级可能误导搜索。出现异常时，应回到本节的对象与假设排查，继续更换模型通常不能消除定义上的错误。

真正应用时，可以先做一个最小对照。保留旧方法作为基线，只引入本节讨论的变化，并记录它对正确性、稳定性和运行代价的影响。任务规划器应记录搜索预算和启发函数。

## 配置空间把物体运动转成点的运动

作者在这里关注机器人姿态成为高维点，碰撞区域成为空间障碍。这一步把一个宽泛问题缩成能够训练、推断或验证的对象。

拓扑与几何描述自由空间。前后章节的连接也在这里形成，上一章提供表示，本章说明怎样利用，下一章再处理它留下的限制。

界面操作也可定义控件状态和合法区域。把它放进 AI 应用评审时，还应写出负责组件、可观察指标和失败后的接管方式。

状态变量选得不全会让路径在现实中不可执行。这种错误常在离线样本里不明显，进入新分布或长任务以后才集中暴露。

本节适合沉淀成设计记录。记录中写明采用这项方法的理由、被舍弃的方案、成立条件和回退办法。状态变量选得不全会让路径在现实中不可执行，这些信息能让后续维护者知道何时应重新评估。

## 采样规划避免完整离散化空间

理解这一部分，可以从一个具体判断开始。算法随机探索自由区域并逐步连接可行路径。条件改变以后，原有算法的结论也会跟着改变。

PRM 与 RRT 服务于多查询和单查询情形。这种安排让方法的适用条件显形，也让不同模型能够在同一问题上比较。

巨大工具状态空间可借候选采样减少展开。这项迁移要求保留原书的假设，不能因为换成大语言模型就省略环境状态与评价标准。

概率完备不代表有限时间必然找到答案。因此，本节知识最终应沉淀成一条可以复查的设计约束，而不只是一个术语。

读者还应检查概念的测量方式。训练指标、离线任务和真实运行各能看见一部分现象，三者的口径若不一致，概率完备不代表有限时间必然找到答案。这时要先修正证据链。

## 放进 AI 应用与 Agent 学习路线

这本书在路线中连接“离散状态搜索”与“动力学和反馈控制”。前者帮助读者定义系统正在处理的对象，后者把知识带到真正的结果和边界。读者可以选一个正在做的系统，把中间章节逐项映射到模型、数据、工具、运行时和评价证据。映射到却没有负责人和指标的地方，通常就是设计缺口。

阅读笔记可以专门留两栏。左栏跟踪“配置空间”等原书概念的对象与假设，右栏写本地系统里的对应组件。读到“采样运动规划”以后，再补一条这项知识改变了哪个选择。这样做能阻止术语堆积，也会让后续论文有稳定位置。

## 本书没有替你完成的工作

《Planning Algorithms》提供了从“规划问题先定义状态与动作”开始的问题框架，但它不知道你的数据分布、用户任务、权限制度和事故成本。团队仍需用本地样本与对照实验验证“完备性概念说明算法保证到哪里”在项目里是否成立，并从运行轨迹和外部结果中检查失败方式。

当前综述依据的版本为2006。阅读作者公开的完整 PDF时，读者应在笔记中保存访问日期和章节标题。开放正文若调整“采样运动规划”相关内容，可以直接比较定义与判断是否改变，不必凭页面更新时间重写全部结论。

## 推荐阅读方法

第一次沿“离散状态搜索”到“采样运动规划”阅读，只处理定义、关键图和章末总结。第二次带着一个真实系统进入“动力学和反馈控制”，检查输入表示、计算限制与验证方式。准备实现“搜索算法依赖候选展开顺序”时，再回到推导、代码和习题。三次阅读各有任务，一次读透往往会被局部细节拖住。
