# Python 自然语言处理阅读综述

大模型接口让文本生成变得容易，也让许多人跳过了文本怎样进入系统。文件编码、分词、词性、语料许可、标注一致性和数据格式仍在决定结果。NLTK 教材让读者亲手处理这些材料，看见语言数据从原始字符变成可计算对象的每一步。

全书从 Python 与语料探索开始，推进到原始文本处理、程序结构、词性标注、分类、信息抽取、句法、特征语法、语义和语言数据管理。它以可运行代码把语言学与计算连接起来。

[阅读 NLTK 官方完整在线教材](https://www.nltk.org/book/){target="_blank" rel="noopener noreferrer"}
