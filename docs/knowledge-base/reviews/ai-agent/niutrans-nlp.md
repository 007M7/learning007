# 自然语言处理神经网络与大语言模型阅读综述

传统 NLP 教材常按分词、标注、翻译等任务排列，LLM 教程又从提示词和接口开始。两条路线之间缺少模型怎样建立、训练和部署的连续过程。这本新教材按构造神经语言系统的顺序组织内容，适合补上中间断层。

全书由机器学习与神经网络基础、神经 NLP 方法、大语言模型三部分组成。重点覆盖表示、序列建模、Transformer、预训练、长上下文、Prompt、对齐、推理与部署，知识时间点比经典 NLP 教材新。
