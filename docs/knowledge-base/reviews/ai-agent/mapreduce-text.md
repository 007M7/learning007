# 用 MapReduce 处理数据密集型文本阅读综述

知识库扩大以后，文本清洗、统计、索引和图计算无法一直靠单机脚本。任务必须切开，数据需要移动，中间结果要排序，失败的工作还得重跑。MapReduce 已经不是今天唯一的计算框架，但它把这些代价暴露得很清楚。

本书先讲 MapReduce 执行模型和算法设计，再处理文本共现、倒排索引、图算法与机器学习，最后讨论它不适合的在线学习和全局状态问题。

键的设计决定数据在哪里相遇决定后续方法能否站稳。拥有同一键的中间记录会进入同一归约组。读者应先把这里的假设写清，再进入公式或代码。
