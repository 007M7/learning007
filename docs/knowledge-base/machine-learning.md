# 机器学习知识库

这份目录保存机器学习教材综述、可以直接阅读的教材原文和论文全文。教材综述负责快速讲清全书的问题、知识路线与适用边界，原文保留独立入口；论文用于追溯关键方法、证据与工程判断。

它不是“从第一条读到最后一条”的书单。先选择当前学习模块，再根据自己的阶段使用资源：**入门教材建立地图，核心教材形成体系，进阶论文解决具体问题**。

::: info 收录状态
页面中的“已核验”表示原文链接无需登录即可直接打开书籍正文或论文全文。点击教材卡片的“阅读综述”会进入站内中文综述，“查看原文”仍然直达权威正文。购买页、登录页、课程介绍页和只有摘要的 DOI 页面不收录。知识库没有下载原文；某项资料真正进入学习文章前，还需要记录实际阅读范围、采用观点和不能推出的结论。
:::
