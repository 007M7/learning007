# 学习资源知识库

这里不是一份不断堆链接的收藏夹，而是学习文章的上游原文目录。我们先建立学科结构，判断每一类知识应当由什么教材和论文支撑，再用检索工具核验作者、大学、出版社、会议或标准机构维护的全文入口。

## 一条资源怎样进入知识库

```text
学科模块与学习目标
        ↓
确定应当检索的教材与核心论文
        ↓
核对无需登录即可阅读的 PDF 或在线正文
        ↓
保存保真 URL、用途、难度、模块与核验日期
        ↓
写作前另行取得原稿，记录实际阅读范围和采用观点
```

这套流程刻意区分三种状态：**值得学习**不等于**已经阅读**，**全文链接已核验**也不等于**论文结论已被采用**。当前知识库只保存直接阅读入口，不下载、不镜像，也不保存书籍或论文原文。

## 已建立的模块

### [机器学习：教材原文与核心论文](/knowledge-base/machine-learning)

以六个知识子模块组织资源，首批包含 13 本可直接阅读的权威教材与 118 篇核心论文。你可以按学习阶段、资源类型和主题筛选，而不是从一张没有顺序的书单开始。

## 后续扩展

深度学习、NLP、AI 产品经理、物理 AI 和软件工程会沿用同一数据契约：只保存可直接阅读的权威原文，不把购买页、登录页或课程宣传页当成学习素材。

每个新模块都必须先回答三个问题：它覆盖哪条知识主线、资源为什么权威、学习者应在什么时候使用它。只有能回答清楚，才进入正式目录。
