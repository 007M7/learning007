# 软件与系统工程教材、权威手册与核心论文

软件工程课程容易分成两套互不相干的内容。一套教语言、数据结构、操作系统、网络和数据库，另一套直接讨论性能、分布式共识、可观测性和架构演进。真实系统会同时遇到两套问题。服务延迟可能来自算法、内存、运行时、网络、数据库或跨节点协调；架构决定也会反过来改变测试、部署和团队协作。

本知识库把正式学习与软件进阶放进同一张来源地图。十二个模块既保留必要前置，也标出进入进阶主题的位置。教材帮助建立完整模型，论文负责呈现一个机制怎样被提出、验证、质疑和改进。

```text
程序与数据结构 → 语言和运行时 → 操作系统与并发 → 网络与数据库
       ↓                ↓                 ↓                ↓
   设计与架构   →   测试与验证   →   性能与可观测性   →   分布式系统
                                                          ↓
                              可靠性与安全 ← 存储和流处理 → 架构演进
```

## 收录边界

- 教材和手册必须由作者、大学、标准组织或官方项目维护，并能直接阅读正文。
- 每份教材或手册都配有独立中文阅读综述，原文入口单独保留。
- 论文从权威课程阅读清单和主题化经典论文库中筛选，只收录可直接打开的全文。
- 模块数量用于检查覆盖，不用引用量或热度代替课程相关性。
- 目录记录 URL 核验状态。正式课程引用仍需记录具体阅读范围和适用边界。
