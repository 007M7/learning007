## 两份证据把“SFT：用示范重塑条件行为”的边界画在哪里

### Direct Preference Optimization（2023-05-29）

这项工作追问：能否不用显式奖励模型和在线 RL 直接优化偏好？

DPO 从 KL 约束奖励最优策略与 Bradley–Terry 偏好概率关系推导封闭目标，用 chosen/rejected 对训练策略。 论文在摘要、对话等任务报告与 PPO 类方法竞争且训练简单稳定。

本章据此采用的判断是：**贡献是降低偏好对齐工程复杂度并形成广泛基线。** 但不能外推到：离线偏好覆盖、reference 和超参会限制效果；DPO 不自动解决标签偏差或分布外过优化。

### DeepSeek-R1（2025-01-22）

本章用它校准“SFT：用示范重塑条件行为”的边界：贡献是提供可验证奖励驱动 reasoning 的大规模证据与训练配方。。**不要越过的边界：**厂商自报且依赖具体数据/奖励/预算；基准表现不能证明忠实思维过程或开放任务通用性。

两份来源若结论看似冲突，先比较任务定义、数据分布、资源预算和评价方法；不能只用发布日期或排行榜高低裁决。

## 当 监督指令微调 失效，先查哪里

先排除这些看似合理的误解：SFT 会增加所有知识；DPO 不需要任何奖励假设；RL 奖励上升等于推理更真实；chain-of-thought 是忠实解释；后训练只影响风格。

### 把偏好等同真理

先查看 **任务质量**：主指标、切片、置信区间与失败样本。如果证据确认失败，回到“每类后训练数据记录来源、标注政策与版本”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

### 用同一 Judge 生成、训练和验收

先查看 **推理**：首 Token、每 Token、P50/P95、吞吐、峰值内存。如果证据确认失败，回到“奖励与 Judge 需红队并保留确定验证器”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

本章的边界不是一句“视情况而定”，而是能写进测试、监测或人工审核条件的触发器。

## 把“SFT：用示范重塑条件行为”迁移到新条件

围绕“SFT：用示范重塑条件行为”完成如下变式：设计一个偏好数据偏爱长答案的实验，观察 DPO 后长度与真实正确率；再通过长度匹配、独立 rubric 或约束修正，解释哪个指标被投机。

提交“SFT 数据配方与行为回归”时同时附上：

1. 一个成功样本和一个失败样本；
2. 失败推翻了哪条假设，而不只是报错信息；
3. 哪项结论来自公开来源，哪项只来自你的本地实验；
4. 如果换数据、人群、环境或本体，最先需要重测什么；
5. 当前仍无法消除的残余风险。
