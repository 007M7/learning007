## 把问题放回完整系统

> 增加参数、数据与计算时，收益和风险分别如何缩放？

参数量、训练 Token 和 FLOPs 经常被混为“规模”。重复低质量数据会降低有效信息，数据污染又让基准分数失真。技术报告中的 GPU 小时受芯片、利用率、精度和并行策略影响，不能直接横比。缩放拟合若跨越架构/数据制度变化，外推可能失败。

|---|---|---|---|
| DLF13 · 缩放律 | 在给定范式内拟合损失随模型、数据和计算的规律 | 如何分配有限预训练预算 | 参数越多必然更强 |
| DLF14 · 数据混合 | 质量、重复、领域和顺序共同塑造能力 | 收集、过滤、重采样和权利边界 | Chinchilla 比例是永久常数 |
| DLF15 · 训练系统 | 并行、精度、通信和容错决定可实现算力 | 理论方案是否能稳定跑完 | token 是统一信息单位 |

## 计算最优分配与数据—系统协同

经验缩放律在固定范式下拟合 loss 随参数 $N$、数据 $D$ 或计算 $C$ 的幂律；Chinchilla 结论强调给定计算下模型与数据应共同扩展。数据管道进行语言/领域配比、质量过滤、去重、污染检测和权利治理。系统用数据/张量/流水线/专家并行与低精度提高利用率，但通信、负载不均和故障会改变有效计算。

~~~~mermaid
flowchart LR
  B[能力/预算目标] --> S[小规模 scaling runs]
  S --> N[参数/数据/计算分配]
  N --> D[数据混合/去重/权利]
  N --> Y[并行/精度/容错]
  D --> T[预训练]
  Y --> T
  T --> E[loss+下游+污染评测]
  E --> R[是否扩展/调整制度]
~~~~

## 从这里看完整闭环：训练一个 1B 中文领域模型

预算不是先定 1B 参数再塞数据，而是用 50M/100M/300M 小模型在多个 token 配比做 pilot，拟合 loss 与下游任务；对领域数据去重并保留文档级时间切分。报告 tokenizer 后 token、有效样本、FLOPs、GPU 利用率和碳/费用。若领域 SFT/RAG 已达到目标，不因缩放曲线漂亮就启动全量预训练。

### 读案例时做三次停顿

1. 到 缩放律 时停一次：如何分配有限预训练预算？
2. 到 数据混合 时再停一次：哪条数据流、状态变化或约束能证明机制真的发生？
3. 到 训练系统 时最后停一次：如果出现“跨 tokenizer 直接比较 token 数”，系统应继续、拒绝还是交给人？

## 哪些量必须持续被测量

常见经验形式：

$$
L(N,D)\approx L_\infty + A N^{-\alpha}+B D^{-\beta},
\qquad C\approx 6ND
$$

（常数与指数依实现和定义）。计算最优选择是在约束 $C$ 下最小化估计损失，而不是单独最大化 $N$。

把每个符号放回真实系统。下面任何一项说不清，计算正确也不能保证结论正确：

- 幂律只在观测尺度和固定数据/架构制度内可信
- token 不是跨 tokenizer 完全可比的数据单位
- $6ND$ 是粗略 dense Transformer 训练估计
- 下游能力、安全和涌现不能由预训练 loss 唯一决定

## 真实系统为什么比一次演示更难

这些来源分别照亮闭环中的一段；拼在一起时，仍要保留各自的适用范围。

### Training Compute-Optimal Large Language Models（2022-03-29）

**它追问什么：**固定训练计算时，模型大小与训练 token 应怎样配置？

**方法和结果：**Chinchilla 通过大量小规模训练拟合参数/数据缩放，提出当时许多大模型训练不足，并训练 70B 参数、1.4T token 模型对照。 论文报告 Chinchilla 以更小参数在多个任务超过更大 Gopher，同时推理更便宜。

**它改变的判断：**贡献是把数据量重新放回计算最优配比。

> **不要越过这条边界：**指数依数据质量、架构和训练制度；现代重复训练、MoE 与后训练不能简单套用。

### The Llama 3 Herd of Models（2024-07-23）

**它追问什么：**开源权重级别的现代基础模型如何组织数据、规模、后训练和安全评测？

**方法和结果：**报告描述最高 405B dense 模型、15T+ token 预训练、多语言/代码数据、扩展上下文及 SFT/偏好优化流程。 作者跨知识、推理、代码、多语言和人工偏好给出广泛评测。

**它改变的判断：**贡献是相对完整地公开模型族训练与后训练设计。

> **不要越过这条边界：**训练数据细节和基础设施仍不完全开放，厂商自评与公开 benchmark 存在污染/选择风险。

### DeepSeek-V3（2024-12-27）

**它追问什么：**稀疏 MoE、MLA 和低精度系统怎样改变训练/推理资源分配？

**方法和结果：**671B 总参数、37B 激活参数模型在 14.8T token 上训练，结合专家路由、MLA 和 FP8 系统设计。 报告给出 2.788M H800 GPU 小时和广泛评测，显示稀疏激活的成本路径。

**它改变的判断：**贡献是算法/系统联合的开放技术报告。

> **不要越过这条边界：**硬件、软件与计费口径特定，且总参数、激活参数与能力不可线性换算。

## 把运行方式写成可恢复的流程：拟合一个会失败的缩放律

### 第 1 步：训练至少三个参数规模和三个数据量组合

- **这一步在验证：**缩放律能否支持“如何分配有限预训练预算”这项判断。
- **至少留下：**主指标、切片、置信区间与失败样本。
- **先停下来而不是继续调参的信号：**跨 tokenizer 直接比较 token 数。

### 第 2 步：拟合幂律并保留未参与拟合的点验证

- **这一步在验证：**数据混合能否支持“收集、过滤、重采样和权利边界”这项判断。
- **至少留下：**loss、梯度/激活、吞吐、显存、数据量、FLOPs。
- **先停下来而不是继续调参的信号：**用 GPU 小时代替 FLOPs/费用。

### 第 3 步：对数据去重前后比较 memorization 与下游

- **这一步在验证：**训练系统能否支持“理论方案是否能稳定跑完”这项判断。
- **至少留下：**首 Token、每 Token、P50/P95、吞吐、峰值内存。
- **先停下来而不是继续调参的信号：**在少量尺度上过度外推。

### 第 4 步：将 GPU 小时换算为硬件、精度、利用率和估计 FLOPs

- **这一步在验证：**缩放律能否支持“如何分配有限预训练预算”这项判断。
- **至少留下：**校准、偏移、攻击、记忆/污染与能耗。
- **先停下来而不是继续调参的信号：**重复数据制造表面 loss 收益。

## 哪些改变应沉淀为长期资产

### 1. 扩展前必须用 pilot 预测并设停止阈值

验收时查看 **任务质量**，至少保存主指标、切片、置信区间与失败样本。如果观察到“跨 tokenizer 直接比较 token 数”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 2. 数据账本记录来源、许可、语言/领域和去重

验收时查看 **训练**，至少保存loss、梯度/激活、吞吐、显存、数据量、FLOPs。如果观察到“用 GPU 小时代替 FLOPs/费用”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 3. benchmark 污染检查在评测前冻结

验收时查看 **推理**，至少保存首 Token、每 Token、P50/P95、吞吐、峰值内存。如果观察到“在少量尺度上过度外推”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 4. 训练成本和下游/安全收益同表决策

验收时查看 **风险**，至少保存校准、偏移、攻击、记忆/污染与能耗。如果观察到“重复数据制造表面 loss 收益”，这项决定必须重新评审，不能因为已经实现就默认保留。

## 系统最可能在哪些接缝处失效

先排除这些误解：参数越多必然更强；Chinchilla 比例是永久常数；token 是统一信息单位；GPU 小时可跨硬件直接比；更多数据不需要权利和重复审计。

### 跨 tokenizer 直接比较 token 数

- **先看什么：**主指标、切片、置信区间与失败样本
- **回到哪项控制：**扩展前必须用 pilot 预测并设停止阈值
- **怎样留下证据：**保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“拟合一个会失败的缩放律”的回归记录。

### 用 GPU 小时代替 FLOPs/费用

- **先看什么：**loss、梯度/激活、吞吐、显存、数据量、FLOPs
- **回到哪项控制：**数据账本记录来源、许可、语言/领域和去重
- **怎样留下证据：**保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“拟合一个会失败的缩放律”的回归记录。

### 在少量尺度上过度外推

- **先看什么：**首 Token、每 Token、P50/P95、吞吐、峰值内存
- **回到哪项控制：**benchmark 污染检查在评测前冻结
- **怎样留下证据：**保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“拟合一个会失败的缩放律”的回归记录。

### 重复数据制造表面 loss 收益

- **先看什么：**校准、偏移、攻击、记忆/污染与能耗
- **回到哪项控制：**训练成本和下游/安全收益同表决策
- **怎样留下证据：**保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“拟合一个会失败的缩放律”的回归记录。

### 把预训练 loss 当所有能力代理

- **先看什么：**主指标、切片、置信区间与失败样本
- **回到哪项控制：**扩展前必须用 pilot 预测并设停止阈值
- **怎样留下证据：**保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“拟合一个会失败的缩放律”的回归记录。

## 最后的迁移任务：拟合一个会失败的缩放律

用小规模运行拟合幂律，再故意在最大点改变数据质量或架构，观察外推残差；解释制度变化为何使旧曲线失效。

提交时一并回答：

- 你能否不看正文解释计算最优缩放与单纯放大参数的区别；
- 产物是否真的包含一份含 pilot 外部验证的训练预算；
- 哪个失败样本暴露了幂律跨制度外推失效的原因；
- 如果换一个数据、人群、环境或本体，最先需要重测哪项指标。

提交物不能只有成功截图。附上一个失败样本，并说明它推翻了什么假设、哪些残余风险还不能消除。

## 本章小结

- 缩放律是局部经验预算模型
- 参数、数据和计算需联合分配
- 数据质量/权利与系统利用率决定有效规模
- 任何制度变化都需重新校准外推
