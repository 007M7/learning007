## 八份材料合起来才是一项训练证据

字符分类器最初只有几行能运行的代码。第一章没有急着训练，它先给 `[B,C,H,W]` 的每个轴命名，区分形状、步幅、类型与设备，并用 `[B,1]` 对 `[B]` 的失败样本拦住静默广播。

有了张量契约，第二章才能把一次前向执行画成计算图。图上记录每个值由谁产生、被谁使用，数据损失与权重惩罚在哪里分叉和汇合，哪些参数从 loss 可达。第三章沿这张图逆向手算，让一条路径上的局部导数相乘，让多条路径的贡献相加，再用 VJP 解释反向模式为何适合大量参数和标量损失。

手算只覆盖一张很小的图。第四章加入中心差分、随机方向和结构不变量。数值差分检查程序导数，张量不变量检查程序有没有表达预期任务。两类证据分开以后，“梯度检查通过”才不会被误写成“整个模型正确”。

前四章回答程序算了什么。后四章回答它能不能稳定学习。

第五章把同一网络逐步加深，在训练以前观察激活与梯度怎样传播。Xavier 和 He 初始化提供有假设的尺度起点，逐层统计再判断真实网络是否符合近似。第六章固定初始化与数据，让 SGD、动量、Adam 和 AdamW 获得相同搜索机会与训练预算，参数轨迹、验证结果和资源共同决定选择。

第七章继续固定优化器，只改变归一化与残差。BatchNorm 与 LayerNorm 统计的轴、train 与 eval 的状态、恒等支路的短梯度路径都被单独验证。第八章把这些正常基线带进一次 Loss Spike 调查。故障 batch、checkpoint、随机状态、精度状态与 rank 日志共同组成现场，重放和单变量对照负责找到根因。

八章的依赖可以压成下面这条线。

```text
任务里的张量对象
      │
      ▼
轴语义、形状、布局、类型与设备                 张量契约
      │
      ▼
值经过哪些算子，又沿哪些支路影响损失           计算图
      │
      ▼
损失怎样把变化传给每个参数                     手算反传
      │
      ▼
程序导数与任务语义能否被独立核对               梯度验证套件
      │
      ▼
信号在训练开始时能否穿过许多层                 初始化报告
      │
      ▼
梯度怎样经过状态与日程变成参数更新             优化器对照
      │
      ▼
尺度控制与短路径分别改善了什么                 结构消融
      │
      ▼
异常能否回到同一输入与状态重新发生             故障复盘
```

缺少其中任何一项，后面的解释都会失去前提。没有张量契约，计算图只画出未知含义的数组。没有计算图，手算梯度很容易漏掉支路。没有独立梯度检查，层间信号异常可能来自导数实现。初始化不稳定，优化器比较从不同质量的起点出发。训练状态不完整，事故无法重放。

## 可重放训练包应当保存什么

八份产物不要求装进一份巨大报告。它们可以分别维护，用稳定实验 ID 连接。

| 产物 | 它固定的判断 | 修改后要重测什么 |
|---|---|---|
| 张量契约与单元测试 | 每个轴、布局、类型和设备代表什么 | 输入格式、批量、损失或框架算子变化 |
| 计算图卡 | 前向依赖、分支、保存状态和梯度边界 | 控制流、模块连接或冻结策略变化 |
| 手算梯度账本 | 一张最小图的路径相乘、汇合相加和 VJP | 局部算子或损失定义变化 |
| 梯度验证套件 | 自动梯度、数值近似和任务不变量各自通过 | 自定义算子、低精度或编译路径变化 |
| 初始化与信号报告 | 训练起点的逐层激活和梯度处于可用范围 | 深度、宽度、激活或分支结构变化 |
| 优化器对照与 checkpoint | 更新规则在公平预算下的轨迹与完整状态 | batch、日程、参数组或预算变化 |
| 归一化与残差消融 | 统计轴、运行状态和短路径的实际作用 | batch 条件、norm 位置或残差投影变化 |
| 故障包与回归门禁 | 触发输入、最早异常、根因、修复和重放结果 | 同类数据、精度和运行环境变化 |

训练包还要保存代码、数据版本、配置、随机种子集合与环境。它们属于所有产物的共同索引。模型权重只是某一步的函数状态，不能独立恢复训练过程。

最上层再放一份很小的 manifest，让实验 ID 成为唯一入口。它至少记录代码提交、数据版本、配置与环境指纹、checkpoint、八份产物的位置，以及最近一次验证状态。下面只是字段示意，路径和状态由实际流水线填写。

```json
{
  "experiment_id": "dl-stage1-...",
  "code_revision": "...",
  "data_version": "...",
  "config": "...",
  "environment": "...",
  "checkpoint": "...",
  "artifacts": ["tensor-contract", "graph-card", "gradient-ledger", "gradient-check", "signal-report", "optimizer-report", "norm-residual-ablation", "incident-package"],
  "validation_status": "pending | passed | failed"
}
```

这样才能从一次曲线回到同一段程序、同一批数据、同一训练状态和同一组判断材料。某个链接缺失或验证仍为 pending 时，训练包还没有完成。

## 三个问题可以快速找到薄弱点

第一组问题检查程序是否在计算预期对象。

每个张量轴代表谁，广播共享了哪个轴，损失归约了哪些元素。最终 loss 能否沿图到达所有应训练参数，分支贡献有没有在正确位置合并。自动梯度与数值近似一致以后，batch 交换、样本复制和单标签扰动等不变量是否仍然成立。

这些检查保护“程序和任务一致”。一条下降的曲线不能替代它们。

第二组问题检查网络是否拥有可训练的信号和更新轨迹。

训练前的激活、梯度和饱和比例有没有随深度系统性塌缩或放大。优化器保存了哪些历史状态，学习率日程推进了多少次更新，权重衰减是否按预期作用。归一化统计哪些轴，残差的恒等路径经过了哪些节点。不同配置是否在同样数据、预算和调参机会下比较。

这些检查保护“结果差异可以被归因”。一次最好运行不能替代多种子和公平对照。

第三组问题检查训练能否重放和调查。

从任意 checkpoint 恢复时，模型、优化器、日程、精度、随机数和采样器是否完整。出现尖峰以后，触发 batch 与最近健康状态能否重新生成同一异常。第一个非有限值出现在哪个节点，修复有没有同时保护正常样本，故障是否进入回归门禁。

这些检查保护“失败可以转化为下一次的工程能力”。一段口头经验不能替代重放样本。

## 换成传感器序列重新搭一遍

现在离开图片分类，换一项本阶段没有使用过的任务。

一台设备每分钟产生 12 项传感器读数。系统每次读取最近 60 分钟，判断下一小时是否需要人工检查。输入形状约定为 `[B,T,F]`，其中 $T=60$，$F=12$。不同设备可能缺少部分分钟，`mask` 标记有效位置。第一版模型对每个时间点使用同一组两层 MLP，再按有效位置求平均，最后输出一个二分类 logit。

这项迁移不需要卷积、RNN 或注意力。它只要求把第一阶段的训练能力带到一组新轴和新故障里。

### 先重建张量与计算关系

给输入、mask、逐时刻隐藏表示、汇总表示、logit、标签和 loss 写张量契约。重点判断 mask 应该怎样扩展。

逐时刻隐藏表示是 `[B,T,H]`，mask 常需要显式变成 `[B,T,1]` 才能沿隐藏特征轴共享。若先把隐藏表示归约成逐位置损失，它通常是 `[B,T]`，这时可以直接使用 `[B,T]` 的 mask。有效位置数量可以写成 `[B,1]`，汇总时要防止某个样本的有效数量为零。`[B,T]` 与 `[B,T,H]` 能不能直接广播，要根据右侧对齐逐轴推演，不能凭视觉猜。

随后画出共享 MLP 的计算图。同一组参数在 60 个位置使用，反向时会累积各有效位置的贡献。mask 为零的位置是否彻底停止贡献，分母怎样进入梯度，都要在图上可见。

### 给共享算子做一次独立梯度核验

把 $B$、$T$、$F$ 和 $H$ 都缩到 2 或 3，选择没有落在 ReLU 折点的具体数字。手算两个时间点怎样共同影响共享权重，再用中心差分或随机方向核对。

接着设计三个不变量。

1. 交换 batch 顺序，输出跟着交换，总平均损失不变。
2. 把一个被 mask 的时间点改成极端数值，当前样本输出保持不变。
3. 在序列末尾追加一个被 mask 的填充时间点，有效位置数和模型输出都应保持不变。

若自动梯度与中心差分一致，第二项仍然失败，先查 mask 语义与归约。它再次说明两种正确导数无法证明任务关系正确。

### 让深层共享 MLP 获得可训练起点

把每个时间点的 MLP 加深到 20 层，使用 ReLU。根据 fan-in 写出初始配方，再在训练以前记录逐层激活 RMS、零比例与梯度 RMS。过小和过大尺度各保留一份失败曲线。

随后在固定初始化、batch 顺序、更新和搜索预算下比较两种候选优化器。报告训练与验证、更新参数比和资源，保存完整 checkpoint 并验证十步续训。

如果加入 LayerNorm，明确它是在每个时间点的 $H$ 个特征上统计；如果加入残差，画出 `[B,T,H]` 上的恒等支路和变换支路。先做无结构、只有 norm、只有残差和组合四组消融，再决定是否保留。

### 调查一个全 mask 样本引起的 NaN

假设某批数据含一台整小时离线的设备，mask 全为零。模型把加权隐藏表示除以有效位置数，分母为零，loss 最终出现 NaN。

先保存故障 batch、最近健康 checkpoint 和全部训练状态。固定随机数重放，不执行更新，沿前向图找到第一次非有限值。修复要依据产品定义。系统可以拒绝这项输入并转人工，也可以为“无传感器数据”建立独立处理路径，不能默默用零向量冒充一小时有效观测。

回归测试同时覆盖全 mask、仅一个有效位置、正常密集序列与最大允许长度。恢复短程训练以后，确认 loss、梯度、更新参数比和精度状态回到健康范围。

完成这些动作，说明八章产物已经能够在新形状、新共享关系和新故障中重新组合。

## 什么时候该退回上一环

训练失败以后继续向后调参，通常会让解释更混乱。按最早失守的证据退回更有效。

| 当前发现 | 应退回的位置 |
|---|---|
| 两个样本在逐元素 loss 中互相影响 | 张量契约与语义不变量 |
| 某个应训练参数从 loss 不可达 | 计算图与梯度边界 |
| 自定义算子与中心差分不一致 | 局部反向实现 |
| 小图正确，深网第一步梯度逐层消失 | 初始化与信号传播 |
| 只换优化器名称，学习率和预算未经重调 | 优化器对照协议 |
| train 正常，eval 输出突然改变 | 所有训练态组件；隔离后再判断归一化运行统计 |
| 故障无法在保存状态下重现 | checkpoint、随机数与数据引用 |

退回并不等于推翻后面所有工作。它表示当前最早的可信链断在这里。修复后让相关门禁重新通过，再恢复后续实验。

## 阶段自检

合上前八章，用自己的项目回答下面的问题。

1. 一个普通张量保存了哪些元数据，轴的任务含义从哪里来。
2. 为什么同一参数经过两条路径影响 loss 时，梯度要相加。
3. 为什么错误损失可能同时通过自动微分和中心差分。
4. Xavier 与 He 的尺度分别依赖哪些近似和激活条件。
5. Adam 的二阶原始矩为什么不能叫作 Hessian。
6. BatchNorm 与 LayerNorm 分别统计哪些轴，推理状态有什么差异。
7. 残差结构怎样为梯度增加一条短路径，又为什么仍可能失稳。
8. 一次 Loss Spike 出现以后，哪些状态决定事故能否重放。

能够解释术语还不够。至少提交一个失败输入、一组对照和一项修复门禁，证明这些判断已经进入可执行训练。

## 进入第二阶段以前要达到什么程度

达到基础掌握时，你应当能独立搭建一个小网络，写出张量契约与计算图，手算并数值核对一段反向，选择有依据的初始化，并在公平预算下完成一次优化器与结构对照。训练中途故障时，你能保存现场、重放并定位到一条具体路径。

达到熟练掌握时，你还应当能把这套方法迁移到另一种张量结构，解释每项检查的盲区，并在证据不足时停下训练或缩小结论。第二次日期不同的重放与变式成功，才提供熟练证据。

这一阶段尚未教授卷积怎样利用图像局部性，也没有教授序列记忆、注意力、预训练或分布式并行。我们现在拥有一台可验证、可诊断的通用训练机器。第二阶段会开始向模型加入结构假设，先问图像平移以后，网络应该保留哪种关系。
