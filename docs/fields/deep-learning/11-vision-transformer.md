### 第一步：固定要解释或改变的对象

不要用“整体效果更好”代替对象。把“弱化视觉先验后，数据规模和预训练为何更重要？”改写为：在明确输入、时间点和约束下，观察什么量，比较什么基线，最后据此采取什么动作。

上一主题“残差网络与多尺度特征”提供前置条件，本章用 **视觉 Transformer** 解释关键机制，并把结果留在“CNN/ViT 数据规模对照”中。下一主题“别只看 Top-1：视觉错误切片”只在这些证据成立后继续。 只要中间任一环只能凭主观解释，结论就应降级为假设。

### 第三步：主动寻找反例

先尝试制造“用分类准确率代表安全漏检”。如果当前方法仍给出看似正常的平均分，说明评价没有覆盖真正风险，需要补切片、过程指标或拒绝条件。

当前决定是“分类之外保留定位/区域证据”。同时写下适用条件、责任人和重新评审信号；这样新证据出现时能更新，而不是把旧结论当永久规则。

## 两份证据把“ViT：把图像变成 Token 序列”的边界画在哪里

### Deep Residual Learning for Image Recognition（2015-12-10）

本章用它校准“ViT：把图像变成 Token 序列”的边界：贡献是提供可扩展深度的优化接口，影响远超视觉。。**不要越过的边界：**原始结果不能代表今天最优骨干；残差也不保证任意深度/尺度稳定。

### An Image is Worth 16x16 Words（2021-06-03）

这项工作追问：纯 Transformer 在足够预训练数据下能否替代卷积视觉骨干？

ViT 将图像分 patch、线性嵌入并用标准 Transformer encoder；依赖大规模监督预训练后迁移到中等图像任务。 作者报告在大预训练规模下匹配或超过强 CNN，同时训练计算更有竞争力。

本章据此采用的判断是：**贡献是证明视觉可统一成 token 序列建模。** 但不能外推到：小数据、边缘延迟和密集预测需要独立对照，不能从 ImageNet 迁移成绩概括。

### A ConvNet for the 2020s（2022-03-02）

本章用它校准“ViT：把图像变成 Token 序列”的边界：贡献是用受控现代化削弱“注意力单独带来全部提升”的归因。。**不要越过的边界：**具体硬件效率与实现相关，架构消融也无法穷尽所有交互。

两份来源若结论看似冲突，先比较任务定义、数据分布、资源预算和评价方法；不能只用发布日期或排行榜高低裁决。

## 当 视觉 Transformer 失效，先查哪里

先排除这些看似合理的误解：ViT 已淘汰 CNN；卷积天然平移不变；参数少一定更快；预训练收益等于架构收益；ImageNet 领先等于领域任务领先。

### 训练/测试拍摄批次泄漏

先查看 **推理**：首 Token、每 Token、P50/P95、吞吐、峰值内存。如果证据确认失败，回到“分类之外保留定位/区域证据”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

### 用分类准确率代表安全漏检

先查看 **任务质量**：主指标、切片、置信区间与失败样本。如果证据确认失败，回到“骨干选型绑定数据规模、任务粒度和硬件”，保存触发输入、系统响应和人工处置，再把样本加入回归集。
