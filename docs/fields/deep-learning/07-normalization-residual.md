# 07 · 归一化管尺度，残差管路径

> 初始化已经让信号安全出发，优化器也有了合理步长。网络变深以后，层间分布会随参数不断变化，误差信号还要连续穿过许多变换。归一化与残差连接处理的是两类问题，放在一起使用也不能混成一句“让训练更稳定”。

## 优化器没有变，深层版本还是更难训练

团队在八层字符分类器上选定了初始化和 AdamW 配置。把相同隐藏层继续堆到四十层以后，训练前的激活统计尚可，更新几十步后却逐渐分化。部分层的输出尺度越来越大，靠近输入的层更新很慢。调低学习率能延缓问题，也会让全部层一起走得更慢。

这次先不换优化器。团队构造四个模型，保持宽度、数据、初始化、更新预算和随机种子集合一致。

| 配置 | 归一化 | 残差路径 | 想隔离的判断 |
|---|---|---|---|
| A | 无 | 无 | 深层普通网络的基线 |
| B | 有 | 无 | 只控制层间统计带来什么 |
| C | 无 | 有 | 只增加短路径带来什么 |
| D | 有 | 有 | 两种机制怎样共同作用 |

四组不能预先假定 D 一定最好。归一化选择的轴、残差分支的尺度和模型任务都会影响结果。消融的目的，是让每项结构用自己的证据说话。

## BatchNorm 从同一通道的一批值估计统计量

先看二维隐藏张量 $x\in\mathbb R^{B\times H}$。BatchNorm 对每个隐藏特征 $j$，使用当前小批量中的 $B$ 个值计算均值与方差。

$$
\mu_j=\frac1B\sum_{i=1}^{B}x_{ij},
\qquad
\sigma_j^2=\frac1B\sum_{i=1}^{B}(x_{ij}-\mu_j)^2.
$$

标准化以后，再应用可学习的缩放与平移。

$$
\hat x_{ij}=\frac{x_{ij}-\mu_j}{\sqrt{\sigma_j^2+\epsilon}},
\qquad y_{ij}=\gamma_j\hat x_{ij}+\beta_j.
$$

$\gamma$ 与 $\beta$ 让网络在需要时恢复或改变尺度。没有这两个参数，标准化会永久限制每个特征的均值与方差。

卷积输入常写成 `[B,C,H,W]`。二维 BatchNorm 通常为每个通道 $C$ 统计一组量，归约轴包括 batch 与空间位置，也就是 `[B,H,W]`。同一张量换成别的布局，统计轴也要随算子约定变化。只说“按 batch 归一化”很容易漏掉空间轴。

BatchNorm 在训练和推理时使用不同状态。训练时依据当前小批量统计，同时更新运行均值与运行方差；评估时通常使用训练期间累积的运行统计，让单个样本的输出不依赖同批其他样本。

这一差异会产生几类常见故障。

- 小批量过小时，当前统计噪声大，训练轨迹会明显变化。
- 训练数据与推理数据分布不同，运行统计无法代表新环境。
- 验证时忘记切换到 eval 模式，输出会随验证批次组成变化。
- 微调时冻结参数却继续更新运行统计，模型状态仍在改变。
- 多设备训练各自统计或同步统计，代表的有效批量不同。

这些问题来自 BatchNorm 选择了跨样本统计。它可能带来有用的正则化与优化效果，也让样本之间产生了运行时联系。部署单样本、强化学习非独立数据或极小微批次时，需要专门验证。

原始论文把训练期间隐藏层输入分布随前层参数更新而变化称作“内部协变量偏移”，并用降低这种变化解释设计动机。后续研究对这一因果解释有不同讨论。学习时更稳妥的做法是先抓住可观察机制，BatchNorm 具体统计哪些轴，怎样改变尺度，训练与推理分别读取什么状态。至于收益来自平滑优化、噪声还是其他作用，要由更针对性的实验回答。

## LayerNorm 在一个样本内部选择特征轴

LayerNorm 不依赖同批其他样本。对于 `[B,H]` 隐藏表示，它通常在每个样本自己的 $H$ 个特征上计算均值与方差。第 $i$ 个样本的统计写成

$$
\mu_i=\frac1H\sum_{j=1}^{H}x_{ij},
\qquad
\sigma_i^2=\frac1H\sum_{j=1}^{H}(x_{ij}-\mu_i)^2.
$$

同一批里增加或删除其他样本，不会改变当前样本的 LayerNorm 输出。训练与推理也不需要切换运行均值。这让它更适合序列模型和小批量情境。

对 `[B,T,D]` 的 token 表示，常见 LayerNorm 为每个样本的每个位置独立归一化最后一个特征轴 $D$。它不会自动沿时间 $T$ 求平均。若 `normalized_shape` 覆盖多个尾部维度，统计范围又会不同。张量契约必须写出具体轴，不能靠“LayerNorm 按层归一化”这句话代替。

LayerNorm 也有代价。它会移除所选特征集合的共同平移与尺度信息，后续用可学习仿射参数恢复一部分自由。某些任务依赖绝对幅度时，要确认前后是否还有路径保存这类信息。epsilon、计算精度和归约实现也会影响极小方差输入。

RMSNorm 等变体省去均值中心化，只按均方根缩放。它们说明归一化本身仍包含设计选择。本章不展开变体排名，只要求读者看到“统计哪些轴、移除什么、恢复什么”这三步。

把 BatchNorm 与 LayerNorm 放在一起比较，关键差异可以收进一张表。

| 问题 | BatchNorm | LayerNorm |
|---|---|---|
| 统计单位 | 同一特征或通道跨一批样本，卷积时常含空间轴 | 单个样本或 token 内被指定的特征轴 |
| 是否依赖批次组成 | 训练时依赖 | 通常不依赖其他样本 |
| 推理状态 | 常使用运行均值与方差 | 使用当前样本自身统计 |
| 主要风险 | 小批量噪声、运行统计失配、train/eval 错位 | 轴配置错误、绝对尺度信息被改变、极小方差数值问题 |

表格没有给出“谁更好”。结构选择要看张量形状、批量条件、推理方式和模型骨干。

## 残差连接给梯度留一条短路

现在把归一化暂时放下，单独看一个残差块。

$$
y=x+F(x;\theta).
$$

普通堆叠层要求后续表示完全经过 $F$。残差块保留输入 $x$，变换分支只学习相对它的修正。若当前最合适的变换接近恒等，$F$ 可以学习接近零，优化任务往往更容易表达。

反向时，输入梯度包含两条路径。

$$
\frac{\partial L}{\partial x}
=\frac{\partial L}{\partial y}
\left(I+\frac{\partial F}{\partial x}\right).
$$

$I$ 来自恒等支路。即使 $\partial F/\partial x$ 的某些方向很小，上游梯度仍有一条不经过整个变换分支的路线。很多残差块串联时，网络拥有多种长短不同的路径，这会改变深层优化。

短路不等于梯度永不消失或爆炸。若残差分支 Jacobian 很大，$I+J_F$ 仍可能放大；若加法以后紧跟饱和或错误缩放，后续路径也会受阻。分支输出与主干尺度不匹配，连续相加还可能让激活随深度增长。

形状也必须对得上。$x$ 与 $F(x)$ 的维度不同，常用线性投影或卷积把恒等支路调整到目标形状。投影后的支路已经不再是纯恒等映射，它拥有参数和自己的数值行为。下采样、通道扩张与精度转换都要画进计算图。

残差连接同时影响表达。每个块学习一个增量，深层模型可以逐步修正表示。第二阶段进入 ResNet 与 Transformer block 时，会继续研究这种结构怎样与图像和序列归纳偏置结合。本章只处理它对训练路径和信号尺度的作用。

## 归一化放在哪里会改变整条残差路

一个残差块可以先变换再归一化，也可以先归一化再进入变换。位置不同，恒等支路上是否经过归一化、梯度需穿过哪些节点都会改变。

```text
Pre-LN   x ────────────────┐
          └─ Norm ─ F ─────┴─ add ─ y

Post-LN  x ──────────┐
          └─ F ───────┴─ add ─ Norm ─ y
```

在序列模型里，Pre-LN 通常把归一化放到注意力或 MLP 子层以前。从反向图看，残差主路能够沿连续加法节点跨过多个块。Post-LN 把归一化放在残差相加以后，每个块的输出和反向路径都会经过归一化节点。这个差异可以解释训练路径，却不能单独判定哪种结构在所有任务上更好。两者对深度、初始化、学习率和最终表示的影响需要在具体架构中比较，第十五章会展开 Transformer 中的数据流。

在卷积残差网络里，BatchNorm、激活和卷积的先后也经历过不同设计。背诵一个顺序不足以理解。画出前向图以后，从损失逆向追踪主路，检查恒等路径经过了哪些有状态或非线性节点，才知道“短路”有多短。

归一化和残差还会共同影响初始化。若残差分支最后一层初始接近零，网络开始时更接近恒等映射；若每个分支都输出同样尺度的随机信号，深度增加后相加方差可能增长。这些配方需要回到第五章的层间信号扫描验证。

## 四组消融要同时看函数、信号和状态

回到 A、B、C、D 四个模型。训练以前先确认参数量和计算量差异，投影支路或仿射参数也要计入。每组使用相同训练数据、更新预算和合理调参机会，随后记录三类证据。

第一类是任务结果。训练与验证 loss 是否下降，准确率是否稳定，多随机种子差异多大。它说明配置在当前任务上有没有实际收益。

第二类是信号。逐层激活 RMS、梯度 RMS、分位数、残差分支与主路的尺度比怎样变化。它帮助解释收益出现在哪条路径。

第三类是状态。BatchNorm 的批统计与运行统计差多大，切换 train 和 eval 后同一固定样本输出是否突变，恢复 checkpoint 后运行统计是否连续。

可以把实验结果组织成下面的记录。

| 配置 | 验证表现 | 前层梯度 | 深层激活 | 归一化状态差异 | 当前判断 |
|---|---|---|---|---|---|
| A 无归一化无残差 | 实测填写 | 实测填写 | 实测填写 | 无归一化状态 | 深层普通基线 |
| B 只有归一化 | 实测填写 | 实测填写 | 实测填写 | 需重点记录 | 尺度控制贡献 |
| C 只有残差 | 实测填写 | 实测填写 | 实测填写 | 无归一化状态 | 短路径贡献 |
| D 两者都有 | 实测填写 | 实测填写 | 实测填写 | 需重点记录 | 组合效果与交互 |

“实测填写”不能提前换成理想化数字。消融要保留失败种子和异常曲线。若 B 改善激活统计却没有改善验证结果，说明尺度问题不一定是当前瓶颈。若 C 的前层梯度更健康而激活逐层放大，需要继续调整分支尺度。若 D 只在较大 batch 下稳定，BatchNorm 的统计条件应写入结论。

还可以把归一化层隔离出来做两个很小的功能测试，先关闭 Dropout、随机深度、数据增强与其他跨样本操作。对 LayerNorm 子图，改变同批其他样本，固定样本的输出应保持；对 eval 状态下的 BatchNorm 子图，改变同批其他样本也不应让固定样本依赖当前批统计。测试失败时，先检查模式切换与统计轴。整模型若仍有差异，还要继续调查其他训练态组件，不能全部归给归一化。

## 一份结构报告要允许别人反驳

本章最终留下层间统计与消融报告。它要回答下面这些问题。

- 每个归一化层到底统计哪些轴，epsilon 与仿射参数怎样设置。
- BatchNorm 的运行统计怎样更新，验证和部署使用哪个模式。
- 每个残差块的恒等支路与变换支路怎样对齐形状。
- 沿反向图从 loss 到早期层，最短路径经过哪些节点。
- 四组消融在同一预算下分别改变了什么，失败条件是什么。
- 架构、初始化或 batch 改变以后，哪些结论必须重测。

这份报告会直接进入第八章的故障调查。Loss Spike 出现时，团队需要知道某个异常来自 batch 统计、残差尺度、混合精度还是优化器。没有结构基线，所有异常都会被归到“训练不稳定”。
