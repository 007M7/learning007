## 表面现象背后，究竟是谁在起作用

> SGD、Adam、初始化和归一化怎样共同决定训练轨迹？

loss spike 可能由脏 batch、学习率暖启动、混合精度溢出、MoE 路由失衡或分布式通信错误造成。Adam 在某些配置更快降低训练损失，不代表在相同 token/算力下泛化更好。批量变化还会改变梯度噪声和有效学习率。

## 三个变量，不是三个并列名词

| 知识节点 | 先用一句话说清 | 它支持哪项决定 | 先排除的误解 |
|---|---|---|---|
| DLF04 · 优化轨迹 | 随机梯度、动量和自适应尺度共同决定参数路径 | 未收敛、鞍点还是噪声 | Adam 总比 SGD 好 |
| DLF05 · 信号传播 | 初始化、残差和归一化控制激活/梯度尺度 | 深度增加后信息是否稳定 | 权重衰减就是 Adam 中的 L2 |
| DLF06 · 稳定训练 | 学习率、批量、精度、裁剪和监控形成闭环 | 何时恢复、回滚或调整 | 梯度裁剪解决爆炸根因 |

读表时不要横向背三行。任选一行，把“定义—决定—反例”连成一句因果解释；然后把本章案例中的一个输入替换掉，检查原判断是否仍成立。

## 梯度估计、动量与尺度控制

SGD 用 minibatch 给出总体梯度的噪声估计；动量平滑长期方向。Adam 对一阶、二阶矩做指数平均并按坐标缩放，AdamW 将权重衰减从自适应梯度更新中解耦。Xavier/He 初始化匹配前后向方差；残差提供短梯度路径；LayerNorm 按 token 特征归一化，适合序列模型。warmup 控制早期未校准激活下的更新。

~~~~mermaid
flowchart LR
  B[数据 batch] --> F[前向激活]
  F --> L[loss/scale]
  L --> G[反向梯度]
  G --> N[范数/非有限/分布]
  N --> O[优化器+schedule]
  O --> W[参数/EMA/checkpoint]
  W --> F
  N --> A[告警/跳步/回滚]
~~~~

## 从直觉走到形式化

动量 SGD 与 AdamW 的核心更新可概括为

$$
v_t=\beta v_{t-1}+g_t,\quad \theta_{t+1}=\theta_t-\eta v_t,
$$

$$
m_t=\beta_1m_{t-1}+(1-\beta_1)g_t,\quad
v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2,
$$

$$
\theta_{t+1}=(1-\eta\lambda)\theta_t-\eta\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon}.
$$

把每个符号放回真实系统。下面任何一项说不清，计算正确也不能保证结论正确：

- 权重衰减与 L2 正则在自适应优化器中不完全等价
- 梯度裁剪掩盖爆炸原因时只能作为护栏
- 混合精度 loss scaling 需监测溢出/跳步
- 比较优化器必须固定 token、模型、数据顺序和搜索预算

## 把机制放进：Transformer 训练第 8k 步尖峰

先对尖峰 batch 重放，检查 token 长度、异常标签和 loss 分项；再检查 grad norm、FP8/FP16 overflow、学习率位置与各层激活。若只有某数据源触发，修数据和采样；若所有 batch 在 warmup 结束触发，检查 schedule。裁剪可防止模型损坏，但事故报告仍需找到根因。

### 读案例时做三次停顿

1. 到 优化轨迹 时停一次：未收敛、鞍点还是噪声？
2. 到 信号传播 时再停一次：哪条数据流、状态变化或约束能证明机制真的发生？
3. 到 稳定训练 时最后停一次：如果出现“只保存模型权重无法精确续训”，系统应继续、拒绝还是交给人？

## 两份证据把边界画在哪里

好证据不仅告诉你某种方法有效，还会暴露比较基线、资源条件和不能迁移的部分。

### Decoupled Weight Decay Regularization（2019-01-04）

先看这份来源时，要带着一个具体问题：为什么把 L2 项加到 Adam 梯度中不等于直接衰减权重？

论文分析自适应尺度会改变 L2 惩罚的坐标作用，提出 AdamW 将权重衰减独立于梯度更新。 实验在图像分类与语言建模展示更可解释的超参数和泛化收益。 因此，本章采用它来支持这样的判断：贡献是修正广泛使用的优化器正则实现。

但它没有替我们回答所有问题。具体优势依任务和调参；AdamW 也不会自动解决学习率、数据或数值问题。

### DeepSeek-V3 Technical Report（2024-12-27）

最后看这份来源时，要带着一个具体问题：大规模 MoE 训练怎样在较低激活参数和数值风险下保持稳定？

报告描述 MLA、DeepSeekMoE、无辅助损失负载均衡、多 Token 预测、FP8 训练与系统协同；总参数 671B、每 Token 激活 37B，预训练 14.8T Token。 作者报告 2.788M H800 GPU 小时，并称训练中无不可恢复 loss spike 或回滚。 因此，本章采用它来支持这样的判断：贡献是公开大规模稀疏模型在算法与系统层的联合稳定设计。

但它没有替我们回答所有问题。厂商自报、硬件/集群高度特定；不能用总 GPU 小时直接与不同实现和会计口径比较。

## 用小实验拆开因果链：构建训练稳定性仪表盘

- **这一步在验证：** 信号传播能否支持“深度增加后信息是否稳定”这项判断。
- **至少留下：** loss、梯度/激活、吞吐、显存、数据量、FLOPs。
- **先停下来而不是继续调参的信号：** 用更强裁剪掩盖坏数据。

- **至少留下：** 首 Token、每 Token、P50/P95、吞吐、峰值内存。
- **先停下来而不是继续调参的信号：** 比较不同训练 Token 的优化器。

### 第 4 步：制造异常 batch 并验证检测、跳步和 checkpoint 恢复

- **这一步在验证：** 优化轨迹能否支持“未收敛、鞍点还是噪声”这项判断。
- **至少留下：** 校准、偏移、攻击、记忆/污染与能耗。

## 做到什么，才算结果可信

| 观察维度 | 要留下的记录 | 它防止你误判什么 |
|---|---|---|
| 任务质量 · 优化轨迹 | 主指标、切片、置信区间与失败样本 | 确认改进是否稳定且可解释；本章还要据此判断：未收敛、鞍点还是噪声 |
| 训练 · 信号传播 | loss、梯度/激活、吞吐、显存、数据量、FLOPs | 区分算法收益和更多计算；本章还要据此判断：深度增加后信息是否稳定 |
| 推理 · 稳定训练 | 首 Token、每 Token、P50/P95、吞吐、峰值内存 | 模型参数量不等于用户体验；本章还要据此判断：何时恢复、回滚或调整 |
| 风险 · 优化轨迹 | 校准、偏移、攻击、记忆/污染与能耗 | 把能力放入真实部署边界；本章还要据此判断：未收敛、鞍点还是噪声 |

## 实验结果怎样进入系统

### 1. 训练卡记录有效 batch、token、schedule 和优化器全部状态

验收时查看 **任务质量**，至少保存主指标、切片、置信区间与失败样本。如果观察到“只保存模型权重无法精确续训”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 2. checkpoint 包含随机数、采样器与 scaler

验收时查看 **训练**，至少保存loss、梯度/激活、吞吐、显存、数据量、FLOPs。如果观察到“用更强裁剪掩盖坏数据”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 3. 尖峰门禁区分数据异常、数值溢出和优化失稳

验收时查看 **推理**，至少保存首 Token、每 Token、P50/P95、吞吐、峰值内存。如果观察到“比较不同训练 Token 的优化器”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 4. 大规模前先用缩放实验校准超参迁移

验收时查看 **风险**，至少保存校准、偏移、攻击、记忆/污染与能耗。如果观察到“把 Adam 二阶矩叫 Hessian”，这项决定必须重新评审，不能因为已经实现就默认保留。

## 当假设被破坏，会先出现什么

先排除这些误解：Adam 总比 SGD 好；权重衰减就是 Adam 中的 L2；梯度裁剪解决爆炸根因；batch 越大越稳定且越优；恢复权重等于恢复训练。

### 只保存模型权重无法精确续训

- **先看什么：** 主指标、切片、置信区间与失败样本
- **回到哪项控制：** 训练卡记录有效 batch、token、schedule 和优化器全部状态
- **怎样留下证据：** 保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“构建训练稳定性仪表盘”的回归记录。

### 用更强裁剪掩盖坏数据

- **先看什么：** loss、梯度/激活、吞吐、显存、数据量、FLOPs
- **回到哪项控制：** checkpoint 包含随机数、采样器与 scaler
- **怎样留下证据：** 保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“构建训练稳定性仪表盘”的回归记录。

### 比较不同训练 Token 的优化器

- **先看什么：** 首 Token、每 Token、P50/P95、吞吐、峰值内存
- **回到哪项控制：** 尖峰门禁区分数据异常、数值溢出和优化失稳
- **怎样留下证据：** 保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“构建训练稳定性仪表盘”的回归记录。

### 把 Adam 二阶矩叫 Hessian

- **先看什么：** 校准、偏移、攻击、记忆/污染与能耗
- **回到哪项控制：** 大规模前先用缩放实验校准超参迁移
- **怎样留下证据：** 保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“构建训练稳定性仪表盘”的回归记录。

### 忽略分布式 worker 间数据/梯度差异

- **先看什么：** 主指标、切片、置信区间与失败样本
- **回到哪项控制：** 训练卡记录有效 batch、token、schedule 和优化器全部状态

## 本章小结

- 训练稳定来自数据、数值和优化联合
- AdamW 解耦权重衰减
- 激活/梯度监控比单 loss 更有诊断力
- 可重放和完整 checkpoint 是恢复底线
