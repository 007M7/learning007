## 为什么现在要学“Transformer Block 的完整数据流”

你看到的是输出变化，真正需要追的是状态、信息和约束怎样传递。标准注意力能让任意 token 直接比较，却为训练构造 $n^2$ 关系；自回归推理又被 KV cache 容量和内存带宽限制。

**本章核心判断：** Transformer Block 是残差、归一化、注意力和 MLP 的耦合系统，单看注意力无法解释稳定性。

本章只追一个判断：**残差、归一化、MLP 和位置编码怎样共同工作？** 最后必须用“Pre-LN/Post-LN 消融”来回答；如果产物不能暴露失败样本，就还不能算学会。

## 两份证据把“Transformer Block 的完整数据流”的边界画在哪里

### FlashAttention（2022-06-23）

本章用它校准“Transformer Block 的完整数据流”的边界：贡献是把硬件内存层级变成算法设计变量。。**不要越过的边界：**收益依 GPU、序列形状、内核和后续版本；不能把理论 FLOPs 当实际速度。

### Mamba: Linear-Time Sequence Modeling with Selective State Spaces（2023-12-01）

这项工作追问：SSM 如何获得内容相关选择能力并在语言上接近注意力？

Mamba 使状态更新参数依输入变化，使用硬件感知并行 scan；网络不使用注意力或传统 MLP 块。 论文报告 3B Mamba 超过同规模 Transformer、匹配约两倍规模模型，并称推理吞吐最高约 5 倍、长度线性扩展。

本章据此采用的判断是：**贡献是让内容选择与线性状态更新结合成强通用骨干。** 但不能外推到：指标来自特定模型、硬件与 2023 基线；精确回忆和现代混合架构需重新测试。

两份来源若结论看似冲突，先比较任务定义、数据分布、资源预算和评价方法；不能只用发布日期或排行榜高低裁决。

## 当 选择性 SSM 失效，先查哪里

先排除这些看似合理的误解：注意力天然可解释；FlashAttention 是近似；线性复杂度必然低延迟；百万上下文等于百万有效推理；KV cache 只与参数量有关。
