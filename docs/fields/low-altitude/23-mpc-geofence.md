## 在“城市巡检 runtime assurance”中定位关键判断

学习规划器只输出短时航点；NMPC 检查障碍、推力、倾角、空域与 SOC。独立监视器用保守可达管判断未来 3 秒，违例切备用悬停/返航。SIL→HIL 注入求解超时、状态跳变和障碍突现。

| 检查点 | 应留下的证据 | 不能接受的替代品 |
|---|---|---|
| 分层飞控 | 任务成功、航迹/时间/载荷与拒绝率，并写入约束违例、可达性与 Fallback | 完成任务但越界不算成功 |
| 约束规划 | 最小间隔、能量/控制余度、告警与失效覆盖，并写入约束违例、可达性与 Fallback | 平均性能不能证明包线边缘安全 |
| 自主安全壳 | 定位/感知/C2 延迟、P95/P99、可用性，并写入约束违例、可达性与 Fallback | 闭环由最慢和最弱链路决定 |

## 当 自主安全壳 失效，先查哪里

先排除这些看似合理的误解：端到端控制最先进所以更安全；MPC 优化即可保证可行；地理围栏等于避障；备用存在就可靠；平均求解时间足够。

### 地理围栏只在云端

先查看 **系统性能**：定位/感知/C2 延迟、P95/P99、可用性。如果证据确认失败，回到“求解超时有确定降级”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

### 学习与安全监视共享同一故障

先查看 **飞行任务**：任务成功、航迹/时间/载荷与拒绝率。如果证据确认失败，回到“学习策略不直接输出电机命令”，保存触发输入、系统响应和人工处置，再把样本加入回归集。
