# 06 · 飞控、轨迹规划与自主决策

> 学习规划器可以提出动作，但不应拥有无边界控制权；安全关键飞行依靠分层控制、硬约束和独立恢复形成防线。

## 表面现象背后，究竟是谁在起作用

> 学习策略怎样与可验证控制器、地理围栏和应急逻辑共存？

端到端策略在训练城市成功绕障，遇到未见吊线输出激进转向并进入推力饱和。需要 verified envelope、运行时 assurance 和应急着陆候选，而不是只加训练数据。

## 三个变量，不是三个并列名词

| 知识节点 | 先用一句话说清 | 它支持哪项决定 | 先排除的误解 |
|---|---|---|---|
| LAF16 · 分层飞控 | 快内环稳定本体，慢外环跟踪与规划 | 哪些环必须确定、可验证 | 端到端控制最先进所以更安全 |
| LAF17 · 约束规划 | 轨迹同时满足动力学、障碍、空域和能量 | 最优性何时让位安全可行 | MPC 优化即可保证可行 |
| LAF18 · 自主安全壳 | 独立监视器覆盖模型/规划器失效并触发恢复 | 学习策略能做哪些动作 | 地理围栏等于避障 |

## 优化控制与 runtime assurance

内环 PID/LQR 保姿态，外环位置/速度跟踪；NMPC 在滚动时域优化动力学与约束。高层学习策略输出目标/航点，安全过滤器预测可达集或控制 barrier，越界时切换 verified backup。状态机覆盖失链、低能量、导航降级和避让。

 R -->|越界| B[备用/返航/着陆]

## 从直觉走到形式化

LQR 最小化 $J=\sum x^TQx+u^TRu$；MPC 在 $N$ 步满足 $x_{k+1}=f(x_k,u_k),g(x,u)\le0$。控制 barrier 条件 $\dot h(x,u)+\alpha h(x)\ge0$ 维持安全集 $h(x)\ge0$。

把每个符号放回真实系统。下面任何一项说不清，计算正确也不能保证结论正确：

- 线性/动力学模型适用包线
- 求解器最坏时延与不可行处理
- 安全集是否含估计不确定和延迟
- 备用控制器在故障状态仍可用

## 把机制放进：城市巡检 runtime assurance

学习规划器只输出短时航点；NMPC 检查障碍、推力、倾角、空域与 SOC。独立监视器用保守可达管判断未来 3 秒，违例切备用悬停/返航。SIL→HIL 注入求解超时、状态跳变和障碍突现。

### 读案例时做三次停顿

1. 到 分层飞控 时停一次：哪些环必须确定、可验证？
2. 到 约束规划 时再停一次：哪条数据流、状态变化或约束能证明机制真的发生？
3. 到 自主安全壳 时最后停一次：如果出现“仿真 reward 当安全证明”，系统应继续、拒绝还是交给人？

## 用小实验拆开因果链：给学习规划器加安全壳

### 第 1 步：分离任务/规划/控制/安全层接口

- **这一步在验证：** 分层飞控能否支持“哪些环必须确定、可验证”这项判断。
- **至少留下：** 任务成功、航迹/时间/载荷与拒绝率。
- **先停下来而不是继续调参的信号：** 仿真 reward 当安全证明。

### 第 2 步：验证 baseline 控制器包线

- **这一步在验证：** 约束规划能否支持“最优性何时让位安全可行”这项判断。
- **至少留下：** 最小间隔、能量/控制余度、告警与失效覆盖。
- **先停下来而不是继续调参的信号：** 备用控制器从未在故障状态测试。

### 第 3 步：给学习输出加约束过滤和超时

- **这一步在验证：** 自主安全壳能否支持“学习策略能做哪些动作”这项判断。
- **至少留下：** 定位/感知/C2 延迟、P95/P99、可用性。
- **先停下来而不是继续调参的信号：** 地理围栏只在云端。

### 第 4 步：SIL/HIL/系留逐级注入故障

- **这一步在验证：** 分层飞控能否支持“哪些环必须确定、可验证”这项判断。
- **至少留下：** 每航次成本、机队利用、人工、维护与事故暴露。
- **先停下来而不是继续调参的信号：** 忽略求解器尾延迟。

## 做到什么，才算结果可信

| 观察维度 | 要留下的记录 | 它防止你误判什么 |
|---|---|---|
| 飞行任务 · 分层飞控 | 任务成功、航迹/时间/载荷与拒绝率 | 完成任务但越界不算成功；本章还要据此判断：哪些环必须确定、可验证 |
| 安全裕度 · 约束规划 | 最小间隔、能量/控制余度、告警与失效覆盖 | 平均性能不能证明包线边缘安全；本章还要据此判断：最优性何时让位安全可行 |
| 系统性能 · 自主安全壳 | 定位/感知/C2 延迟、P95/P99、可用性 | 闭环由最慢和最弱链路决定；本章还要据此判断：学习策略能做哪些动作 |

## 实验结果怎样进入系统

### 1. 学习策略不直接输出电机命令

验收时查看 **飞行任务**，至少保存任务成功、航迹/时间/载荷与拒绝率。如果观察到“仿真 reward 当安全证明”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 2. 安全监视独立进程/电源边界按风险设计

验收时查看 **安全裕度**，至少保存最小间隔、能量/控制余度、告警与失效覆盖。如果观察到“备用控制器从未在故障状态测试”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 3. 求解超时有确定降级

验收时查看 **系统性能**，至少保存定位/感知/C2 延迟、P95/P99、可用性。如果观察到“地理围栏只在云端”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 4. 包线扩张需新回归与飞行卡

验收时查看 **运行经济**，至少保存每航次成本、机队利用、人工、维护与事故暴露。如果观察到“忽略求解器尾延迟”，这项决定必须重新评审，不能因为已经实现就默认保留。

## 当假设被破坏，会先出现什么

先排除这些误解：端到端控制最先进所以更安全；MPC 优化即可保证可行；地理围栏等于避障；备用存在就可靠；平均求解时间足够。

### 仿真 reward 当安全证明

- **先看什么：** 任务成功、航迹/时间/载荷与拒绝率
- **回到哪项控制：** 学习策略不直接输出电机命令
- **怎样留下证据：** 保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“给学习规划器加安全壳”的回归记录。

### 备用控制器从未在故障状态测试

- **先看什么：** 最小间隔、能量/控制余度、告警与失效覆盖
- **回到哪项控制：** 安全监视独立进程/电源边界按风险设计
- **怎样留下证据：** 保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“给学习规划器加安全壳”的回归记录。

### 地理围栏只在云端

- **先看什么：** 定位/感知/C2 延迟、P95/P99、可用性
- **回到哪项控制：** 求解超时有确定降级
- **怎样留下证据：** 保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“给学习规划器加安全壳”的回归记录。

### 忽略求解器尾延迟

- **先看什么：** 每航次成本、机队利用、人工、维护与事故暴露
- **回到哪项控制：** 包线扩张需新回归与飞行卡
- **怎样留下证据：** 保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“给学习规划器加安全壳”的回归记录。

### 学习与安全监视共享同一故障

- **先看什么：** 任务成功、航迹/时间/载荷与拒绝率
- **回到哪项控制：** 学习策略不直接输出电机命令
