# 05 · 定位、导航与状态估计

> 导航不是输出一个位置，而是输出带不确定度、可观测性和健康状态的估计；控制器必须知道何时不能再相信它。

## 这次只练一件事：实现一个带健康门禁的融合回放

GNSS 欺骗造成位置平滑漂移，传统合理性检查不报警；视觉在水面/夜间退化，IMU 偏置继续累积。仅增加传感器会产生错误自信，需创新统计、跨源一致和地理/动力学约束。

不要急着把整套系统做完。本章先用一个可重放的小任务回答：**GNSS 受扰、城市峡谷和高速机动时怎样维持可观测状态？**

## 示范任务：城市峡谷 GNSS 欺骗降级

仿真和回放注入阶跃、缓慢拖拽、多路径及视觉纹理退化。比较 GNSS-only、EKF 和多源健康门禁；报告定位误差、NEES/NIS、一致覆盖、告警延迟、误警和安全模式进入时的航迹。

### 读案例时做三次停顿

1. 到 状态估计 时停一次：估计是否一致可信？
2. 到 VIO/GNSS 融合 时再停一次：哪条数据流、状态变化或约束能证明机制真的发生？
3. 到 导航韧性 时最后停一次：如果出现“只看平均 RMSE”，系统应继续、拒绝还是交给人？

## 误差状态滤波与健康门禁

IMU 高频传播名义状态与误差协方差，GNSS/视觉/气压计更新；创新残差与协方差检测异常。VIO 通过特征/光度约束估计相对运动，但尺度、纹理和动态物体影响可观测。独立健康管理决定排除观测、扩大保护级或进入安全模式。

## 做到什么，才算结果可信

| 观察维度 | 要留下的记录 | 它防止你误判什么 |
|---|---|---|
| 飞行任务 · 状态估计 | 任务成功、航迹/时间/载荷与拒绝率 | 完成任务但越界不算成功；本章还要据此判断：估计是否一致可信 |
| 安全裕度 · VIO/GNSS 融合 | 最小间隔、能量/控制余度、告警与失效覆盖 | 平均性能不能证明包线边缘安全；本章还要据此判断：城市峡谷/纹理弱如何切换 |
| 系统性能 · 导航韧性 | 定位/感知/C2 延迟、P95/P99、可用性 | 闭环由最慢和最弱链路决定；本章还要据此判断：何时降级返航/着陆 |
| 运行经济 · 状态估计 | 每航次成本、机队利用、人工、维护与事故暴露 | 单机演示不能证明可持续运营；本章还要据此判断：估计是否一致可信 |

## 为什么这些步骤能够解释结果

EKF：$x^-_k=f(x_{k-1},u), P^-=FPF^T+Q$；创新 $r=z-h(x^-)$，$S=HP^-H^T+R$，NIS $r^TS^{-1}r$ 用于一致性检验。保护级应覆盖真实误差概率，不能只看 RMSE。

把每个符号放回真实系统。下面任何一项说不清，计算正确也不能保证结论正确：

- IMU 偏置/时间同步是否入状态
- 滤波 Q/R 是否由数据辨识
- 线性化和非高斯/多模态条件
- 真值系统精度和坐标基准

## 轮到你：换一组条件再做：实现一个带健康门禁的融合回放

用简化二维 EKF 融合 IMU/GNSS，注入缓慢欺骗；比较仅 RMSE 与 NIS 门禁，提交告警/误警和降级轨迹。

提交时一并回答：

- 你能否不看正文解释RMSE 与一致性的差异；
- 产物是否真的包含一个异常注入融合实验；
- 哪个失败样本暴露了状态不可观测时的安全动作；
- 如果换一个数据、人群、环境或本体，最先需要重测哪项指标。

提交物不能只有成功截图。附上一个失败样本，并说明它推翻了什么假设、哪些残余风险还不能消除。

## 验证通过后，项目要改变什么

### 1. 估计接口携带协方差与健康标志

验收时查看 **飞行任务**，至少保存任务成功、航迹/时间/载荷与拒绝率。如果观察到“只看平均 RMSE”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 2. 保护级超阈值禁止继续任务

验收时查看 **安全裕度**，至少保存最小间隔、能量/控制余度、告警与失效覆盖。如果观察到“协方差过小造成错误自信”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 3. GNSS 恢复需多源一致和滞回

验收时查看 **系统性能**，至少保存定位/感知/C2 延迟、P95/P99、可用性。如果观察到“所有传感共享 GNSS 时间却称独立”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 4. 欺骗/干扰样本进入回归

验收时查看 **运行经济**，至少保存每航次成本、机队利用、人工、维护与事故暴露。如果观察到“失效后立即自动恢复”，这项决定必须重新评审，不能因为已经实现就默认保留。

## 本章小结

- 状态估计输出不确定性和健康
- 可观测性决定能否校正漂移
- 一致性比轨迹平滑重要
- 导航失效需显式降级
