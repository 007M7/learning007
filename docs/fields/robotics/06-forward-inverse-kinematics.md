## 位姿与运动学 怎样经过 Jacobian/奇异 影响结果

齐次变换组合旋转平移，正运动学从基座到末端连乘；逆运动学多解用种子、限位与碰撞约束选择。Jacobian 把 $\dot q$ 映射末端 twist 并用转置映射 wrench。动力学可递归计算并与接触约束耦合。

~~~~mermaid
flowchart LR
 Q[关节状态] --> FK[SE3 正运动学]
 FK --> X[末端位姿]
 X --> IK[约束逆解]
 IK --> J[Jacobian/奇异]
 J --> D[动力学/力矩]
 D --> R[仿真/实机校准]
~~~~

读图时从结果逆向追问：哪一步能够观察，哪一步只是假设，哪一步失效后必须让系统拒绝或降级。

## 用公式审查“正运动学与逆运动学”

$T(q)=\prod_iT_i(q_i)$，$\dot x=J(q)\dot q$；$M(q)\ddot q+C(q,\dot q)\dot q+g(q)+J^T\lambda=\tau$。$\kappa(J)$ 或最小奇异值用于监测接近奇异，伪逆需阻尼。

逐个把符号放回真实任务，并检查：

- 左/右手系和变换方向
- 旋转表示归一/双覆盖
- 关节限位、自碰与多逆解
- 惯量/摩擦/柔顺参数证据

推导完成不代表结论成立。至少改变一次关键条件，观察 **Jacobian/奇异** 的结论是否保持；若不保持，把条件写入“IK 求解、工作空间与解支选择”而不是藏在代码默认值里。
