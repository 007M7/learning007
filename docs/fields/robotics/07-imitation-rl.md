# 07 · 模仿学习、强化学习与数据

> 机器人数据最稀缺的不是成功片段数量，而是覆盖失败前状态、纠正动作和真实闭环分布；无安全探索和数据边界的 RL 不能直接上线。

## 表面现象背后，究竟是谁在起作用

> 遥操作示范、离线数据、仿真奖励和在线探索怎样组合？

BC 在专家轨迹附近很好，首次偏离后误差累积；离线 RL 对数据外动作给虚高价值。若用策略自动筛选好看轨迹，会进一步删除恢复证据。

## 三个变量，不是三个并列名词

| 知识节点 | 先用一句话说清 | 它支持哪项决定 | 先排除的误解 |
|---|---|---|---|
| RBF19 · 模仿学习 | 从示范学习策略但执行会进入未见状态 | 怎样减少协变量偏移 | 更多成功轨迹等于覆盖 |
| RBF20 · 强化/离线学习 | 通过奖励/价值改进动作，受探索和外推误差限制 | 何时允许在线探索 | 随机切帧可泛化 |
| RBF21 · 机器人数据治理 | 多本体传感动作需同步、校准、任务与失败元数据 | 更多轨迹是否真的增加覆盖 | 离线 RL 无安全风险 |

读表时不要横向背三行。任选一行，把“定义—决定—反例”连成一句因果解释；然后把本章案例中的一个输入替换掉，检查原判断是否仍成立。

## 协变量偏移、价值外推与数据覆盖

BC 最大似然拟合专家条件动作，部署状态由自身策略产生；DAgger 让专家标策略访问状态。离线 RL 从固定数据估值，需保守约束减少 OOD 动作；在线探索只能在仿真/安全壳和受控设备。数据单元绑定本体、校准、控制器、延迟、任务、结果和干预。

~~~~mermaid
flowchart LR
 D[示范+校准元数据] --> BC[BC/离线策略]
 BC --> S[安全壳部署]
 S --> F[失败前状态/人工纠正]
 F --> C[覆盖/质量审计]
 C --> D
 S -->|仅受控| X[在线探索]
 X --> D
~~~~

## 从直觉走到形式化

BC $L=-E_{(s,a)\sim D}\log\pi(a|s)$；性能误差可随 horizon 累积。离线 RL Bellman 目标含 $Q(s',a')$，若 $a'$ 不在数据支持会外推。覆盖可用状态/动作密度、最近邻距离和失败切片估计。

把每个符号放回真实系统。下面任何一项说不清，计算正确也不能保证结论正确：

- 示范者与策略观测是否一致
- 动作时间戳/控制器语义
- 训练/测试轨迹按场景实体隔离
- 在线探索的硬停止和责任

## 把机制放进：仓库抓取恢复数据飞轮

首轮收正常遥操作，再在安全限速下运行 BC，专家接管并保存接管前 5 秒和纠正。测试按新物体/摆放/遮挡隔离；对照只加成功数据与加恢复数据。任何在线 RL 仅仿真和隔离台架。

### 读案例时做三次停顿

1. 到 模仿学习 时停一次：怎样减少协变量偏移？
2. 到 强化/离线学习 时再停一次：哪条数据流、状态变化或约束能证明机制真的发生？
3. 到 机器人数据治理 时最后停一次：如果出现“随机切帧泄漏轨迹”，系统应继续、拒绝还是交给人？

## 两份证据把边界画在哪里

好证据不仅告诉你某种方法有效，还会暴露比较基线、资源条件和不能迁移的部分。

### DAgger（2011-04-21）

**它追问什么：**如何缓解模仿学习部署状态偏移？

**方法和结果：**迭代运行当前策略，让专家对访问状态标动作并聚合数据。 理论与实验说明可把序列错误累积从平方级改善。

**它改变的判断：**建立数据在环模仿范式。

> **不要越过这条边界：**需要专家安全介入；真实机器人采集成本/风险很高。

### ISO Robotics Standards（2026-08-30）

**它追问什么：**学习策略的数据迭代仍受什么系统安全约束？

**方法和结果：**ISO 官方入口列机器人安全与性能标准。 提醒在线学习/探索不豁免机械安全要求。

**它改变的判断：**把数据飞轮置于控制边界。

> **不要越过这条边界：**标准并不直接给 ML 算法方案，需结合风险分析。

## 用小实验拆开因果链：测一次协变量偏移

### 第 1 步：数据绑定本体/控制/校准/任务版本

- **这一步在验证：**模仿学习能否支持“怎样减少协变量偏移”这项判断。
- **至少留下：**成功率、完成时间、部分进展与恢复。
- **先停下来而不是继续调参的信号：**随机切帧泄漏轨迹。

### 第 2 步：场景级去重与时间外切分

- **这一步在验证：**强化/离线学习能否支持“何时允许在线探索”这项判断。
- **至少留下：**碰撞/力/间隔/约束违例和人工接管。
- **先停下来而不是继续调参的信号：**只收成功造成覆盖空洞。

### 第 3 步：测策略访问状态到数据支持距离

- **这一步在验证：**机器人数据治理能否支持“更多轨迹是否真的增加覆盖”这项判断。
- **至少留下：**对象、场景、语言、本体和扰动切片。
- **先停下来而不是继续调参的信号：**离线 Q 高就相信。

### 第 4 步：采集接管/恢复并做因果对照

- **这一步在验证：**模仿学习能否支持“怎样减少协变量偏移”这项判断。
- **至少留下：**控制频率、P95、算力、数据/人工和能耗。
- **先停下来而不是继续调参的信号：**示范动作与实机控制频率错位。

完成示范后再做一次变式：训练简单 BC，故意扰动初始状态；记录错误随 horizon 累积，再加入少量纠正轨迹，比较恢复和 OOD 检测。

## 做到什么，才算结果可信

| 观察维度 | 要留下的记录 | 它防止你误判什么 |
|---|---|---|
| 任务 · 模仿学习 | 成功率、完成时间、部分进展与恢复 | 一次漂亮成功不能表示可靠性；本章还要据此判断：怎样减少协变量偏移 |
| 过程 · 强化/离线学习 | 碰撞/力/间隔/约束违例和人工接管 | 结果正确也可能过程危险；本章还要据此判断：何时允许在线探索 |
| 泛化 · 机器人数据治理 | 对象、场景、语言、本体和扰动切片 | 平均分不说明分布外边界；本章还要据此判断：更多轨迹是否真的增加覆盖 |
| 系统 · 模仿学习 | 控制频率、P95、算力、数据/人工和能耗 | 策略必须在真实闭环预算运行；本章还要据此判断：怎样减少协变量偏移 |

## 实验结果怎样进入系统

### 1. 失败/接管片段不自动丢弃

验收时查看 **任务**，至少保存成功率、完成时间、部分进展与恢复。如果观察到“随机切帧泄漏轨迹”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 2. 离线策略 OOD 触发拒绝/求助

验收时查看 **过程**，至少保存碰撞/力/间隔/约束违例和人工接管。如果观察到“只收成功造成覆盖空洞”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 3. 在线探索限定 sandbox

验收时查看 **泛化**，至少保存对象、场景、语言、本体和扰动切片。如果观察到“离线 Q 高就相信”，这项决定必须重新评审，不能因为已经实现就默认保留。

### 4. 数据权和人员隐私进入治理

验收时查看 **系统**，至少保存控制频率、P95、算力、数据/人工和能耗。如果观察到“示范动作与实机控制频率错位”，这项决定必须重新评审，不能因为已经实现就默认保留。

## 当假设被破坏，会先出现什么

先排除这些误解：更多成功轨迹等于覆盖；随机切帧可泛化；离线 RL 无安全风险；专家动作是唯一最优；数据飞轮自动形成。

### 随机切帧泄漏轨迹

- **先看什么：**成功率、完成时间、部分进展与恢复
- **回到哪项控制：**失败/接管片段不自动丢弃
- **怎样留下证据：**保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“测一次协变量偏移”的回归记录。

### 只收成功造成覆盖空洞

- **先看什么：**碰撞/力/间隔/约束违例和人工接管
- **回到哪项控制：**离线策略 OOD 触发拒绝/求助
- **怎样留下证据：**保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“测一次协变量偏移”的回归记录。

### 离线 Q 高就相信

- **先看什么：**对象、场景、语言、本体和扰动切片
- **回到哪项控制：**在线探索限定 sandbox
- **怎样留下证据：**保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“测一次协变量偏移”的回归记录。

### 示范动作与实机控制频率错位

- **先看什么：**控制频率、P95、算力、数据/人工和能耗
- **回到哪项控制：**数据权和人员隐私进入治理
- **怎样留下证据：**保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“测一次协变量偏移”的回归记录。

### 探索奖励绕过安全

- **先看什么：**成功率、完成时间、部分进展与恢复
- **回到哪项控制：**失败/接管片段不自动丢弃
- **怎样留下证据：**保存触发条件、原始输入、系统响应和人工处置；修复后把同一样本加入“测一次协变量偏移”的回归记录。

## 本章小结

- 模仿学习受部署分布影响
- 离线价值有外推风险
- 恢复片段比重复成功更稀缺
- 数据版本包含本体和控制语义
