## 为什么现在要学“机器人需要 Belief，不只需要状态值”

公式不是装饰。它的价值是迫使我们写清对象、假设和优化目标，再检查现实是否满足。

**本章核心判断：** Belief State 用分布表达部分可观测性，规划与控制应依据置信而非伪精确单值。

本章只追一个判断：**部分可观测下怎样把不确定性带入规划和控制？** 最后必须用“状态分布、一致性与拒绝门槛”来回答；如果产物不能暴露失败样本，就还不能算学会。

上一主题“检测、分割与六维位姿”提供前置条件，本章用 **传感标定** 解释关键机制，并把结果留在“状态分布、一致性与拒绝门槛”中。下一主题“里程计、地图与漂移”只在这些证据成立后继续。 只要中间任一环只能凭主观解释，结论就应降级为假设。

### 第三步：主动寻找反例

先尝试制造“mAP 高就抓得准”。如果当前方法仍给出看似正常的平均分，说明评价没有覆盖真正风险，需要补切片、过程指标或拒绝条件。

当前决定是“外参变化触发全链回归”。同时写下适用条件、责任人和重新评审信号；这样新证据出现时能更新，而不是把旧结论当永久规则。

## 当 传感标定 失效，先查哪里

先排除这些看似合理的误解：2D 检测足以操作；渲染逼真等于物理正确；多视角消除所有遮挡；协方差越小越好；标定一次永久有效。

### 静态精度外推动态人

先查看 **系统**：控制频率、P95、算力、数据/人工和能耗。如果证据确认失败，回到“外参变化触发全链回归”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

### mAP 高就抓得准

先查看 **任务**：成功率、完成时间、部分进展与恢复。如果证据确认失败，回到“感知输出 frame/time/covariance”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

本章的边界不是一句“视情况而定”，而是能写进测试、监测或人工审核条件的触发器。
