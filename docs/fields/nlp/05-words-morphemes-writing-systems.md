## 为什么现在要学“词、词素与文字系统”

很多误判并非算错，而是把两个相近词当成同一件事。围绕 **切分单位**，本章先建立可反驳的定义。

**本章核心判断：** 词是理论单位而非跨语言自然常数，形态和书写系统决定可接受的分割假设。

本章只追一个判断：**中文、黏着语和拼音文字为何不能共享一种‘词’假设？** 最后必须用“跨语言切分现象图”来回答；如果产物不能暴露失败样本，就还不能算学会。

## 两份证据把“词、词素与文字系统”的边界画在哪里

### SentencePiece（2018-08-21）

这项工作追问：能否直接从原始句子学习语言无关的子词模型？

SentencePiece 将空格当普通符号，在固定词表下提供 Unigram/BPE 和可逆切分，避免依赖语言特定预分词。 论文在日英翻译等设置展示与传统子词管线相当或更好的结果，并简化多语言处理。

本章据此采用的判断是：**建立了现代多语言 tokenizer 的可复现基础。** 但不能外推到：语言无关实现不等于语言公平；训练混合和词表容量仍决定分配。

### Byte Latent Transformer（2024-12-13）

本章用它校准“词、词素与文字系统”的边界：提供按信息复杂度而非固定词表分配计算的路线。。**不要越过的边界：**结果来自特定规模与训练配方；推理栈、缓存和真实多语言成本仍需独立测量。

两份来源若结论看似冲突，先比较任务定义、数据分布、资源预算和评价方法；不能只用发布日期或排行榜高低裁决。

## 当 切分单位 失效，先查哪里

先排除这些看似合理的误解：Tokenizer 只是工程预处理；词表越大越好；无 OOV 等于跨语言公平；更少 token 必然更强；换 tokenizer 不影响模型接口。

### 只报告平均 token 长度

先查看 **任务质量**：主指标、分层指标、置信区间和失败类型。如果证据确认失败，回到“上下文窗口按最差语言预算”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

### 训练测试使用不同规范化

先查看 **资源经济**：训练/推理/标注成本、吞吐、容量与能耗。如果证据确认失败，回到“费用/延迟看每项任务而非每 token 单价”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

本章的边界不是一句“视情况而定”，而是能写进测试、监测或人工审核条件的触发器。
