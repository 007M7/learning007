## 为什么现在要学“Tokenizer 的成本与语言公平”

先还原现场：构造语义对齐的 1,000 段合同，分别统计字符、字节、token、截断位置和实体破碎率。固定语义内容与模型，比较子词和 byte/patch 方案在条款检索、金额抽取、吞吐和费用上的 Pareto；额外加入拼写噪声、混语和罕见公司名。

**本章核心判断：** Tokenizer 决定序列长度、成本和上下文份额，语言间膨胀率是产品公平与容量问题。

本章只追一个判断：**同一句话为何在不同语言中消耗不同 Token 与上下文？** 最后必须用“多语言膨胀率与成本审计”来回答；如果产物不能暴露失败样本，就还不能算学会。

## 两份证据把“Tokenizer 的成本与语言公平”的边界画在哪里

### SentencePiece（2018-08-21）

本章用它校准“Tokenizer 的成本与语言公平”的边界：建立了现代多语言 tokenizer 的可复现基础。。**不要越过的边界：**语言无关实现不等于语言公平；训练混合和词表容量仍决定分配。

### Byte Latent Transformer（2024-12-13）

这项工作追问：固定 token 是否是扩展语言模型的必要前提？

BLT 在字节层建模，以熵阈值形成动态 patch，并在局部 byte 编码器与全局 latent Transformer 之间传递表示。 作者报告在相近训练 FLOPs 下可匹配 token 模型，并在噪声和字符任务上表现出优势。

本章据此采用的判断是：**提供按信息复杂度而非固定词表分配计算的路线。** 但不能外推到：结果来自特定规模与训练配方；推理栈、缓存和真实多语言成本仍需独立测量。

两份来源若结论看似冲突，先比较任务定义、数据分布、资源预算和评价方法；不能只用发布日期或排行榜高低裁决。

### 第二步：写出中间机制

上一主题“BPE 与 SentencePiece 如何学词表”提供前置条件，本章用 **Tokenizer 公平性** 解释关键机制，并把结果留在“多语言膨胀率与成本审计”中。下一主题“字节级模型与开放词汇边界”只在这些证据成立后继续。 只要中间任一环只能凭主观解释，结论就应降级为假设。

### 第三步：主动寻找反例

先尝试制造“认为无 OOV 就没有语言偏差”。如果当前方法仍给出看似正常的平均分，说明评价没有覆盖真正风险，需要补切片、过程指标或拒绝条件。

### 第四步：把结论写成可撤回决定

当前决定是“费用/延迟看每项任务而非每 token 单价”。同时写下适用条件、责任人和重新评审信号；这样新证据出现时能更新，而不是把旧结论当永久规则。

这条推理链最终必须落到 **多语言膨胀率与成本审计**。只有定义、机制、观察和决定互相对得上，文章内容才真正进入工作系统。

## “同一句话为何在不同语言中消耗不同 Token 与上下文？”依赖哪些前提

本章暂时不展开整套推导，但必须把判断拆成可以检查的前提：

| 顺序 | 必须成立的前提 | 对应控制 |
|---|---|---|
| 1 | Unicode 归一化和空白规则是否改变实体；在“Tokenizer 的成本与语言公平”中必须显式核对 | 上下文窗口按最差语言预算 |
| 2 | 训练词表的语言/领域配比；在“Tokenizer 的成本与语言公平”中必须显式核对 | 缓存同时保存原文、字符偏移与 token 偏移 |
| 3 | 长度比较使用字符、字节还是语义对齐段落；在“Tokenizer 的成本与语言公平”中必须显式核对 | 费用/延迟看每项任务而非每 token 单价 |
| 4 | 特殊 token、注入和反序列化是否安全；在“Tokenizer 的成本与语言公平”中必须显式核对 | Tokenizer 更新视为数据接口破坏性变更 |

这四项共同约束“同一句话为何在不同语言中消耗不同 Token 与上下文？”。任何一项只能靠猜测回答时，都应降低结论强度或补实验。

## 当 Tokenizer 公平性 失效，先查哪里

先排除这些看似合理的误解：Tokenizer 只是工程预处理；词表越大越好；无 OOV 等于跨语言公平；更少 token 必然更强；换 tokenizer 不影响模型接口。

### 训练测试使用不同规范化

先查看 **资源经济**：训练/推理/标注成本、吞吐、容量与能耗。如果证据确认失败，回到“费用/延迟看每项任务而非每 token 单价”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

### 认为无 OOV 就没有语言偏差

先查看 **任务质量**：主指标、分层指标、置信区间和失败类型。如果证据确认失败，回到“上下文窗口按最差语言预算”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

本章的边界不是一句“视情况而定”，而是能写进测试、监测或人工审核条件的触发器。

| 决定 | 验收依据 | 重新评审的信号 |
