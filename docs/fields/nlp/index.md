## 本领域的五条当前判断

1. NLP 前沿已从英语平均榜转向多语言、地方知识与真实有效上下文
2. 标称百万 token 不能代替位置×长度×语言利用测试
3. Byte/动态 patch 重新打开固定 tokenizer 之外的设计空间
4. 事实性评价从答案总分转向 claim—evidence 与评价器校准
5. 高效 encoder 与专用结构模型仍在大量生产任务保持独立价值

## 每章怎样学

每章都遵守同一个闭环：问题定义 → 机制与公式 → 一手证据拆解 → 贯穿案例 → 最小复现 → 失败边界 → 练习 → 自测 → 作品证据。论文摘要、视频演示、运行截图和“我懂了”都不能单独证明掌握。

## 贯穿项目

一个中文优先、可追溯、可拒答、跨语言可评测的领域文本理解与生成系统。

最终验收至少包括：

- 中英与至少一个低资源/混语切片
- 版本化语料、授权、标注指南和分歧记录
- 规则/专用模型/生成或检索三层基线
- claim 证据、无法回答和人工接管
- 质量—成本—延迟—风险与线上回归
