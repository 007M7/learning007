## 本领域的五条当前判断

1. 表格基础模型已成为小中型 IID 数据的强候选，但 2026 年 BeyondArena 显示非 IID、大规模与高维任务仍不存在统一冠军。
2. 模型选择从点预测分数扩展到条件覆盖、校准、成本、延迟和许可；高性能与高可靠性可能分离。
3. 分布无关保证有明确的交换性边界；真实时间偏移下必须诊断覆盖失败，而不是引用理论口号。
4. 因果学习的主要瓶颈仍是设计、识别和真实干预证据，不是更灵活的预测器。
5. 生产 ML 的核心资产是版本化数据与评测闭环；模型类别会变，任务合同和失败证据会复利。

## 每章怎样学

每章都遵守同一个闭环：问题定义 → 机制与公式 → 一手证据拆解 → 贯穿案例 → 最小复现 → 失败边界 → 练习 → 自测 → 作品证据。论文摘要、视频演示、运行截图和“我懂了”都不能单独证明掌握。

## 贯穿项目

一套能解释数据切分、基线、校准、偏移、因果边界与上线监控的风险预测系统。

最终验收至少包括：

- 任务定义含预测时点、样本单位、标签成熟、成本矩阵和禁止特征
- 至少包含 dummy、规则、线性/树模型和一个现代候选的公平对照
- 随机、时间或群组切分与部署目标一致，且自动检查泄漏
- 同时报告区分、校准、不确定性、关键切片、成本和资源
- 完成 shadow、灰度、漂移诊断和回滚演练，能重建任意预测
