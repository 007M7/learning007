## 为什么现在要学“特征重要性为什么经常撒谎”

先还原现场：数据包含套餐、使用量、工单、合同期限和地区。

**本章核心判断：** 归因描述模型在当前数据上的行为，不是变量的因果贡献；相关与代理特征会重分配重要性。

本章只追一个判断：**相关特征、代理变量和分布变化会怎样改写 SHAP 排名？** 最后必须用“三种归因对照与不可外推清单”来回答；如果产物不能暴露失败样本，就还不能算学会。

## 在“客户续费概率”中定位关键判断

数据包含套餐、使用量、工单、合同期限和地区。逻辑回归先提供可解释基线；CatBoost 处理高基数类别，XGBoost 使用显式编码。时间切分模拟下月续费，客户 ID 永不作为特征。比较不仅看 AUC，还看概率校准、前 5% 营销容量内增益、推理 P95、模型大小和重要性在不同时间窗的稳定性。

| 检查点 | 应留下的证据 | 不能接受的替代品 |
|---|---|---|
| 决策树 | 主指标、切片指标、无效/拒绝比例，并写入三种归因对照与不可外推清单 | 避免平均分掩盖关键用户或条件 |
| Bagging | 校准、方差、置信区间、最坏切片，并写入三种归因对照与不可外推清单 | 知道预测何时不可直接行动 |
| Boosting | 训练/推理时间、内存、能耗或费用，并写入三种归因对照与不可外推清单 | 确认提升不是无限预算换来的 |

案例不是为了模仿结论，而是为了练习定位：如果“只比较默认线性模型与精调 boosting”发生，先查哪条数据或控制链，再决定继续、拒绝或交给人。

## 给“特征重要性为什么经常撒谎”一个可操作定义

归因描述模型在当前数据上的行为，不是变量的因果贡献；相关与代理特征会重分配重要性。

可操作定义必须允许你回答三件事：输入或条件是什么，发生了哪条机制，最后观察什么才算支持结论。本章的观察出口是 **三种归因对照与不可外推清单**。

### 三个支撑概念，而不是本章的替代标题

| 位置 | 概念 | 在本章中的作用 | 一旦误用会怎样 |
|---|---|---|---|
| 前置 | Boosting | 逐步拟合梯度/残差以构造加法模型 | 把高基数 ID 当正常类别 |

### Beyond IID: How General Are Tabular Foundation Models, Really?（2026-06-29）

本章用它校准“特征重要性为什么经常撒谎”的边界：贡献是把基准从基础模型擅长的区域扩到真实困难区域。。**不要越过的边界：**预印本和统一框架可能无法包含每个模型的最优领域调参；排名不能替代本地任务对照。

## 沿着一条完整推理链走到底

### 第一步：固定要解释或改变的对象

不要用“整体效果更好”代替对象。把“相关特征、代理变量和分布变化会怎样改写 SHAP 排名？”改写为：在明确输入、时间点和约束下，观察什么量，比较什么基线，最后据此采取什么动作。

### 第二步：写出中间机制

上一主题“Boosting：沿着损失梯度加树”提供前置条件，本章用 **决策树** 解释关键机制，并把结果留在“三种归因对照与不可外推清单”中。下一主题“尺度与距离定义了模型眼中的世界”只在这些证据成立后继续。 只要中间任一环只能凭主观解释，结论就应降级为假设。

### 第三步：主动寻找反例

先尝试制造“把高基数 ID 当正常类别”。如果当前方法仍给出看似正常的平均分，说明评价没有覆盖真正风险，需要补切片、过程指标或拒绝条件。

### 第四步：把结论写成可撤回决定

当前决定是“解释性结论必须附相关特征和扰动稳定性”。同时写下适用条件、责任人和重新评审信号；这样新证据出现时能更新，而不是把旧结论当永久规则。

这条推理链最终必须落到 **三种归因对照与不可外推清单**。只有定义、机制、观察和决定互相对得上，文章内容才真正进入工作系统。

## “相关特征、代理变量和分布变化会怎样改写 SHAP 排名？”依赖哪些前提

本章暂时不展开整套推导，但必须把判断拆成可以检查的前提：

| 顺序 | 必须成立的前提 | 对应控制 |
|---|---|---|
| 1 | 贪心分裂不是全局最优树；在“特征重要性为什么经常撒谎”中必须显式核对 | 表格任务默认保留 GBDT 强基线 |
| 2 | bagging 只有在基学习器误差不完全相关时有效；在“特征重要性为什么经常撒谎”中必须显式核对 | 模型选择使用预算相同的嵌套验证而非各跑默认值 |
| 3 | boosting 的迭代轮数与学习率不能分别孤立解释；在“特征重要性为什么经常撒谎”中必须显式核对 | 类别编码、缺失方向和单调约束进入模型合同 |
| 4 | 类别统计必须严格保持时间/折内因果顺序；在“特征重要性为什么经常撒谎”中必须显式核对 | 解释性结论必须附相关特征和扰动稳定性 |

这四项共同约束“相关特征、代理变量和分布变化会怎样改写 SHAP 排名？”。任何一项只能靠猜测回答时，都应降低结论强度或补实验。

## 当 决策树 失效，先查哪里

先排除这些看似合理的误解：树不需要任何数据治理；随机森林一定不会过拟合；boosting 轮数越多越好；SHAP 等于因果贡献；最新基础模型已经淘汰 GBDT。

### 只比较默认线性模型与精调 boosting

先查看 **运维**：漂移、缺失、延迟、人工接管和回滚。如果证据确认失败，回到“解释性结论必须附相关特征和扰动稳定性”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

### 把高基数 ID 当正常类别

先查看 **任务**：主指标、切片指标、无效/拒绝比例。如果证据确认失败，回到“表格任务默认保留 GBDT 强基线”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

本章的边界不是一句“视情况而定”，而是能写进测试、监测或人工审核条件的触发器。

## “三种归因对照与不可外推清单”怎样进入真实系统

| 决定 | 验收依据 | 重新评审的信号 |
|---|---|---|
| 解释性结论必须附相关特征和扰动稳定性 | 漂移、缺失、延迟、人工接管和回滚 | 只比较默认线性模型与精调 boosting |
| 表格任务默认保留 GBDT 强基线 | 主指标、切片指标、无效/拒绝比例 | 把高基数 ID 当正常类别 |

这些不是永久最佳实践，而是当前证据下的可逆决定。把决定、理由、适用范围和退出信号一起写进“三种归因对照与不可外推清单”，否则下一次改动只能重新争论。

## 把“特征重要性为什么经常撒谎”迁移到新条件

围绕“特征重要性为什么经常撒谎”完成如下变式：在一个包含相关特征的数据集上训练 boosting，分别计算 gain、permutation 和 SHAP；删除或复制一个强相关变量后观察排名变化，写出不能从重要性推出的结论。

提交“三种归因对照与不可外推清单”时同时附上：

1. 一个成功样本和一个失败样本；
2. 失败推翻了哪条假设，而不只是报错信息；
3. 哪项结论来自公开来源，哪项只来自你的本地实验；
4. 如果换数据、人群、环境或本体，最先需要重测什么；
5. 当前仍无法消除的残余风险。
