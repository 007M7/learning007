## 为什么现在要学“异质处理效应与 Double ML”

前沿方法通常是在旧边界上交换了新的成本。我们要分清稳定机制、近期证据和仍未解决的问题。

**本章核心判断：** Double ML 用交叉拟合削弱高维干扰估计偏差，却不能替代因果识别和重叠条件。

本章只追一个判断：**机器学习怎样估计谁受益，同时避免把拟合能力当因果识别？** 最后必须用“交叉拟合、uplift 与敏感性分析”来回答；如果产物不能暴露失败样本，就还不能算学会。

## 两份证据把“异质处理效应与 Double ML”的边界画在哪里

### Double/Debiased Machine Learning（2018-01-25）

本章用它校准“异质处理效应与 Double ML”的边界：贡献是把预测器作为因果估计组件而非因果结论本身。。**不要越过的边界：**它依赖识别、收敛率和正值性等条件；不能处理任意未观测混杂。

### Causal Chambers as a Real-world Physical Testbed（2025-01-15）

本章用它校准“异质处理效应与 Double ML”的边界：贡献是把真实干预和可重复地面真值引入算法评测。。**不要越过的边界：**小型受控装置仍与社会、医疗等开放系统差距大，不能证明跨领域外部有效性。

### CausalBench（2025-03-11）

本章用它校准“异质处理效应与 Double ML”的边界：贡献是用真实干预数据挑战合成基准的乐观排序。。**不要越过的边界：**基因网络的测量噪声、部分干预和领域指标不等同于一般产品 A/B 因果问题。

两份来源若结论看似冲突，先比较任务定义、数据分布、资源预算和评价方法；不能只用发布日期或排行榜高低裁决。

### 第三步：主动寻找反例

先尝试制造“把特征重要性当干预杠杆”。如果当前方法仍给出看似正常的平均分，说明评价没有覆盖真正风险，需要补切片、过程指标或拒绝条件。

## 当 因果问题 失效，先查哪里

先排除这些看似合理的误解：预测准确即可指导干预；DAG 可从数据唯一学出；控制变量越多越安全；Double ML 消除未观测混杂；子组效果高就能立即个性化。

### 从探索分群挑最好子组

先查看 **运维**：漂移、缺失、延迟、人工接管和回滚。如果证据确认失败，回到“无法识别时输出预测或描述，不包装成因果”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

### 把特征重要性当干预杠杆

先查看 **任务**：主指标、切片指标、无效/拒绝比例。如果证据确认失败，回到“因果 estimand、干预版本和时间窗进入实验合同”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

本章的边界不是一句“视情况而定”，而是能写进测试、监测或人工审核条件的触发器。
