## 两份证据把“表格基础模型的先验从哪里来”的边界画在哪里

### Accurate Predictions on Small Data with TabPFN（2025-01-09）

本章用它校准“表格基础模型的先验从哪里来”的边界：贡献是证明摊销的任务级预训练可成为表格学习新范式。。**不要越过的边界：**论文适用规模、GPU条件和基准组成明确；不能外推到任意大表、时间偏移和高维文本字段。

### Beyond IID（2026-06-29）

这项工作追问：标准基准是否系统遗漏表格基础模型困难的任务？

BeyondArena 用 Data Foundry 统一 142 个数据集，覆盖 IID、时间、群组、规模、高维、高基数和文本特征，比较 11 个模型。 结果显示表格基础模型在小中型 IID 强，但树与传统深度模型在非 IID、大型和高维仍占优。

本章据此采用的判断是：**它把“基础模型是否通用”改为按任务形态分区的实证问题。** 但不能外推到：预印本会随模型版本快速变化；本地数据仍需复测，不能只引用总体平均排名。

### High Performance, Low Reliability（2026-05-27）

本章用它校准“表格基础模型的先验从哪里来”的边界：贡献是给选型增加可靠性轴，而非只追逐平均分。。**不要越过的边界：**条件覆盖指标和 conformal 构造有特定假设，不能把结论泛化成基础模型永远不校准。

两份来源若结论看似冲突，先比较任务定义、数据分布、资源预算和评价方法；不能只用发布日期或排行榜高低裁决。

## 在“中小企业应收账款风险”中定位关键判断

## 当 公平门禁 失效，先查哪里

先排除这些看似合理的误解：基础模型等于任何数据都通用；不做梯度训练等于没有计算成本；AutoML 消除了实验设计；总体平均排名可直接采购；点预测最强就最可靠。

### 只用其擅长的小 IID 基准

先查看 **资源**：训练/推理时间、内存、能耗或费用。如果证据确认失败，回到“AutoML 保存完整搜索轨迹和失败 trial”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

先查看 **任务**：主指标、切片指标、无效/拒绝比例。如果证据确认失败，回到“建立任务形态路由而非统一默认模型”，保存触发输入、系统响应和人工处置，再把样本加入回归集。
