# 23 · 正则化如何用偏差换取稳定

> 模型把训练样本记得越细，越容易把偶然差异带到未来。正则化提前声明我们愿意放弃哪些拟合自由，换来怎样的稳定性。

## 十个几乎相同的指标争夺一个系数

需求预测模型包含十个高度相关的促销指标。未正则化线性回归在验证集表现尚可，更换一个训练月份后，某个指标系数从正数变成负数，另一个指标承担了原来的解释。预测整体变化不大，团队却无法根据系数制定稳定规则。

数据没有提供足够证据区分这十列的独立作用。模型仍要选一组参数，微小样本变化便会在相似方向之间重新分配权重。

L2 正则把系数平方和加入目标。

$$
\hat\beta=\arg\min_\beta\left[\sum_i(y_i-x_i^T\beta)^2+\lambda\sum_j\beta_j^2\right]
$$

$\lambda$ 增大后，大系数付出更多代价，相关变量往往共同收缩。训练误差上升，系数和预测可能更稳定。

> 正则化表达一项偏好。模型需要额外证据才能使用更大系数、更复杂边界或更长训练过程。这项偏好是否合适，要由未来数据验证。

## 偏差与方差怎样出现在重复训练里

想象从同一总体重复抽取训练集，每次拟合一个模型。预测误差可以从噪声、偏差和方差理解。偏差高说明平均预测系统性偏离真实关系，方差高说明训练集轻微变化便改变预测。

复杂度增加通常降低训练偏差，也可能提高方差。这个图景不是每个现代模型的机械定律，却是正则实验的有效问题。模型究竟在欠拟合，还是在追随抽样波动？

单次训练与测试无法直接看到重复抽样。可以用 bootstrap、多个时间窗口或多随机种子近似观察。记录对象级预测分布，比分数标准差更具体。总体指标稳定，少量高代价对象仍可能反复跨越阈值。

不可约噪声来自同样输入下结果仍然随机或测量不完整。继续增加模型容量无法消除它。若误差集中在标签争议与不可观测事件，正则强度搜索不会创造信息。

## L2 收缩解决近共线与过大权重

Ridge 使 $X^TX+\lambda I$ 更容易求解，改善近共线问题的条件数。它保留所有特征，适合许多变量都携带少量信息的情况。

系数解释要经过尺度。标准化后，同一 $\lambda$ 对各列施加可比惩罚；未标准化时，单位大的特征可以用较小系数表达同样变化，从而受到较少惩罚。缩放器应在训练折拟合。

通常不惩罚截距，因为它表示目标基线，是否惩罚仍取决于实现。类别变量展开成多列以后，逐列 L2 会让一个原始字段的总惩罚随编码变化。组正则在需要整体选择字段时更合适。

$\lambda$ 的数值还受损失是否取均值影响。不同库或样本量下复制参数没有保证。报告应保存目标函数的完整定义，不只保存 `alpha=1`。

## 从概率视角看惩罚项

L2 也可以理解为给参数放置零均值高斯先验，L1 对应拉普拉斯先验。在最大后验估计里，负对数先验成为目标中的惩罚项。这个视角说明收缩偏好从哪里来，也说明正则强度与噪声尺度、样本量的关系。

先验解释不能自动证明参数真的服从某个分布。它提供一套概率建模语言，让团队检查“多数系数应接近零”或“参数应平滑变化”是否符合领域知识。若需要完整不确定性，应做后验推断，点估计加惩罚只给出一个解。

结构化正则可以表达更具体偏好。Group lasso 让一组编码共同进入或退出，fused lasso 惩罚相邻系数差异，图正则利用已知关系约束参数。结构写错会系统性压制真实差异，所以仍要用独立数据和反例检验。

## L1 为什么会产生零系数

Lasso 使用绝对值惩罚。

$$
\hat\beta=\arg\min_\beta\left[\sum_i(y_i-x_i^T\beta)^2+\lambda\sum_j|\beta_j|\right]
$$

L1 在零点有尖角，优化解更容易落在坐标轴上，得到稀疏系数。它可以同时拟合与选择变量，稀疏不等于找到了真实原因。

高度相关变量中，Lasso 可能任意保留一个，其余压到零。换一批样本，被保留的变量就会交换。若产品需要稳定字段列表，应做重采样选择频率，而非读取一次非零系数。

Elastic net 组合 L1 与 L2，既允许稀疏，又鼓励相关变量更成组地保留。两个正则参数增加了搜索空间，选择必须在嵌套或独立验证中完成。

稀疏模型的维护成本有时更低，线上特征更少、采集依赖更少。这是工程收益，需要与预测稳定、字段获取成本和业务可解释性一起评价。

## 早停是沿优化路径选择复杂度

迭代模型在训练初期先学普遍结构，后期继续追随细节。早停根据验证表现选择某个训练时刻，等于限制模型沿优化路径走多远。

早停强度由学习率、批量、优化器、检查频率与耐心共同决定。相同训练轮数在两种优化器下不代表相同复杂度。恢复训练时必须恢复优化器和早停状态。

验证集被用来选择停止轮次，就已经参与模型训练。最终性能还要在独立测试集评价。反复观察测试曲线再修改耐心，会把测试变成验证集。

早停可以与 weight decay 并用。两种约束相互影响，分别找到的最佳值组合后未必最佳。实验应先确定有限联合空间，再在固定预算下选择。

## 数据增强把不变性写进训练样本

图像翻转、裁剪、颜色扰动，文本遮盖或表格中的领域允许扰动，都可以扩展训练样本。增强隐含一条判断，变换以后标签应保持不变或按已知方式改变。

判断错误会制造标签噪声。医疗影像左右翻转可能改变解剖含义，时间序列打乱顺序会破坏事件，表格对金额随意加噪可能越过业务规则。增强策略必须由数据机制支持。

增强也不能提前作用于验证和测试，除非评价协议明确采用测试时增强，并汇总同一对象多次变换的预测。随机增强种子、强度和顺序属于模型版本。

数据增强常降低模型对特定输入细节的敏感性，它约束的是函数在变换邻域内的行为。L1 与 L2 约束参数，早停约束路径。四种方法都叫正则化，限制对象并不相同。

## 正则路径比一个最佳点更有信息

从极弱到极强选择一组对数尺度的 $\lambda$。每个值记录训练误差、验证误差、系数范数、非零特征数与跨重采样稳定性。

弱正则区域训练分数好，验证波动可能大。强正则区域参数接近零，训练与验证都差。中间通常有一段性能相近区域。若最佳点与相邻点差异落在不确定范围内，可以选择更简单、更稳定或成本更低的方案。

正则路径还会暴露数据问题。某个本应晚于预测时点生成的字段在很强正则下仍率先进入模型，应优先检查泄漏。某组相关变量在路径中反复交换，说明单变量解释不稳。

对分类概率，再检查 NLL、Brier 与校准曲线。正则强度会改变 logit 尺度和置信程度，只看 AUC 会漏掉概率变化。

## 完成正则路径与偏差方差报告

选择一个线性模型和一个可早停的树或神经网络。沿用同一数据切分，先训练弱正则基线，再建立候选强度。

线性模型分别比较 L2、L1 与 elastic net。每个设置做 bootstrap 或多个训练窗口，保存系数路径、非零频率、对象级预测方差和测试指标。对于高度相关变量，增加组内替换实验。

迭代模型比较 weight decay、早停与一个符合领域的增强。每次只改变一项，再在有限网格内观察交互。报告达到目标分数所需资源和最终校准。

交付物需要包含以下内容。

1. 训练与验证误差随正则强度的曲线。
2. 系数、非零特征或模型容量路径。
3. 多次重采样的性能与对象级稳定性。
4. 关键人群、校准和决策阈值的变化。
5. 最终选择、相邻替代方案与回退条件。

如果强正则让所有模型一起欠拟合，应减少限制或改善表示。如果弱正则的错误集中于标签和流程异常，先修数据。报告要把算法选择与数据修复分开。

部署后还应监控正则所依赖的稳定性。相关特征关系改变时，原来平稳的系数可能失去意义；增强假设被新产品规则打破时，不变性会变成偏差。正则方案与数据版本共同登记，重训时重新比较路径，而非永久沿用旧强度。

## 正则化不能替代验证隔离

尝试一百种正则强度，再挑验证集最高者，验证集也会被过拟合。正则化控制单个模型的复杂度，搜索过程本身又增加了一层选择复杂度。

下一章用嵌套交叉验证隔离调参与性能估计。当前章节留下的正则路径和搜索范围将成为内层选择空间，外层数据只用于评价整个选择流程。

## 与 AI 协作读正则路径

AI 可以汇总正则路径、找出系数交换和不稳定对象，并生成对照图。让它解释每种正则限制的是参数、训练时长还是输入变换，不要把所有方法混成同一种“防过拟合”。

AI 可以提出增强候选，标签保持假设必须由领域人员确认。任何会改变对象语义、时间顺序或权限条件的变换，都应先构造反例。
