# 机器学习板块学习总结 · 从问题到学习飞轮

## 五个阶段共同回答六个问题

一套机器学习系统无论使用线性模型、树、核方法还是表格基础模型，都要回答六个问题。

第一，系统在什么时刻为哪类对象作出什么判断。第二，训练样本怎样被现实流程生成，哪些信息在当时可见。第三，模型比最小基线多学到了什么，证据能否面对未来。第四，概率怎样经过阈值、容量与人工流程变成行动。第五，行动的效果、不确定性、群体伤害和环境变化怎样被限制。第六，系统上线后如何追溯、发布、监测、恢复与学习。

五个阶段对应这六个问题的依赖关系。

```text
阶段一  问题、数据与泛化
   ↓  确认训练任务值得比较
阶段二  可解释强基线
   ↓  建立概率、阈值与模型行为参照
阶段三  表示、训练与选型
   ↓  在公平证据和多目标约束下增加能力
阶段四  因果、可信与鲁棒
   ↓  限定行动、覆盖、群体和环境边界
阶段五  生产闭环
   └  用真实反馈更新前四个阶段
```

箭头表达前置，也允许返回。监测发现标签定义改变时要回到阶段一，事故暴露特征泄漏时回到数据与切分，策略没有效果时回到因果识别。学习飞轮由这些有证据的返回组成。

## 第一阶段建立的是实验合同

一句“预测流失”缺少对象、时点和行动。把它落到具体工作，需要定义实体键、决策时点、可见特征、结果窗口、标签成熟、损失、资源和非模型基线。

样本不是抽象的 $(x,y)$。一个样本代表某个对象在某个时点的观测，特征只能来自该时点前，标签在之后的观察窗中成熟。预测前可见性把线上世界带回训练数据，也决定什么属于泄漏。

数据表由采集、业务筛选、测量和旧政策共同生成。没有标签可能表示尚未成熟、没有被检查、对象退出或记录失败，与结果为零不同。缺失本身可能携带流程信息，也可能造成选择偏差。

切分协议模拟未来使用。时间依赖任务按过去预测未来，实体重复任务隔离对象，空间迁移任务保留目标区域。预处理、特征选择和调参都在训练折内拟合，最终测试只在选择完成后读取。

这一阶段交付问题定义卡、样本时间图、成本映射、数据生成图、标签规范、切分协议和泄漏攻击集。它们组成实验合同。缺少其中一项，模型比较可能回答另一个更容易的问题。

## 第二阶段教会你从可解释参照开始

线性回归把目标投影到特征张成空间。残差图会暴露非线性、异方差、遗漏结构和高影响点。广义线性模型进一步把响应分布、线性预测子和链接函数组合起来，使均值或概率的含义可检查。

逻辑回归的排序能力与概率质量分开评价。AUC 高只说明正例倾向排在负例前，不能保证 0.8 真的对应八成频率。Brier、NLL、可靠性图和分组校准检查概率，阈值再按错误代价、容量与伤害转成行动。

决策树用贪心轴对齐切分产生规则，容易理解，也容易随样本扰动。Bagging 平均不完全相关的高方差模型，随机森林通过特征随机性减少树间相关。Boosting 逐轮拟合当前损失的负梯度，以串行加法降低偏差，同时更容易追随泄漏与噪声。

特征重要性描述模型在当前数据上的依赖。相关特征会交换贡献，代理变量会携带敏感信息，分布改变会改写排名。置换、树内重要性和 SHAP 各有条件，都不能直接证明现实原因。

这一阶段的价值不是选出永远最强的模型。线性与树模型形成一条行为参照，模型升级必须说明新增表达能力、稳定收益、解释代价和失败边界。

## 第三阶段把模型选择扩展为系统选择

尺度、权重和距离决定模型眼中的相似。KNN 在局部支持充分时有意义，高维下最近邻仍可能很远。SVM 用间隔控制边界，核函数改变隐式相似空间。PCA 保留线性方差，UMAP优先局部邻域，二维布局需要保真与多种子检查。

表示之后才是训练。曲率和条件数解释梯度为何在不同方向难以前进，SGD、动量和自适应优化处理小批量噪声与计算预算。正则化用偏差换取方差、稀疏、平滑或稳定，不同方法约束的对象不同。

超参数搜索也是训练。反复读取验证集会产生选择偏差，嵌套交叉验证让内层做选择，外层评价整套选择流程。搜索空间、预算、失败试验和停止条件进入账本。

特征流水线把拟合边界和离在线语义写成可回放契约。AutoML 自动组合候选，无法修复错误目标、泄漏和禁止字段。表格基础模型将预训练任务先验带入新数据，优势取决于目标任务是否落在其先验与规模范围。

最终选择使用硬门槛和 Pareto 前沿。质量、校准、延迟、成本、稳定、可解释与维护互相冲突，没有一个平均分可以提前替团队决定取舍。

## 第四阶段改变模型能够支持的结论

预测询问当前世界中谁更可能发生结果，因果询问采取明确处理后结果怎样变化。高风险对象不一定最受益，风险排序不能直接成为干预排序。

DAG 将处理分配、共同原因、碰撞点和中介写成可审查假设。调整集来自目标效应与图结构，观察数据通常不能证明整张图。随机实验通过分配机制减少混杂，还要处理随机化单位、功效、意向性分析、流失、干扰和提前停止。

异质处理效应在识别成立后寻找收益差异。Double ML 的正交化与交叉拟合削弱高维辅助模型误差，无法创造缺失对照或消除未测混杂。风险、处理效应和资源资格保留为三个判断。

不确定性来源决定处置。结果随机性可能需要更保守行动，模型知识不足可能需要补数据或拒绝。校准检查长期频率，共形预测在交换性条件下提供边际覆盖。覆盖率与区间宽度、标签集合大小一起报告。

公平指标对应不同价值判断，基础率不同时常无法兼得。审查从伤害、分母、决策链和申诉开始。分布偏移则按环境机制设计压力情景，观察性能、校准、覆盖、公平和人工负担的退化曲线，提前设置拒绝与退出门槛。

这一阶段把“模型是否好”改写为“哪些结论在什么人群、环境和行动条件下可以被采用”。

## 第五阶段让结论经得起真实变化

可复现覆盖训练、评价和单次预测。数据快照、特征契约、代码、环境、配置、模型、阈值和政策共同版本化。模型登记卡记录血缘、评价、限制、状态和负责人，回滚恢复一个兼容组合。

候选模型先通过离线回归，再用影子流量检查真实输入与运行兼容，最后用金丝雀流量承担有限影响。成功指标、护栏和过程指标分开，扩量按伤害、可逆性、检测时间和人工能力决定。

监测沿服务、数据、特征、模型、政策、反馈和成熟结果展开。早期代理信号帮助限制影响，延迟标签按预测批次回填并验证真实损失。输入漂移触发诊断，通常不直接触发自动再训练。

事故响应先缓解和恢复，再从时间线、影响和促成条件学习。行动项必须有负责人、期限和故障注入证据。失败样本按机制进入数据契约、模型回归、政策模拟、发布门禁和响应演练。

生产闭环使新数据能够修正旧结论，也防止系统在没有审查时自行放大反馈。

## 四十章最后沉淀为十项核心判断

第一，先定义决定，再定义预测。对象、时点、行动和代价是算法的上游。

第二，数据是流程产物。样本选择、测量、缺失、标签成熟和旧政策都会进入模型。

第三，评价是在模拟部署。切分、预处理与调参边界错误时，分数没有外推依据。

第四，概率、排序和行动各有指标。阈值属于政策，会随成本、容量与伤害变化。

第五，复杂度必须相对强基线购买。新增能力要带来稳定收益，并承担资源、解释和维护代价。

第六，表示和搜索同样是模型。距离、预处理、验证读取次数和预算都会改变结论。

第七，预测不能代替干预效果。识别设计先于灵活估计器，异质性也受重叠与外推限制。

第八，可信是一组有条件证据。校准、覆盖、公平和鲁棒分别约束不同风险，没有通用可信分数。

第九，上线是一项受控实验。版本、影子、金丝雀、监测、降级和回滚共同限制未知影响。

第十，失败只有改变下一次系统行为才产生复利。复盘结论必须进入测试、门禁、数据、SOP 和责任。

## 用一个项目验收整条路线

选择一个有真实动作的任务，例如设备维护、需求补货或客户服务。先写任务卡和非模型基线，画出样本、特征与标签时间，重建数据生成过程，并选择符合部署目标的切分。

建立线性模型、树、Bagging、Boosting 与一个现代候选。报告排序、概率、成本、关键切片和资源。用残差、学习曲线、校准、稳定性和失败样本解释候选差异。

若目标包含干预，补充预测与干预对照卡、DAG、实验或观察协议。为单次输出建立不确定性来源与覆盖报告，完成群体伤害审查和环境压力测试。

最后交付版本清单、模型登记、影子对照、金丝雀门禁、分层监控、组合回滚和一次事故演练。任意选取一条历史预测，能够重建特征、分数、政策动作和当时依据。

项目验收看证据链是否闭合。一个候选即使分数最高，只要无法解释时间边界、关键群体、行动效果或回滚，仍未满足整板块目标。

## 怎样判断自己真正学会了

认识层能够解释主要术语和方法对象。基础掌握能够在新任务中完成五阶段最小产物，发现泄漏、校准、支持、覆盖和版本问题，并选择对应修复。

熟练掌握要求跨场景迁移。面对结果变差，你能区分任务漂移、数据故障、训练困难、泛化问题、选择偏差、政策变化和生产反馈。面对高分候选，你会主动寻找不能支持的结论。

真正的检验要求你判断当前问题属于哪一层、缺少什么证据、下一步最小实验是什么，以及何时应停止自动化。复述四十章无法单独证明这些能力。
