## 为什么现在要学“PCA 与 UMAP：漂亮图不等于真实结构”

先还原现场：营销团队想找“相似客户”。

**本章核心判断：** PCA 保留线性方差，UMAP 优先局部邻域；二维可视化不能单独证明真实群体存在。

本章只追一个判断：**二维簇能支持哪些结论，不能支持哪些结论？** 最后必须用“保真度、多种子稳定性与反例图”来回答；如果产物不能暴露失败样本，就还不能算学会。

## 在“相似客户检索与二维人群图”中定位关键判断

营销团队想找“相似客户”。先定义相似是消费结构、生命周期还是响应概率；类别特征不能直接当整数距离。使用 Gower/分块度量或经监督验证的表示，与 KNN、RBF-SVM 比较。二维 UMAP 只作探索，需报告 trustworthiness、不同种子邻居保持率和原空间下游效果，禁止仅凭图中簇给人群贴标签。

| 检查点 | 应留下的证据 | 不能接受的替代品 |
|---|---|---|
| 距离与邻域 | 主指标、切片指标、无效/拒绝比例，并写入保真度、多种子稳定性与反例图 | 避免平均分掩盖关键用户或条件 |
| 核与间隔 | 校准、方差、置信区间、最坏切片，并写入保真度、多种子稳定性与反例图 | 知道预测何时不可直接行动 |
| 降维 | 训练/推理时间、内存、能耗或费用，并写入保真度、多种子稳定性与反例图 | 确认提升不是无限预算换来的 |

案例不是为了模仿结论，而是为了练习定位：如果“使用测试标签调 UMAP”发生，先查哪条数据或控制链，再决定继续、拒绝或交给人。

### 第三步：主动寻找反例

先尝试制造“把类别编码当欧氏坐标”。如果当前方法仍给出看似正常的平均分，说明评价没有覆盖真正风险，需要补切片、过程指标或拒绝条件。

当前决定是“核方法超过样本/延迟边界时切换近似或树/神经基线”。同时写下适用条件、责任人和重新评审信号；这样新证据出现时能更新，而不是把旧结论当永久规则。

## 当 距离与邻域 失效，先查哪里

先排除这些看似合理的误解：标准化总是必要且只有一种方式；余弦相似等于语义相同；核方法显式创建全部高维特征；PCA 保留最有用信息；二维分离证明真实群体存在。

### 使用测试标签调 UMAP

先查看 **运维**：漂移、缺失、延迟、人工接管和回滚。如果证据确认失败，回到“核方法超过样本/延迟边界时切换近似或树/神经基线”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

### 把类别编码当欧氏坐标

先查看 **任务**：主指标、切片指标、无效/拒绝比例。如果证据确认失败，回到“距离度量与缩放作为模型版本的一部分”，保存触发输入、系统响应和人工处置，再把样本加入回归集。

本章的边界不是一句“视情况而定”，而是能写进测试、监测或人工审核条件的触发器。

## “保真度、多种子稳定性与反例图”怎样进入真实系统

| 决定 | 验收依据 | 重新评审的信号 |
|---|---|---|
| 核方法超过样本/延迟边界时切换近似或树/神经基线 | 漂移、缺失、延迟、人工接管和回滚 | 使用测试标签调 UMAP |
| 距离度量与缩放作为模型版本的一部分 | 主指标、切片指标、无效/拒绝比例 | 把类别编码当欧氏坐标 |

这些不是永久最佳实践，而是当前证据下的可逆决定。把决定、理由、适用范围和退出信号一起写进“保真度、多种子稳定性与反例图”，否则下一次改动只能重新争论。

## 把“PCA 与 UMAP：漂亮图不等于真实结构”迁移到新条件

围绕“PCA 与 UMAP：漂亮图不等于真实结构”完成如下变式：用同一数据改变 UMAP 邻居数、最小距离和种子，生成至少六种布局；量化同一点近邻变化，并写出哪些结论在所有布局下仍成立。

提交“保真度、多种子稳定性与反例图”时同时附上：

1. 一个成功样本和一个失败样本；
2. 失败推翻了哪条假设，而不只是报错信息；
3. 哪项结论来自公开来源，哪项只来自你的本地实验；
4. 如果换数据、人群、环境或本体，最先需要重测什么；
5. 当前仍无法消除的残余风险。
