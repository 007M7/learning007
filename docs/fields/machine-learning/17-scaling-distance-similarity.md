## 两份证据把“尺度与距离定义了模型眼中的世界”的边界画在哪里

### UMAP: Uniform Manifold Approximation and Projection（2018-09-18）

这项工作追问：能否以拓扑/流形假设构建兼顾速度和局部结构的降维方法？

UMAP 构造加权 k 近邻模糊图，再在低维优化图的交叉熵；邻居数和最小距离显式控制局部—全局权衡。 论文在多类数据展示较强运行速度和可视化表现，并讨论变换新数据与半监督扩展。

本章据此采用的判断是：**贡献是把局部流形、图构建和可扩展优化组合成通用工具。** 但不能外推到：二维布局仍高度依赖预处理、距离、参数和随机性，不能当聚类或统计显著性证据。
