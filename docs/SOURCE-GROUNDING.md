# 原稿与章节证据说明

> 主题规划、书目收集和文章完成是三种不同进度。本页公开区分它们，避免再把“找到链接”写成“读过原稿”。

## 五个状态

| 状态 | 只表示什么 | 还不能声称什么 |
|---|---|---|
| catalogued | 已确认书或论文的身份与官方地址 | 已拿到全文 |
| retrieved | 已从合法公开地址取得原稿或完整网页 | 已读过相关章节 |
| extracted | 已转为可检索文本，记录了哈希和页码 | 正文实际采用了观点 |
| read | 已阅读与某章命题有关的明确范围 | 其他章节也被覆盖 |
| cited | 采用观点、适用边界和目标章节都已登记 | 来源能替代本地实验 |

正式学习文章必须达到 `cited`，并在 `knowledge-base/fields/<field>/reading-evidence.json` 中留下章节级记录。原稿缓存在本地且不提交 Git；仓库只保存官方地址、文件哈希、阅读页码/章节和观点用途。

## 当前真实进度

机器学习前四章已经完成第一批原稿驱动重写：

1. 从业务愿望到可证伪任务；
2. 样本、特征与标签不是三张表；
3. 损失函数在替谁承担代价；
4. 经验风险、泛化与最小基线。

它们实际使用了三本已下载教材原稿和四篇由 Tavily 从论文 PDF 抽取的全文。其余领域页面仍是旧生成草稿，页面顶部会明确显示状态，不能计入正式完成数。

## 为什么不把整本书提交到仓库

即使作者允许在线阅读，也不代表本项目可以重新分发全文。原稿只在本地用于检索和核验；公开仓库保留可复核的哈希、官方链接和阅读范围。这样既能维护来源，也尊重不同许可证和版权边界。

## 正式章门禁

一篇领域文章进入正式状态前必须同时满足：

- 至少一份权威教材/专著的具体章或页已经实际阅读；
- 至少一篇关键论文、标准或一手报告已读到方法与限制，而非只看标题或摘要；
- 来源账本写明本章采用了什么、不能推出什么；
- 章节结构由本章学习任务决定，不复用固定标题签名；
- 例子、推导、练习与前后章产物相互衔接；
- 本地构建、链接、内容和来源真实性检查通过。
