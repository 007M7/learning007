# 15 题起点诊断

这不是考试。每题只选：`0 不知道`、`1 能在提示下解释`、`2 能独立解释并举例`、`3 在项目中验证过`。**不要把总分当能力排名**，只用错题选择 3—5 个近期节点。

## 软件与系统

1. 能沿输入、分支、调用、副作用解释一段 50 行代码吗？（SW01）
2. 为什么 TypeScript 类型不能验证网络 JSON？（SW02）
3. 一次网页请求经过 DNS、TCP、TLS、HTTP 哪些层？（SW07）
4. 怎样用数据库约束防止两个并发请求重复领取？（SW11/13）
5. 认证、授权、租户隔离分别回答什么？（SW14）

## 质量与交付

6. 能把模糊需求写成正常、异常、边界验收例吗？（Q01）
7. 单元、集成、契约和 E2E 各能发现什么？（Q02—06）
8. 能从全新目录用 lockfile 重建同一制品吗？（Q08）
9. 代码回滚为什么可能无法恢复数据库？（Q11）
10. 日志、指标、trace、备份恢复分别提供什么证据？（Q12—14）

## AI 与 Agent

11. 模型参数知识、上下文、RAG 来源和业务事实有何区别？（AI01）
12. 结构化输出合法为什么不等于内容正确？（AI03）
13. RAG 错误怎样拆成解析、召回、重排和生成？（AI05—08）
14. Tool Calling 中谁最终做授权和执行？（AI09—10）
15. Agent 怎样在进程崩溃、等待审批和重复消息后恢复？（AI13）

## 选近期节点

- 正在做普通 Web/业务系统：优先 SW01、SW07、SW10、Q01；
- 已能做功能但交付不稳：优先 Q03、Q08、Q12、SW13；
- 正在做 RAG：优先 AI01、AI03、AI06、AI08；
- 正在做工具 Agent：优先 AI03、AI09、AI10、AI13、AI16。

若大部分是 0，不从 51 节点同时开始。默认取 **SW01、SW02、SW07**，一周后再调。若大部分是 2，但没有 3，说明缺的是项目证据，直接进入[案例 02](/cases/02-task-runner)。
