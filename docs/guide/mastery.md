# 怎样判断真正掌握

“看懂了”和“能使用”之间还有一段距离。

## 基本掌握

一个知识节点至少需要：

1. 不看答案，用自己的话解释关键机制；
2. 完成一次基础应用或判断任务；
3. 最近相关练习平均不低于 7/10。

## 熟练掌握

在基本掌握之外，还需要：

- 解决一个变化后的问题；
- 指出常见错误、适用条件或失败边界；
- 在不同日期出现两次掌握证据；
- 最近相关练习平均不低于 8.5/10。

## 推荐证据

| 证据 | 示例 |
|---|---|
| 主动解释 | 画出请求从浏览器到数据库的路径 |
| 基础应用 | 给 API 加输入验证和统一错误体 |
| 变化任务 | 把同步接口改成长任务提交与查询 |
| 故障诊断 | 根据日志定位端口、权限或事务问题 |
| 项目产物 | 提交、测试报告、ADR或复盘 |
