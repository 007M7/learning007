# 12 周最小路线

这不是把全部内容顺读一遍，而是用同一个任务运行器反复增加约束。每周 3 次、每次 30—60 分钟：一次理解、一次实现、一次验证/复盘。忙时只保留“实现＋验证”。

| 周 | 活动节点（不超过 5） | 可交付证据 |
|---:|---|---|
| 1 | SW01、SW02、SW03 | 读懂一条调用链；Schema；3 个小提交 |
| 2 | SW07、SW09、Q01 | 请求路径图；OpenAPI；验收/反例 |
| 3 | SW10、SW11、Q04 | 表/约束/事务；真实 DB 测试 |
| 4 | SW12、SW13、Q03 | 分层；状态表；幂等并发测试 |
| 5 | SW14、SW15、Q05 | 租户授权；质量场景；合同测试 |
| 6 | Q07、Q08、Q09 | 干净构建；可追溯镜像；容器运行 |
| 7 | Q10、Q11、Q12 | CI；迁移/发布计划；日志/trace |
| 8 | Q13、Q14、Q16 | SLO；杀 worker；恢复演练 |
| 9 | AI01、AI02、AI03 | 模型调用预算；结构化输出与失败分支 |
| 10 | AI04、AI05、AI06、AI07 | 20 题 RAG；来源/ACL；混合检索 |
| 11 | AI08、AI09、AI10、AI11 | 分层评测；安全工具；MCP 边界图 |
| 12 | AI12—AI19 中最相关 5 个 | 可恢复 Agent；Trace；发布门禁 |

## 三种缩放方式

- **只有 15 分钟**：回答一个诊断题并为项目补一个反例；
- **有 45 分钟**：读一节 → 改一处 → 跑一项验证 → 写一句复盘；
- **有 2 小时**：完成一个纵向切片，但仍只围绕当周节点。

## 何时跳过

如果你已经能独立解释、在项目应用、指出边界并有近期测试/事故证据，可跳到变化任务。不要因为“看起来熟悉”跳过，也不要为了完整感重复做低价值教程。

## 何时暂停路线

真实项目出现高风险阻塞时暂停顺序，回补最短前置；完成后回主线。连续两周没有产物，缩小任务，不新增知识节点。
