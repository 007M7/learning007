# CSDIY 语言 DNA

CSDIY 的文字不像百科，也不像课程宣传页。它更像一个已经走过这条路的人坐在你旁边，先给判断，再告诉你判断来自哪项作业、哪次踩坑或哪种学习体验。

## 可量化的声音

全站 136 个中文页面中，115 个含“课程简介”。当前脚本在每次运行时重新清洗并计算：它去掉围栏代码和整行标题、列表、表格、引用、图片、HTML、链接定义，再删除 URL 与 Markdown 标记，只保留叙述正文。这个口径得到 74,253 个非空白字符、52,224 个汉字、688 个段落和 1,293 个句子；它刻意漏掉课程元数据与资源列表，不能冒充整站可见字数。

叙述句平均 57.43 个非空白字符，中位数 51，四分位数为 34 / 72；52.3% 的句子至少 50 字，3.9% 不超过 15 字。47.2% 的叙述段落只有一句。正文的确偏密，主要靠短标题、段间空白和列表恢复节奏，但这些数字描述语料，不是要求后续文章把句子写到同样长度。

在同一叙述口径中，“你”出现 377 次，“我”出现 295 次，“如果”出现 124 次。旧版数字来自另一套清洗口径；本版不再手填结果。作者会直接面向学习者，也会交代亲历，但两种人称承担不同责任。

- “你”用于指出选择、前置和下一步。
- “我”用于交代体验证据，不能替代事实证明。
- “如果”用于分流，让同一份指南服务不同基础和目标。

全站共有 375 个 H2 和 51 个 H3。二三级标题合计平均 4.84 个非空白字符，中位数为 4，四分位数为 4 / 4；常见标题只承担“课程简介”“课程资源”“学习路线”一类路标功能。辨识度主要来自正文判断，不依靠营销式标题或大面积加粗。

## 词汇与标点：能统计什么，不能统计什么

Node 的 `Intl.Segmenter` 只提供中文词语切分，不提供词性。为了不伪造“名词识别”，统计文件将三组结果分开保存：

- **名词样候选**：排除停用词、披露的动词表和副词表后，按频次得到的多字符片段。前列包括课程 483、系统 187、作业 172、计算 149、代码 144、知识 117、语言 95、数据 87、资源 87、理论 85、算法 82。它们大多是领域对象，但“所有”等误入项证明这不是 POS 标注。
- **动词词表命中**：从披露词表中按精确子串计数并保留 50 个有命中的高频动作。前列是学习 309、实现 166、设计 102、需要 90、使用 88、理解 87、开发 65、推荐 55、参考 53、提供 52。它呈现“学习—实现—理解—选择”的动作取向，却会受上下文歧义影响。
- **副词噪声表**：非常 111、基本 37、已经 33、可能 26、相当 24、只是 24、比较 21、直接 21、其实 20、完全 20。高频不等于应模仿；“非常”“比较”尤其需要检查后面是否有具体对象和证据。

叙述正文的主要标点计数为：逗号 2,290、句号 1,233、顿号 412、冒号 113、问号 35、感叹号 13、分号 11。中文双引号开、闭各 68 个，书名号开、闭各 7 个，中文单引号为 0。逗号约为句号的 1.86 倍，与长复句倾向一致；感叹号很少，支持“直接但不靠亢奋”的判断。

按“连续破折号算一个使用单元、成对中英文括号算一个插入单元”的口径，破折号为 19 处，括号为 200 处，比值 0.095。原文更常用括号补课程编号、英文原名和条件，不常靠破折号制造戏剧停顿。引号上下文则主要承担四种责任：标记课程或社区中的惯用称呼、框住需要解释的概念、保留人物原话、提醒某个表面说法正在被质疑；书名号很少，通常只指具体教材。

1,293 个叙述句中有 808 个同时包含汉字与拉丁字母，占 62.5%。高频拉丁表面词是 GitHub、Project、MIT、Lab、Vim、Python、CMU、Stanford 和 C++。这不是随意夹英文，而是课程名、学校、工具、语言与项目制教学本来就以这些标识流通。后续文章保留无法安全翻译的真实标识，普通动作和判断仍用中文完成。完整频次、每千字符比率、引号上下文样本和计算方法都在 [_meta/corpus-statistics.json](./_meta/corpus-statistics.json)，不把启发式结果包装成语言学定论。

## 一句话怎样产生价值

典型句子把评价和依据连在一起，很少孤立地下定义。

```text
判断这门课的价值
→ 点出最有辨识度的 Project、Lab 或教学机制
→ 说明它改变哪种理解
→ 补上成本、缺陷或适用人群
```

“课程很好”没有信息。“四个 Project 逐步实现一个数据库，并能在 shell 中观察结果”才让读者知道好在哪里。后续教学文章也应把“重要、核心、系统、实用”换成对象、动作和可观察结果。

## 开头与结尾

课程页很少用悬念。常见开头有六种，分别是权威定位、亲历判断、作品承诺、同类对比、学习痛点和少量问题串。最有效的开头会在一两段内交代为什么值得投入，以及学完会多出什么能力。

结尾更克制。80% 以上的课程页以资源入口或贡献者仓库结束，普通段落也多用于版本提醒、诚信边界、后续课程或条件建议。结尾通常直接把读者交给下一步行动。

## 后续写作采用的语言规则

1. 先给一个可承担责任的判断，再用事实、机制或案例解释它。
2. 一段只跨过一个理解断口。长句承载两个以上因果关系时，主动拆开。
3. 术语保留真实工作语境中的英文名称，但第一次出现必须落到当前对象。
4. 亲历可以增加可信度，必须标明它是个人经验；教材结论、产品事实和编辑判断不能混写。
5. 对一项方法既写收益，也写代价、前置和不适合者。
6. 删掉没有对象的泛化褒词，用具体动作推动读者。
7. 小标题只标记问题转折。读完标题应知道这一节新增了什么判断，避免重复使用“原理”“实践”“边界”。
8. 结尾给练习、检查点或下一章入口，不写解释作者怎样使用资料的幕后报告。

## 不照搬的语言习惯

CSDIY 的长句和括号很多，适合个人推荐，不一定适合非科班读者学习机制。Learning 007 的核心解释优先控制在 25 至 40 字一句，复杂条件拆成两句。口语可以降低距离感，但每段不应靠玩笑、感叹号或“神课”制造价值。

学校、教授和课程声誉只能用于定位，不能直接证明教学质量。真正的证明仍是内容组织、作业产物、反馈机制、资源开放程度和真实完成成本。
