# CSDIY 文章结构模板

CSDIY 有一套稳定的课程卡结构，可迁移的部分是功能顺序。后续文章先判断读者要完成哪种学习任务，再选择合适的推进方式。

这里的“模板”指可选择的关系骨架，不是页面生成器。31 篇完整深读实际出现至少六类结构：站点前言与价值宣言、按读者分支的指南、跨领域路线图、机制解释加操作步骤、课程决策卡、纯资源目录。逐页开头、转折、正文和结尾记录在 [_meta/review-evidence.json](./_meta/review-evidence.json)；下文没有把占多数的课程卡误写成唯一正确结构。

## 稳定的是学习决策，不是栏目

一篇有效的导航型文章通常完成六个动作。

```text
指出能力缺口
→ 给出选择判断
→ 展示学习后能完成的作品
→ 说明获得能力的练习路径
→ 交代成本、阻塞与替代路线
→ 提供可立即使用的入口
```

这六个动作可以穿插在故事、案例、表格或练习中，不得直接变成六个固定小标题。知识讲义还要继续完成直觉、机制、反例和迁移，不能在“资源可用”处提前结束。

例如，`CS50.md` 用很短的元数据、评价和资源完成一次低成本决策；`CSAPP.md` 必须把 150 小时投入、项目难度和拒绝抄答案写进判断；`workflow.md` 则沿“收集—处理—回顾”逐步增加关系图。三篇承担的教学功能不同，标题数量、证据位置和结尾都不应对齐。

## 类型一　学习节点导读

适合一个阶段或专题的入口页。

- 从读者此刻不会处理的任务开始，不从学科史开始。
- 说明本节点解决什么，以及学完后能交付什么。
- 将先修拆成硬先修、有帮助的先修和可边学边补三类。
- 用一个就绪检查替代模糊的“需要一定基础”。
- 给出主路线、时间不足时的最小路线和继续深挖的出口。

入口页承担导航，不提前讲完正文。它应降低开始成本，而不是再造一篇摘要。

## 类型二　概念与机制教学

适合 Learning 007 的正式章节。

```text
真实任务出现矛盾
→ 旧直觉在具体地方失效
→ 给现象命名并解释机制
→ 用案例、数字或代码做一次判断
→ 用反例暴露适用边界
→ 把判断写进可检查产物
```

CSDIY 提供“为什么值得学”和“下一步做什么”的外壳。Awesome Architecture 与已通过审阅的机器学习章节继续提供中间的机制深度。正文不使用“课程简介 → 资源 → 汇总”结构。

## 类型三　项目与实践指导

适合实验、部署、评测和工程项目。

- 先展示最终产物，让读者知道投入会换来什么。
- 把任务拆成会暴露不同机制的里程碑，不按文件或 API 平均切块。
- 每个里程碑写清产物、机制、验证、反馈和预计时间。
- 踩坑依次写明症状、原因、影响、绕行方案和最后验证日，不写“环境比较麻烦”。
- 明确哪些代码必须自己完成，哪些工具可以辅助，哪些行为越过学习诚信边界。

项目要进入正文，成为迫使隐藏假设显形的主要教学过程。

## 类型四　路线与阶段总结

适合领域路线图和阶段复盘。

- 先按目标或学习者状态分流，不要求所有人完成同一清单。
- 用前置依赖和产物关系连接节点，不只按难度贴标签。
- 对同类资源说明各自的教学哲学和取舍。
- 允许降阶入口、替代路线、选择性完成和停止条件。
- 阶段总结用新场景迁移整条方法，不逐章复述。

路线是带条件的知识网络。章节数量、先后顺序和深入程度都服从阶段出口。

## 写完以后做一次反模板检查

去掉标题后，读者仍应看见当前主题独有的对象、矛盾和判断。若把名词换成另一领域也能成立，正文仍是模板。若连续几篇拥有相同的标题数量、案例位置、表格位置和练习形式，也应停下来重排。

再做一项反证检查：某个栏目删掉后，学习决策是否仍完整？如果完整，栏目可能只是仪式；如果不同文章都“必须”保留同一栏目，提炼已经把教学功能固化成模板。真正稳定的是缺口、证据、成本、分流与下一步之间的关系，呈现顺序要服从当前知识。
