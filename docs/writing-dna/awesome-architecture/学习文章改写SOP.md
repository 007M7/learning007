# Learning 007 学习文章改写 SOP

领域来源库、知识图谱、阶段课程和整板块验收的完整流程，见[领域知识库与学习内容建设 SOP](./领域知识库与学习内容建设SOP.md)。本文继续负责单篇文章与相邻章节的写作细则。

这份 SOP 经过两轮人工审阅。第一轮围绕机器学习第 1 至 4 章，解决单篇文章怎样兼顾连贯、专业与可读。第二轮围绕第 5 至 8 章和第一阶段总结，继续验证相邻章节怎样接力、阶段产物怎样组合，以及课程怎样在不固定篇数的情况下保持由浅入深。

共同标准服务于学习，正文结构服从知识本身。任何已经验证有效的写法都只能作为判断依据，不能升级成所有文章共享的目录。

## 先记住这次修改真正解决了什么

第一版的问题不在知识错误。材料、论文和术语都在，读者却要自己把碎片拼成课程。后来单纯增加公式和名词，信息看起来更密，理解反而更慢。再后来删掉专业内容，故事顺了，读者又很难在读完后迅速提取判断。

最终有效的组合分成两层。

- 开头给出一张很轻的学习图，只回答本章是什么、为什么值得学、学完怎样做，并列出本章会真正用到的术语。
- 正文沿一件具体事情推进，让概念在需要它的位置出现。故事负责把关系讲通，表格、图和术语负责把关系固定下来。

学习图只负责提供入口。正文按照知识关系展开，无需沿三张卡拆成三节，也无需让每篇拥有相同数量的小标题。

## 写单章以前先设计阶段产物

读者不会只学一篇。开始一个阶段以前，先写出这个阶段最终让读者完成什么综合任务，再决定需要哪些章节。

阶段设计至少说明五件事。

| 项目 | 要回答的问题 |
|---|---|
| 阶段出口 | 读者最后能独立处理哪一类完整问题 |
| 必要前置 | 哪些判断缺失以后，综合任务无法成立 |
| 产物关系 | 每章留下的材料怎样被后续章节继续使用 |
| 晋级证据 | 读者需要解释、应用或迁移到什么程度 |
| 未教边界 | 哪些相关知识明确留到后续阶段 |

章节数量由这五项推导。一个必要判断需要独立讲清时，可以新增章节；两个主题共享同一认知难点和同一产物时，可以合并。课程不为整齐凑篇数，也不把一个完整问题机械切成若干等长页面。

第一阶段的出口是一份可信实验包。八章依次留下问题定义、样本时间、决策成本、泛化实验、数据生成图、标签规范、切分协议和泄漏回归集。这个顺序来自产物依赖，并不意味着其他领域也要拥有八章或同名产物。

## 第一步先确定本章让读者多会一个什么判断

开始写作前，用一句可以检查的话描述学习结果。句子里应当出现读者要处理的对象和能够完成的动作。

好的学习结果类似下面这些。

- 能把一条业务记录冻结在决策时刻，判断字段有没有携带未来信息。
- 能根据两类错误的后果推导行动阈值，说明阈值变化的原因。
- 能检查一份实验的训练、验证和测试边界，判断最终分数是否仍然独立。

“了解样本”“掌握损失函数”“熟悉泛化”无法验收，不适合作为本章主线。

## 第二步从来源中提取知识骨架

来源负责校准知识，不负责替作者讲课。动笔前建立一份内部账本，至少记下四项内容。

| 项目 | 要回答的问题 |
|---|---|
| 稳定机制 | 哪条关系在教材和经典论文中反复成立 |
| 关键边界 | 这条关系依赖哪些条件，在哪些地方会失效 |
| 可教学材料 | 哪个数字、过程、反例或实验最适合让读者看懂 |
| 不可推出 | 来源没有证明什么，文章不能把它写成结论 |

正文只吸收已经理解的机制和边界。连续介绍作者、年份、章节和“原稿怎样支持本章”，会把阅读笔记泄漏进文章。引用集中放在文末，只有来源身份会改变判断时才在正文说明。

## 第三步设计开头的学习入口

每章保留四项入口信息。

1. 本章回答什么问题。
2. 这个问题为什么会影响真实结果。
3. 学完以后能怎样处理它。
4. 阅读正文会遇到哪些专业术语。

三张卡里写核心判断，不写名词释义，也不塞操作细节。每张卡控制在读者一眼能读完的长度。术语通常保留四至七个，只收录正文会解释和使用的词。

开头可以保持统一视觉，措辞必须来自本章。删掉标题以后，三张卡仍能被辨认出属于这一章。

## 第四步为正文选择一台合适的推进引擎

正文结构由知识关系决定。常见的推进方式包括下面几种，但每章只选真正需要的一种或两种。

| 知识关系 | 更合适的推进方式 |
|---|---|
| 信息随时间产生 | 跟随一个对象走完时间线 |
| 多个动作承担不同后果 | 从一次具体选择开始算账 |
| 结论依赖实验边界 | 跟随实验从设计到最终评估 |
| 系统在压力下失效 | 沿故障发生顺序追查原因 |
| 多个方案需要取舍 | 在同一组约束下逐项比较 |
| 能力需要逐步建立 | 让同一项目连续遇到更难的问题 |

小标题在正文写顺以后再取。它们用于标记认知转折，不用于平均切分篇幅。不同部分可以很不等长。

第 5 至 8 章验证了四种相邻却不同的推进方式。

| 章节任务 | 推进方式 | 读者跟随的对象 |
|---|---|---|
| 理解数据怎样产生 | 沿产品流程追踪 | 一条记录经过准入、曝光、行动和结果确认 |
| 调查标签与缺失 | 沿标签生产线排查 | 一个现实结果怎样经过记录、同步、关联和判定 |
| 选择切分协议 | 并列模拟几种未来 | 同一模型面对后移时间、新对象和新环境 |
| 审计数据泄漏 | 沿异常高分反向追查 | 最终报告里的信息怎样穿过训练与选择边界 |

四篇使用同一个续费项目，保证读者不用反复认识背景。每篇的矛盾、调查动作和最终产物都不同，因此不会变成同一案例的四次释义。复用案例是为了节省背景负担，不能复用段落骨架。

## 写清相邻章节各自解决什么

内容连续很容易滑向重复。动笔前为每章补完三句话。

1. 本章从上一章接过哪份已经完成的产物。
2. 本章只新增哪个判断，哪些相关问题暂时不展开。
3. 本章把什么结果交给下一章继续处理。

机器学习第 5 章解释记录怎样被流程筛选，第 6 章专门检查结果怎样被测量。两章都会谈数据偏差，但前者处理对象能否进入和被观察，后者处理观察结果怎样变成标签。若这条分工说不清，两篇很快会写成同一篇数据质量概论。

相邻章节共享术语时，也要检查术语承担的动作。第 4 章用时间切分说明泛化实验，第 7 章则根据部署场景设计时间、群组和环境协议。后者接过实验职责，不再重讲训练集与测试集的基础定义。

章节结尾只做交接。它指出本章产物暴露了哪个新问题，让下一章自然开始。结尾不重述全文，也不提前讲完下一章。

## 第五步让术语在读者需要时出现

术语要给已经理解的现象命名。通常先让读者看见一件事怎样发生，再告诉他专业上怎样称呼；如果术语必须先出现，就紧跟一句普通话解释它在当前例子中指什么。

每引入一个术语，都检查三件事。

- 它解决了前文哪个表达困难。
- 读者能否在当前案例里指出它对应的对象。
- 后文是否还会用它作出判断。

三个答案里有两个是否定的，这个术语应当删除或后移。术语不能排队进场，也不能靠括号里的英文制造专业感。

## 第六步只在公式能压缩已有推理时使用公式

公式出现以前，读者应当已经用一个小数字例子走过同样的推理。公式随后负责把关系缩短，并帮助读者改变变量继续判断。

每个公式至少配齐下面三件事。

- 每个量在现实里对应什么。
- 某一项变大时，决定会怎样变化。
- 哪个前提不成立时，公式不能直接使用。

公式只负责表达关系。它不能代替业务定义、数据来源和行动效果。

## 第七步让每一段都推动读者跨过一个理解断口

写完一段，问读者此刻最自然会追问什么。下一段接住这个问题，或者接住上一段刚出现的对象。新段落至少增加一种东西，包括新事实、新动作、新区别、新后果或一个会改变决定的边界。

以下内容通常应该删除。

- 把上一段换一种说法再讲一次。
- 为了展示完整而罗列与当前决定无关的知识。
- 连续给术语下定义，却没有让读者使用它。
- 引用一段来源以后再解释“本章采用了什么”。
- 每个小标题下面都放相同的案例、公式、清单和边界提醒。

还要检查单段有没有承担过多工作。一段同时解释三个术语、两个风险和一条建议，读者很难知道哪个判断最重要。先保留这一段正在处理的对象，其余内容移动到真正需要它的位置。

知识密度来自关系清楚。每个重要术语都应当经历一段完整过程。读者先看见现象，随后得到名称，再用它作一次判断，最后把判断写进产物。只增加名词数量会让文章重新退回知识碎片。

## 第八步让文章完成一次学习过程

文章结束前，读者应当完成一件可检查的产物。产物可以是一张时间线、一份成本表、一张实验边界图或一条决策记录。练习使用正文已经教过的概念，不能拿下一章的内容考读者。

选择题只检查一个关键误区。它不能替代应用练习，也不能被当作掌握证明。结尾只说明下一章继承了本章哪个产物，不再总结全文。

## 每个阶段单独写一篇总结

阶段总结承担整合与迁移，不能把各章摘要重新排列一遍。读者已经看过正文，不需要再读八段缩写。

一篇合格的阶段总结完成下面五项工作。

1. 把各章产物连接成一条完整工作过程，说明前后依赖。
2. 从多章中提炼少量反复使用的判断边界，帮助读者压缩记忆。
3. 更换业务场景，让读者把整套方法迁移一次。
4. 给出基础掌握与熟练掌握的可观察标准。
5. 明确本阶段尚未教授什么，并说明下一阶段为什么从那里开始。

第一阶段总结没有逐章复述续费案例。它把八份产物组合成可信实验包，又让读者为设备故障任务重新建立问题、时间、生成过程、切分和泄漏攻击。读者能够完成这个迁移，才说明他掌握了产物之间的关系。

阶段总结里的题目只能使用本阶段已经讲过的概念。单次选择题用于发现明显误解，综合迁移任务才是阶段晋级的主要证据。读者能不看答案解释、完成基础应用，并在新场景中指出失败边界，才能分别达到基础掌握与熟练掌握。

## 第九步按五轮完成审稿

第一轮只看主线。用五句话复述文章，若五句话互不相干，正文仍然是知识拼盘。

第二轮只看章节分工。删掉标题后，说清本章从上一章接过什么，又给下一章留下什么。若相邻两篇可以互换大半正文，至少有一篇边界没有建立。

第三轮只看读者负担。检查术语第一次出现的位置、代词指向、长句主语和公式前的数值例子。

第四轮只看知识价值。读者读完以后应当能说出一个结构化判断，并知道怎样把它用在新情境里。若删掉三分之一后判断和产物没有变化，原稿仍有重复解释。

第五轮才看格式与自动检查。核对链接、来源账本、组件渲染、移动端布局和构建结果。自动检查能发现格式问题，不能替代教学审阅。

## 先小规模放行，再扩大改写

一篇文章通过，只能证明单篇写法成立。连续四篇通过，才能初步证明章节之间没有严重重复或断裂。一个阶段总结通过，才能证明读者可以把章节重新组合成完整方法。

因此，大规模改写分三道门。

| 放行范围 | 要验证的内容 |
|---|---|
| 单篇试写 | 学习入口、正文主线、术语解释和最小产物 |
| 连续章节 | 相邻分工、案例延续、产物交接和结构差异 |
| 阶段总结 | 产物整合、陌生场景迁移、晋级标准和后续边界 |

任何一道门出现可读性下降、名词堆叠或固定目录复发，都停在当前范围修正。通过自动检查只能说明页面可构建，不能代替读者审阅。

## 大规模改写前的放行条件

一篇试写章只有同时满足下面条件，才能成为后续章节的质量参照。

- 开头学习图能够快速提取核心问题和术语。
- 正文脱离学习图以后仍是一篇完整文章。
- 小标题来自知识推进，不与其他章节同构。
- 读者能复述一个机制，也能完成一个新情境判断。
- 术语增加了表达能力，没有打断理解。
- 公式、表格和图各自承担关系，没有作为装饰重复正文。
- 来源校准了结论，正文没有变成来源报告。
- 文章写清适用边界，也给出下一步产物。

第一章确认后，第 2 至 4 章用于验证这套方法能否适应时间线、决策计算和实验推演三种不同知识。三篇都通过人工审阅以后，才扩大到其余章节。课程章节数同样服从知识前置和阶段产物，不能为了凑齐固定数量合并必要主题，也不能把一个主题平均拆成数篇。

第 5 至 8 章进一步验证了跨章写作。共同案例降低了背景成本，差异化推进方式保护了每章边界，阶段总结则把阅读结果转化成一次综合迁移。以后扩展其他领域时，沿用这套放行顺序，重新设计该领域自己的阶段出口、章节产物和正文结构。
