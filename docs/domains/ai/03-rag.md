# 03 · Embedding、RAG 与检索评测

<div class="lesson-meta"><span>AI05—AI08</span><span>必修核心</span><span>预计 4 × 60 分钟</span><span>前置：AI01—AI04、SW10</span></div>

## 本章可观察目标

你能解释 RAG 的端到端数据流；按文档结构切块并保留权限/来源；组合关键词、向量与重排；分别评测检索和回答，定位失败阶段。

## AI05 · Embedding 与相似度

Embedding 把文本映射为向量，距离/相似度用于寻找语义接近项。它不提供事实正确、权限或时效保证。模型版本、向量维度、归一化和距离函数必须一致；升级通常需要重建索引并 A/B 评测。

## AI06 · 摄取、解析、切块与元数据

```text
来源 → 获取/版本 → 解析/OCR → 结构化切块 → Embedding/关键词索引
                                  └→ source_id、标题、页码、时间、ACL、hash
```

切块不是固定每 500 字：优先保持标题、段落、表格和代码单元；需要少量重叠但避免重复污染。每块必须能回到原文位置。删除或权限变化要传播到索引；否则检索层会成为数据泄漏副本。

## AI07 · 检索、重排与引用

查询先改写/过滤，再进行关键词（适合专有名词、ID）和向量召回，合并候选并重排，最后只把最相关且有权限的片段交给模型。引用应指向实际支持句子的来源，不是页面列表装饰。

多租户 ACL 应在检索查询中强制过滤，不能先跨租户召回再让模型“不要泄露”。对时效敏感问题加入时间过滤与“截至何时”。无足够证据时允许回答不知道。

## AI08 · 分开评测检索与生成

| 阶段 | 关键问题 | 示例指标/证据 |
|---|---|---|
| 解析 | 原文是否完整、表格是否损坏 | 抽样比对、解析失败率 |
| 召回 | 支持答案的块是否进入候选 | Recall@k、命中分析 |
| 重排 | 正确块是否靠前 | MRR/NDCG、人工排序 |
| 生成 | 回答是否由证据支持 | 正确性、引用支持率、拒答 |
| 系统 | 权限、时延、成本是否达标 | ACL 测试、p95、Token/查询 |

如果正确片段没召回，改 Prompt 无济于事；如果召回正确却回答错误，才检查生成指令、上下文冲突和模型。评测集要含：可回答、不可回答、过期、冲突来源、专有名词、跨租户、注入文档。

## 练习：20 问最小评测集

选择 10—30 份真实文档，建立 20 个问题及证据块：12 个可答、4 个应拒答、2 个跨权限、2 个冲突/过期。记录每次索引/检索/Prompt 版本，比较纯关键词、纯向量和混合检索。

常见误区：只演示一个成功问题；块没有 source/ACL；向量库永不删除；召回和回答混成一个分数；引用存在但不支持结论；用训练数据假装测试集。

## 本章完成标准

任意回答可定位到具体原文；跨租户测试无法召回；对至少三个失败样例明确归因到解析/召回/重排/生成；一次变化有前后评测，而非主观“感觉更好”。
