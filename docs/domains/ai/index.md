# AI 应用与 Agent 系统

> 核心问题：怎样让不确定的大模型，在确定的权限、证据和业务规则内工作？

## 你将建立的能力

- 理解 Token、Context、Embedding和非确定性；
- 选择生成、检索、规则或人工处理；
- 构建带引用的 RAG 和受控 Tool Calling；
- 设计可暂停、恢复、审计的 Agent Runtime；
- 使用评测集判断模型、Prompt或工具升级是否退化。
