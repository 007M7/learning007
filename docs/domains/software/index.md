# 软件与系统工程

> 核心问题：一段业务需求，怎样成为结构清楚、数据正确、可以维护的软件？

## 你将建立的能力

- 理解程序、进程、网络、数据库之间的关系；
- 读懂一次请求从界面到数据库的完整路径；
- 为 AI 写清输入、输出、状态、权限和错误边界；
- 判断一个实现是“能跑”，还是具备可维护的业务结构。

## 第一阶段模块

| 模块 | 为什么现在学 | 最小掌握证据 |
|---|---|---|
| 程序执行与调试 | 能判断 AI 代码实际会做什么 | 不看答案解释一段请求处理代码 |
| HTTP 与 API | 前后端和工具调用的共同语言 | 独立分析一次请求与错误响应 |
| SQL 与数据建模 | 数据是业务系统的事实基础 | 设计带约束、事务和迁移的表结构 |
| 状态、幂等与权限 | 决定系统是否会重复写入或越权 | 为一个写接口画状态与授权边界 |
