# 质量与生产交付

> 核心问题：怎样证明系统正确，并在失败时发现、止损和恢复？

## 你将建立的能力

- 从需求提取正常、异常和边界测试；
- 区分单元、集成、合同和端到端测试；
- 让一个服务可以重复构建、部署和回滚；
- 使用日志、指标和追踪定位真实问题；
- 对崩溃、重复执行和数据恢复进行验证。
