## 一次错引把问题从检索拉回模型

我们要做的贯穿项目是一名内部政策知识助手。用户输入问题，系统先从已经生效的制度文档中召回候选段落，再由一个小编码器或交叉编码器判断候选是否真正支持答案。只有通过支持判断的段落才能进入回答，而且回答必须带文档版本和段落链接。

第一批候选模型暂时叫作 `E-small` 与 `E-multi`。名字只表示两个待测方案，不暗示真实排行榜；为了让下一章能够核算资源，本阶段把 `E-small` 约定为一个约 110M 参数的教学候选。团队先拿下面这对句子做故障样本。

```text
问题：今年没用完的年假能结转吗？
候选 A：未休年假可以结转，最晚应在次年三月三十一日前使用。
候选 B：未休年假不可以结转，公司将在年底统一清零。
```

假设某次本地试验中，查询与 A 的余弦相似度为 `0.80`，与 B 为 `0.92`。这些数字是教学用的假设观测，不是任何公开模型的成绩。若系统把 `0.9` 当作支持阈值，它会拒绝 A、接受 B。故障并不是“余弦算错了”，而是团队把“主题和措辞接近”偷换成了“事实能够推出答案”。

我们因此把系统拆成两道不同职责：双编码器负责用较低成本找回可能相关的段落，支持验证器负责区分支持、矛盾与信息不足。后面所有数学都服务于这两个可观察问题。

1. 变换后的表示保留了哪些差异，又丢掉了哪些差异？
2. 最终分数能否在独立样本上对应一个稳定的错误风险？

如果回答不了，增加向量维度或把模型换大都只是新的假设。

## 向量先规定模型能够比较什么

编码器不会直接比较两段自然语言。它先把每个输入映射到一个向量。一个批次有 `B` 个文本、每个表示有 `d` 个维度时，可以写成矩阵

$$
H \in \mathbb{R}^{B\times d}.
$$

一层线性变换 `Z = HW + b` 把旧表示混合成新表示。若 `W` 的形状是 `[d, k]`，输出 `Z` 就是 `[B, k]`。矩阵在这里不是装数字的表，而是一组对整个批次重复使用的变换规则。调试时先写形状，能比盯着某个浮点数更早发现批次轴、序列轴或隐藏维被放错。

双编码器分别得到查询矩阵 $Q\in\mathbb{R}^{m\times d}$ 和文档矩阵 $D\in\mathbb{R}^{n\times d}$。若向量都已归一化，$S=QD^\top$ 会一次产生 `[m, n]` 个余弦相似度。这个批量矩阵乘法解释了为什么向量召回很快：文档向量可以预先计算，查询到来时只需做相似度搜索。

速度来自一个限制。查询与文档在打分前互相看不见，编码器只能把大量关系压进各自的固定长度向量。否定词、有效日期、例外条款和精确数字可能只占很小一部分，主题相似度却会主导方向。点积也会同时受方向与长度影响；余弦去掉长度影响，仍没有引入“蕴含”这个目标。

因此，表示质量只能由任务反推。政策助手至少需要包含同主题反义句、过期版本、数字只差一位、例外条件缺失等困难负例。若这些样本没有进入评测，“向量很漂亮”没有产品含义。注意这也限定了本章的结论：二维示意和小批次能够解释运算，不能证明高维表示内部只有两个可命名语义，也不能把相似度解释成因果关系。

## 分数经过归一化也不自动成为可信概率

支持验证器可以把查询与候选一起编码，再输出三个 logit：`支持`、`矛盾`、`信息不足`。Logit 是未归一化分数。Softmax

$$
p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}
$$

把它们变成和为一的数。实现时通常先减去最大 logit，避免指数溢出；减去同一个常数不会改变结果。对二分类，sigmoid $p=1/(1+e^{-z})$ 承担相同的归一化角色。

“和为一”只说明模型在给定类别之间分配质量，不说明长期频率已经吻合现实。若 100 个被报成 `0.9` 的支持判断只有 65 个正确，模型就是过度自信。自然语言中的“我有九成把握”更不是测量结果，除非它经过同样的数据定义、独立校准与复核。

概率之所以值得争取，是因为它能和错误代价连接。假设以下仍是教学用的决策模型：错误引用一段不支持的政策平均造成 20 个损失单位，拒答并转人工造成 1 个单位；人工复核能力足够，且两类代价在当前队列中近似稳定。若 $p$ 真的是“候选确实支持答案”的校准概率，那么自动接受的期望损失是 $20(1-p)$，拒答损失是 1。只有

$$
20(1-p)<1 \quad\Rightarrow\quad p>0.95
$$

时，自动接受才比拒答便宜。这个 `0.95` 不是行业阈值；改变错误后果、复核容量或样本群体就要重算。若 $p$ 未经校准，这段成本计算甚至没有合法输入。

<span id="aai03"></span>

## 交叉熵让自信的错误付出更大代价

训练需要把“错了多少”写成可求导的量。二分类交叉熵为

$$
L=-\big[y\log p+(1-y)\log(1-p)\big].
$$

正确标签为 1 时，模型给 `0.9` 的损失约为 `0.105`，给 `0.1` 的损失约为 `2.303`。它不只是数错了几个样本，还会重罚自信的错误。从信息论看，交叉熵衡量用模型分布编码真实结果时付出的平均代价；在真实分布固定时，降低交叉熵等价于降低从真实分布到模型分布的 KL 差异。这个解释不能反过来证明训练样本就是部署世界：样本偏了，模型会更高效地拟合偏差。

回到开头的两条候选。先把支持验证器极度简化，只保留两个特征：`语义相似度` 与 `极性一致`。支持样本是 $x^+=(0.80,1), y=1$，矛盾样本是 $x^-=(0.92,-1), y=0$。初始权重 $w=(2,0)$、偏置 $b=0$，因此模型只看相似度：两条 sigmoid 概率约为 `0.832` 与 `0.863`，平均交叉熵约为 `1.086`。

对 logistic 模型，单个样本关于 logit 的导数恰好是 $p-y$。两个样本平均后，极性权重的梯度约为 `-0.515`；学习率设为 `0.5` 时，更新规则

$$
w\leftarrow w-\eta\nabla_wL
$$

会把该权重从 `0` 推到约 `0.258`。同时更新相似度权重与偏置后，新权重约为 `(1.835, 0.258)`，偏置约为 `-0.174`，平均损失降到约 `0.850`。矛盾样本的概率从 `0.863` 降到约 `0.778`。一步更新没有解决任务，却清楚显示：损失通过梯度要求模型降低自信错误，而极性特征因为能区分这对样本开始获得权重。

梯度只保证当前位置附近的一阶下降方向。学习率过大可能越过低谷，非凸网络也不承诺找到全局最好。训练损失下降更不等于产品风险下降；若负例只包含随机文档，不包含同主题矛盾句，模型仍能通过主题捷径得到低损失。

## 校准集为概率补上频率含义

分类正确率、排序质量和校准是三个问题。一个模型可以把正确候选排在前面，却把所有分数都压在 `0.51` 附近；也可以准确率不错，却把错误样本报成 `0.99`。前者排序可用但决策余量小，后者一旦接入自动接受阈值就危险。

校准要在没有参与权重训练的样本上进行。把预测按置信区间分桶，比较每桶平均置信与真实正确率，可以画 reliability diagram。Brier score $\frac{1}{N}\sum_i(p_i-y_i)^2$ 同时惩罚概率偏离结果；ECE 把各桶的置信—正确率差加权汇总，但会随分桶方式和样本量变化，不能单独担任放行门禁。

Guo 等人在 2017 年的图像与文档分类实验中发现，当时多种现代神经网络存在明显误校准，温度缩放在其测试设置中常有效。温度缩放用独立校准集学习一个标量 $T$，以 $\operatorname{softmax}(z/T)$ 调整尖锐程度，通常不改变类别排序。它的适用边界同样重要：这项结果不证明温度缩放对生成式语言模型、分布漂移或每个业务子群都可靠；校准集与线上人群不一致时，旧温度也会失效。

政策助手应至少分开报告普通支持句、否定/例外句、过期版本和长文档四个切片。总体曲线看似贴近对角线，少数高风险切片仍可能过度自信。校准只能修正分数含义，不能补回没有召回的正确文档，也不能修复错误标签。

## 用同一张表选择小编码器，而不是挑最高分

下面是一张假设的本地试验表，用来演示决策结构。它不是 `E-small`、`E-multi` 或任何真实模型的公开基准。任务集按文档版本隔离，测试集在阈值确定前保持封存。

| 候选 | 支持段落 Recall@5 | 矛盾样本误接受率 | 支持概率 ECE | 单查询 p95 延迟 | 当前判断 |
|---|---:|---:|---:|---:|---|
| `E-small` + 小验证器 | 0.84 | 0.08 | 0.06 | 22 ms | 进入下一轮机制与训练预算审查 |
| `E-multi` + 小验证器 | 0.86 | 0.07 | 0.05 | 47 ms | 精度差异需区间，且超过 30 ms 预算 |
| 仅向量阈值 | 0.86 | 0.19 | 不适用 | 12 ms | 不能承担自动引用 |

这里的选择不是宣布 `E-small` 更先进。假设当前端到端延迟预算只有 30 ms，而前两者的风险差异在小样本置信区间内尚不稳定，那么保留较小方案做扩大试验更经济。若多语言员工是主要人群，或 `E-small` 在该切片显著失效，结论应反转或缩小适用范围。

模型判断表至少保留六项：任务切片、表示/打分方式、训练损失、独立校准方法、错误代价与阈值、未通过时的退路。数字不带数据版本、样本数和区间，就不能进入选型记录。

## 把整条链做成一个可重放小实验

下面代码只依赖 NumPy，复现前述两个样本的一次更新，并用有限差分检查解析梯度。两条样本过小，代码只验证计算关系，不能证明泛化或完成校准。

```python
import numpy as np

X = np.array([[0.80, 1.0], [0.92, -1.0]])  # 相似度、极性一致
y = np.array([1.0, 0.0])
w = np.array([2.0, 0.0])
b, lr = 0.0, 0.5

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

def loss_at(weight, bias):
    p = sigmoid(X @ weight + bias)
    eps = 1e-12
    return -(y*np.log(p+eps) + (1-y)*np.log(1-p+eps)).mean()

p = sigmoid(X @ w + b)
grad_w = X.T @ (p - y) / len(y)
grad_b = (p - y).mean()

eps = 1e-5
probe = np.array([0.0, eps])
finite_diff = (loss_at(w + probe, b) - loss_at(w - probe, b)) / (2*eps)
assert np.allclose(finite_diff, grad_w[1], atol=1e-6)

before = loss_at(w, b)
w2, b2 = w - lr*grad_w, b - lr*grad_b
after = loss_at(w2, b2)
print(p.round(3), grad_w.round(3), round(before, 3), round(after, 3))
assert after < before
```

完成练习时不要止于“运行成功”。

1. **最小复现：**先预测输出约为 `[0.832, 0.863]`，解释为什么矛盾句反而更高；再核对损失约从 `1.086` 降到 `0.850`。
2. **变式：**把第二列全部置零，重复 20 步，观察模型为何只能压低总体置信而学不会否定；再把学习率改成 `5`，记录损失是否稳定下降。每个变化只改一项。
3. **验证：**保留形状断言和有限差分；把两条训练样本扩成至少 12 条自写样本，并把同一文档版本放在同一侧，避免句式近亲跨集合。
4. **反馈：**输出一页实验记录，写清预期、实际、差异和下一步。若有限差分不通过，先查平均因子与正负号；若训练降损而隐藏负例仍失败，反馈应指向样本/目标，而不是继续调学习率。

## 本章小结：概率只有经过任务、校准与代价约束才可用于决策

模型分数只有沿着“表示 → logit → 概率 → 损失 → 梯度 → 校准 → 决策”留下可重放证据，才有资格驱动接受或拒绝。本章为政策助手固定了支持任务与困难负例，解释了表示和分数的职责，用数值检查验证了一次损失更新，再以独立校准集和错误代价确定阈值。训练损失下降只说明优化过程响应了当前目标，不能证明概率可信，也不能替代隐藏切片上的误接受率。

这份模型判断表仍没有回答 `E-small` 内部怎样让 Token 互相提供上下文，也没有回答 110M 级参数、真实 Token 长度与训练数据会消耗多少内存和算力。

下一章接过同一份模型判断表和同一批政策样本，打开一个 Transformer 编码器的单层计算，再把 tokenizer、数据谱系、显存账和扩展试验接上。只有机制解释和资源测量都与这张表对得上，`E-small` 才有资格从玩具更新进入小规模训练。
