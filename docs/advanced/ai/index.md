# AI 应用与 Agent · 可选进阶

> 进阶不是把模型、训练、推理、GraphRAG 和多 Agent 全部做一遍。它帮助你定位瓶颈，然后只为值得解决的问题购买更深的复杂度。

## 什么时候进入这条路线

先完成 AI 核心路线，至少拥有稳定任务、版本化数据、简单基线和分层评测。若当前失败主要来自需求含糊、知识源过期、权限缺失、工具不可恢复或没有测试集，训练与多 Agent 不会修复它们。

下面几种情况值得进入进阶：

- 你需要读懂损失、概率、梯度、注意力或训练论文，才能作出模型选择；
- Prompt 与基础 RAG 已有稳定基线，仍无法适配特定表达或任务分布；
- 自托管的显存、首 Token、吞吐、尾延迟和成本已经决定产品可行性；
- 普通混合检索无法处理多跳实体关系或多模态证据；
- 单工作流无法利用明确可并行的子任务或独立权限，需要严谨比较多 Agent。

如果只是好奇模型原理，可以主动学第一阶段；如果要改生产系统，必须先写当前瓶颈、基线、收益指标和退出条件。

## 三阶段怎样连接

| 阶段 | 核心问题 | 主要产物 |
|---|---|---|
| 一 · 表示与训练证据 | 一个分数怎样变成概率、损失和梯度，Transformer 又如何消耗数据与资源 | 最小数值实验、模型/Tokenizer 合同、训练数据谱系与单卡 pilot |
| 二 · 适配与服务 | 什么时候值得改参数，已验收模型怎样在真实负载下正确服务 | base/Prompt/RAG/PEFT 对照、独立评测、模型卡、容量与正确性回归 |
| 三 · 检索与协作扩展 | GraphRAG、多模态检索或多 Agent 是否真的解决当前失败 | 分层检索实验、证据图谱、单/多 Agent 同预算对照与退出 ADR |

三个阶段不是模型训练的固定生命周期。只需要 Advanced RAG 的项目仍应理解评测与服务边界；只需要读论文的人可以先完成第一阶段，不必为了“完整”部署多 Agent。

## 用误差来源选章节

| 主要误差或约束 | 先进入 | 最小对照 |
|---|---|---|
| 看不懂 logits、交叉熵、梯度或校准 | 01 数学与优化 | 手算、小张量与有限差分 |
| 需要解释 attention、分词、数据与训练资源 | 02 Transformer 与训练 | 小模型前向、Tokenizer 反例与单卡曲线 |
| Prompt/RAG 已稳定但任务表达仍不适配 | 03 微调与评测数据 | 不训练基线 vs PEFT，盲测与回退 |
| 显存、TTFT、吞吐或成本阻塞自托管 | 04 推理系统 | 相同模型、请求分布与正确性门禁 |
| 查询确实依赖多跳关系或图像/音频证据 | 05 Advanced RAG | 普通混合检索 vs 图/多模态方案 |
| 有可分离的并行子任务或独立权限 | 06 多 Agent | 单 Agent vs 多 Agent 的质量、成本和失败率 |

不能从“技术名”反推问题。一个更复杂方案只有在相同任务、数据、预算和安全条件下稳定修复目标失败，才有采用理由。

## 贯穿项目不是训练一台大模型

路线使用一个可引用政策知识助手和一个小型 `E-small` 模型作为实验对象。第一阶段理解它怎样表示、训练和失效；第二阶段比较是否需要适配，并把通过验收的模型放入推理服务；第三阶段只在证据结构或任务并行确有需要时扩展检索与协作。

实际学习可以使用公开小模型、CPU/单卡或纯 NumPy 玩具实验。目标是复现方向、暴露约束和形成判断，不是复制论文榜单。任何训练结果都要与不训练基线比较，任何服务优化都要保留输出正确性，任何多 Agent 都要保留单 Agent 或确定工作流基线。

## 真实投入与缩小方式

完整路线按 **74 个标准回合**核算，每回合 45 分钟，共 55.5 小时：六章正文 50 回合、三次阶段迁移 18 回合、三次环境准备 3 回合、三个阶段各一次延时复测 3 回合。章节回合已经包含实验运行、失败分析与报告，不再另收未标注时间。按每周 4～5 回合约需 15～19 周；硬件差异会改变墙钟等待，却不改变需要交付的证据。

资源不足时这样缩小：

- 将完整训练改成几百步小数据 pilot，保留数据谱系与独立评测；
- 将大模型服务改成小模型/模拟 trace，仍测 prefill、decode、batch 和尾延迟；
- 将 GraphRAG 缩成几十个实体的可检查图，保留基础检索对照；
- 将多 Agent 缩成两个角色和一个可复位任务，保留同预算单 Agent；
- 不做底座预训练时，可以跳过完整分布式实现，但不能跳资源估算、checkpoint 与失败恢复概念。

缩小规模不等于删除反例和验收。一次可解释的小实验，比跑通一个不知道为何有效的大框架更有学习价值。
