# 学习中心

学习区只负责课程、练习与项目。教材、论文、标准和证据账本统一进入[知识库](/knowledge-base/)，避免“学习顺序”和“资料收藏”混在一起。

## 先选择专题

| 专题 | 包含的正式学习内容 | 什么时候进入 |
|---|---|---|
| [软件与系统工程](/domains/software/) | 16 个核心节点＋18 个软件进阶节点 | 需要理解程序、数据、接口、并发、存储与架构演进 |
| [质量与生产交付](/domains/quality/) | 16 个核心节点＋18 个交付进阶节点 | 需要证明系统正确，并完成构建、发布、观测、恢复与安全治理 |
| [AI 应用与 Agent](/domains/ai/) | 19 个核心节点＋AI 进阶＋Agent 前沿＋AI 产品经理 | 需要把模型、检索、工具、Runtime、评测与产品决策接入真实系统 |
| [模型学习](/fields/machine-learning/) | 机器学习＋深度学习＋NLP 三条正式路线 | 需要理解模型怎样训练、泛化、处理语言并接受可信评测 |
| [物理 AI](/fields/low-altitude/) | 低空智能＋机器人两条正式路线 | 需要把感知、规划、控制和学习带入物理世界 |

“并入专题”表示这些内容在导航中共享一个上级入口，并保留自己的总览、路线、证据账本和正式章节。它不意味着把多门课程合成一篇长文。

## 学习辅助

| 入口 | 用途 |
|---|---|
| [学习方法](/guide/) | 诊断起点、控制近期学习量、练习、复盘与判断掌握 |
| [知识全景](/map/) | 查看专题之间的前置、支撑、约束与独立边界 |
| [项目案例](/cases/) | 在真实约束下组合软件、质量和 AI 知识 |
| [架构模板](/templates/) | 保存需求、系统图、契约、测试、决策与安全边界 |
| [正式学习](/learn/formal/) | 从专题进入现有核心课程、进阶路线和四十章深研内容 |

## 推荐使用顺序

先在知识全景中找到与当前问题最接近的专题，再进入专题总览。近期只选择三至五个节点，用项目案例应用这些节点，并把教材和论文核验工作留在对应知识库中。
